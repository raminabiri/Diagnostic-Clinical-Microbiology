# فلوچارت‌های تشخیصی: مایکوباکتری‌ها

## فلوچارت ۱: از نمونه تا گزارش (شک به سل ریوی)

```mermaid
flowchart TD
A[خلط: 2 تا 3 نمونه] --> B[نمونهٔ اول: Xpert MTB/RIF Ultra]
A --> C[NALC-NaOH ، سانتریفیوژ در BSC]
C --> D[اسمیر اورامین یا ZN<br/>درجه‌بندی]
C --> E[MGIT + LJ یا 7H11<br/>تا 6 تا 8 هفته]
B -->|MTB + ، RIF R| B1[MDR فرضی<br/>Xpert XDR یا LPA ، کشت برای AST<br/>اطلاع فوری]
B -->|MTB + ، RIF S| B2[سل؛ کشت برای تأیید و AST]
B -->|trace| B3[تفسیر با بالین؛ تکرار]
B -->|منفی| B4[سل رد نمی‌شود اگر اسمیر یا کشت مثبت شود]
D -->|مثبت| D1[گزارش فوری اسمیر<br/>جداسازی تنفسی بیمار]
E -->|مثبت| F[فلوچارت 2]
```

## فلوچارت ۲: کشت مثبت مایکوباکتری ← شناسایی

```mermaid
flowchart TD
A[MGIT یا محیط جامد مثبت] --> B[اسمیر AFB از کشت<br/>+ کشت روی آگار خون برای آلودگی]
B -->|AFB منفی، باکتری دیگر| B1[آلودگی ← آلودگی‌زدایی مجدد]
B -->|AFB مثبت| C[MPT64 یا NAAT یا LPA]
C -->|MTBC| D[گزارش M. tuberculosis complex<br/>اطلاع به پزشک و بهداشت<br/>AST فنوتیپی و مولکولی]
D --> D1{PZA R ذاتی، نیاسین − ، سابقهٔ BCG؟}
D1 -->|بله| D2[M. bovis یا BCG ← آزمایشگاه مرجع]
C -->|NTM| E{رشد در کمتر از 7 روز}
E -->|بله| F[سریع‌رشد: M. abscessus، fortuitum، chelonae<br/>MALDI-TOF یا hsp65 ، rpoB ، erm41]
E -->|خیر| G[کندرشد: MAC، M. kansasii، M. xenopi، M. gordonae<br/>MALDI-TOF یا LPA]
F --> H[اهمیت بالینی: فلوچارت 3]
G --> H
```

## فلوچارت ۳: اهمیت NTM در نمونهٔ تنفسی (معیارهای ATS/ERS/ESCMID/IDSA)

```mermaid
flowchart TD
A[NTM از نمونهٔ تنفسی] --> B{گونه}
B -->|M. gordonae، M. mucogenicum| B1[معمولاً آلودگی<br/>گزارش با یادداشت]
B -->|M. kansasii| B2[همیشه بالقوه پاتوژن<br/>بررسی بالینی]
B -->|سایر: MAC، M. abscessus، M. xenopi| C{معیار میکروبی}
C -->|کشت مثبت از 2 خلط جداگانه| D[معیار میکروبی برآورده]
C -->|1 BAL یا شستشوی برونش مثبت| D
C -->|بیوپسی با هیستولوژی گرانولوماتوز + کشت مثبت| D
C -->|فقط 1 خلط مثبت| E[ناکافی ← نمونه‌های بیشتر]
D --> F[همراه علائم و تصویربرداری ← بیماری NTM<br/>شناسایی تا گونه یا زیرگونه + AST]
```
