# ۲۳. مایکوباکتری‌ها

## دامنه
باسیل‌های **اسید–فست** با دیوارهٔ غنی از **مایکولیک اسید**؛ رشد **کند** (MTB: ۲–۶ هفته) یا **سریع** (کمتر از ۷ روز)؛ رنگ گرم ضعیف («گرم مثبت شبح‌مانند» یا مهره‌ای).

| گروه | گونه‌های مهم |
|---|---|
| ***M. tuberculosis* complex (MTBC)** ☣️ | ***M. tuberculosis***، *M. bovis* (و **BCG**)، *M. africanum*، *M. microti*، *M. caprae* |
| **NTM کندرشد** | ***M. avium* complex** (MAC: *M. avium*، *M. intracellulare*، *M. chimaera*)، ***M. kansasii***، *M. xenopi*، *M. marinum*، *M. haemophilum*، *M. simiae*، *M. ulcerans*، *M. gordonae* (اغلب آلودگی) |
| **NTM سریع‌رشد (RGM)** | ***M. abscessus*** complex (*abscessus*، *massiliense*، *bolletii*)، ***M. fortuitum***، ***M. chelonae***، *M. mucogenicum* |
| ***M. leprae*** | غیرقابل‌کشت ← لام **بریدگی پوست** (slit-skin smear) و PCR |
| در ماژول‌های دیگر | *Nocardia*، *Rhodococcus*، *Gordonia*، *Tsukamurella* (اسید–فست **اصلاح‌شده**) ← [15](../15_Aerobic_GPB/README.md) |

## اهمیت بالینی (خلاصه)
| ارگانیسم | بیماری |
|---|---|
| ***M. tuberculosis*** | سل ریوی و خارج ریوی (لنفادنیت، پلور، مننژیت، استخوان، ادراری-تناسلی، میلیاری)؛ **گزارش‌دادنی**؛ MDR/XDR |
| *M. bovis* / BCG | سل از شیر غیرپاستوریزه؛ **BCG**: عفونت پس از تزریق داخل مثانه یا واکسن؛ **ذاتاً PZA R** |
| **MAC** | بیماری ریوی (برونشکتازی، زن سالمند لاغر، COPD)؛ **منتشر در HIV**؛ لنفادنیت کودکان؛ *M. chimaera*: **دستگاه گرم‌کن–سردکن جراحی قلب** |
| ***M. kansasii*** | بیماری ریوی **شبیه سل** (حفره) |
| ***M. abscessus*** | بیماری ریوی (**CF**، برونشکتازی)، پوست/بافت نرم پس از **جراحی زیبایی، مزوتراپی، تاتو**؛ مقاومت بالا |
| *M. fortuitum*، *M. chelonae* | عفونت زخم جراحی، کاتتر، **پدیکور**، تزریقات |
| *M. marinum* | **گرانولوم آکواریوم** (دست، تماس با ماهی/آب) |
| *M. haemophilum* | ضایعات پوستی در نقص ایمنی؛ لنفادنیت کودکان |
| *M. ulcerans* | زخم بورولی |
| *M. gordonae*، *M. mucogenicum* | **آب لوله‌کشی** ← آلودگی/کاذب‌طغیان |

## نمونه‌ها و روش‌ها
- **خلط:** **۲–۳ نمونه** (حداقل یکی صبحگاهی)، ۵–۱۰ mL؛ القایی یا BAL در صورت نیاز؛ **شیرهٔ معده** در کودکان.
- **پیش‌پردازش NALC–NaOH** (نمونه‌های غیراستریل) ← **اسمیر** (اورامین/ZN) + **یک محیط مایع (MGIT) + یک محیط جامد (LJ یا 7H11)** ← [11_Culture_Media/07](../11_Culture_Media/07_Mycobacterial.md)؛ رنگ‌آمیزی و درجه‌بندی ← [12_Identification_Tests/01 بخش ۱.۲](../12_Identification_Tests/01_Microscopy_Stains.md).
- **NAAT (Xpert MTB/RIF Ultra)** روی اولین نمونه ← تشخیص سریع + مقاومت به ریفامپین ← [AST/06 بخش ۴](../AST/06_Mycobacteria/01_Mycobacteria_AST.md).
- **دما:** ۳۵–۳۷°C؛ نمونه‌های **پوستی** هم در **۲۸–۳۰°C** (*M. marinum*، *M. haemophilum*، *M. ulcerans*)؛ *M. haemophilum* + همین.
- **نگهداری:** MGIT تا **۶ هفته**؛ محیط جامد تا **۶–۸ هفته**.
- **IGRA و TST:** عفونت (نهفته یا فعال) را نشان می‌دهند؛ **سل فعال را تأیید یا رد نمی‌کنند**.

## ایمنی ☣️
کشت *M. tuberculosis* در **BSL-3** (یا BSL-2 با روش‌های BSL-3)، **BSC کلاس II**، سانتریفیوژ با **درپوش ایمنی**، **N95/PAPR**. تهیهٔ اسمیر از نمونهٔ مستقیم در BSC. پایش کارکنان (IGRA/TST سالانه).
