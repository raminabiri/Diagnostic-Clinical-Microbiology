# آنتی‌بیوگرام — مایعات استریل، چشم، گوش، مغز استخوان بر اساس EUCAST

> **مرجع:** EUCAST Breakpoint Tables (نسخهٔ جاری). ⚠️ با نسخهٔ جاری تطبیق دهید.

## ۱. نکات ویژه
| موضوع | EUCAST |
|---|---|
| **عوامل موضعی** | EUCAST راهنمایی منتشر کرده که نقاط برش سیستمیک برای عوامل موضعی معتبر نیستند؛ برخی ECOFFها برای پایش |
| استرپتوکوک‌ها، استافیلوکوک‌ها، Enterobacterales، *P. aeruginosa* | جداول استاندارد |
| *Kingella kingae* | جدول اختصاصی |
| *Bacillus* غیر *anthracis* | جدول اختصاصی |
| *H. influenzae*، *M. catarrhalis* | جداول اختصاصی (گوش) |
| *P. aeruginosa* | «I» = دوز بالا (سیپروفلوکساسین در اوتیت بدخیم) |
