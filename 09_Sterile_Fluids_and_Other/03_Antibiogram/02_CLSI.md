# آنتی‌بیوگرام — مایعات استریل، چشم، گوش، مغز استخوان بر اساس CLSI

> **مرجع:** CLSI M100 (نسخهٔ جاری)، M11، M45. ⚠️ با نسخهٔ جاری تطبیق دهید.

## ۱. پنل بر اساس ارگانیسم و محل

| ارگانیسم/محل | پنل | نکته |
|---|---|---|
| Enterobacterales (SBP) | **سفتریاکسون/سفوتاکسیم**، سیپروفلوکساسین/لووفلوکساسین (پروفیلاکسی SBP)، TMP-SMX (پروفیلاکسی)، پیپ–تازو، ارتاپنم/مروپنم، آمیکاسین | ESBL ← کارباپنم؛ (نیتروفورانتوئین ⛔) |
| Enterobacterales + بی‌هوازی (ثانویه) | + آمپی‌سیلین–سولباکتام/پیپ–تازو، مترونیدازول (بی‌هوازی)؛ AST بی‌هوازی در شدید | |
| *S. aureus*/CoNS (PD، مفصل) | سفوکسیتین، ونکومایسین (MIC)، سفازولین (MSSA)، TMP-SMX، کلیندامایسین (+ D-test)، تتراسایکلین (⇒ داکسی)، لینزولید، ریفامپین (ترکیبی)، لووفلوکساسین | |
| استرپتوکوک‌ها (پلور، مفصل) | (پنی‌سیلین: بتا همولیتیک تست لازم نیست)، سفتریاکسون، کلیندامایسین (+ D-test)، ونکومایسین؛ گروه *anginosus*: پنی‌سیلین (MIC در موارد شدید) | |
| *S. pneumoniae* (پلور، گوش، مفصل) | نقاط برش **غیرمننژیت** | |
| *H. influenzae*/*M. catarrhalis* (گوش) | بتالاکتاماز؛ آموکسی‌سیلین/آموکسی‌کلاو، سفالوسپورین‌ها | |
| *P. aeruginosa* (قرنیه، گوش، PD) | سیپروفلوکساسین/لووفلوکساسین، سفتازیدیم، سفپیم، پیپ–تازو، مروپنم، توبرامایسین، (آمیکاسین: محدودیت جدید CLSI) | ⚠️ قطره‌ها: تذکر غلظت موضعی |
| *N. gonorrhoeae* (چشم، مفصل) | ماژول ۰۵ | |
| *B. cereus* (ویتره) | ونکومایسین، کلیندامایسین، سیپروفلوکساسین، کارباپنم، جنتامایسین (M45) | ⛔ بتالاکتام‌ها |
| *K. kingae* | بتالاکتاماز، آمپی‌سیلین، سفتریاکسون (M45) | |
| *S.* Typhi (مغز استخوان) | ماژول ۰۱ | |

### تذکر چشم و گوش
> «نقاط برش CLSI بر اساس غلظت‌های **سیستمیک** تعریف شده‌اند. غلظت داروهای **موضعی** (قطره) در قرنیه/کانال گوش بسیار بالاتر است؛ نتیجهٔ «R» لزوماً به معنای شکست درمان موضعی نیست، و «S» نیز تضمین موفقیت نیست.»

## ۲. انتخاب پنل بر اساس عوامل بیمار

### ۲-۱) سن
| گروه | ملاحظه |
|---|---|
| نوزاد (افتالمی) | سفتریاکسون (گنوکوک)؛ اریترومایسین/آزیترومایسین خوراکی (کلامیدیا) |
| کودکان (اوتیت، مفصل) | آموکسی‌سیلین/آموکسی‌کلاو، سفالوسپورین‌ها؛ ⛔ فلوروکینولون سیستمیک (قطره مجاز) |

### ۲-۲) جنس و بارداری
| وضعیت | ملاحظه |
|---|---|
| بارداری | ⛔ فلوروکینولون سیستمیک، تتراسایکلین |
| جوان فعال جنسی با آرتریت | پنل گنوکوک |

### ۲-۳) بیماری زمینه‌ای و شرایط
| شرایط | ملاحظه |
|---|---|
| **سیروز (SBP)** | پروفیلاکسی قبلی فلوروکینولون ← مقاومت؛ ESBL شایع ← کارباپنم |
| **دیالیز صفاقی** | ونکومایسین MIC؛ سفازولین؛ ضدپسودومونایی |
| **دیابت (گوش)** | *P. aeruginosa* (اوتیت بدخیم): سیپروفلوکساسین (مقاومت رو به افزایش)، سفتازیدیم، سفپیم |
| **لنز تماسی** | *P. aeruginosa*: فلوروکینولون، آمینوگلیکوزید |
| **پس از جراحی چشم** | CoNS: ونکومایسین (MIC)، (فلوروکینولون نسل ۴) |
| آلرژی بتالاکتام | ونکومایسین، فلوروکینولون، TMP-SMX، کلیندامایسین |
