# آنتی‌بیوگرام — مایعات استریل، چشم، گوش، مغز استخوان: اصول

## ۱. اصول کلی
1. AST بر اساس **ارگانیسم** (پنل‌های ماژول ۰۱) و **محل عفونت** (نفوذ دارو) انجام می‌شود.
2. **مایعات استریل:** هر پاتوژن معنی‌دار AST می‌شود (به‌جز موارد قابل پیش‌بینی مانند GAS–پنی‌سیلین).
3. **چشم:** داروهای **موضعی** نقطهٔ برش ندارند (غلظت موضعی بسیار بالاتر از سرم)؛ گزارش بر اساس نقاط برش **سیستمیک** با تذکر.
4. **گوش:** قطره‌های فلوروکینولون/آمینوگلیکوزید نیز غلظت موضعی بالا دارند؛ همان تذکر.
5. **دیالیز صفاقی:** داروها اغلب **داخل صفاقی** (IP) تجویز می‌شوند (ونکومایسین، سفازولین، سفتازیدیم، آمینوگلیکوزید)؛ نقاط برش سیستمیک.

## ۲. ملاحظات اختصاصی محل

| محل | ملاحظه |
|---|---|
| **پلور** | **آمینوگلیکوزیدها در آمپیم (pH اسیدی، چرک) غیرفعال‌اند** ← گزارش با تذکر یا سرکوب در آمپیم؛ بتالاکتام‌ها، کلیندامایسین (بی‌هوازی/*S. anginosus*)، مترونیدازول نفوذ خوب |
| **صفاق (SBP)** | سفالوسپورین نسل ۳ (سفتریاکسون/سفوتاکسیم)، فلوروکینولون (پروفیلاکسی)؛ ESBL ← کارباپنم |
| **صفاق (ثانویه)** | پوشش بی‌هوازی؛ AST بی‌هوازی‌ها در موارد شدید/مرجع |
| **PD** | ونکومایسین (MIC)، سفازولین، سفتازیدیم/سفپیم، آمینوگلیکوزید |
| **مفصل** | اغلب **خوراکی پس از دورهٔ وریدی** (OVIVA)؛ فلوروکینولون‌ها، TMP-SMX، کلیندامایسین، لینزولید |
| **چشم (کراتیت)** | قطره‌های فلوروکینولون (موکسی/گاتی)، سفازولین/توبرامایسین تقویت‌شده؛ AST سیستمیک با تذکر |
| **اندوفتالمیت** | **ونکومایسین + سفتازیدیم داخل ویتره**؛ AST ارگانیسم |
| **گوش** | اوتیت خارجی: قطرهٔ سیپروفلوکساسین/اوفلوکساسین؛ بدخیم: ضدپسودومونایی سیستمیک (سیپروفلوکساسین، سفتازیدیم، سفپیم) |
| **مغز استخوان** | *S.* Typhi: ماژول ۰۱؛ بروسلا: AST روتین نه |

## ۳. مقاومت‌های ذاتی مرتبط
| ارگانیسم | مقاوم |
|---|---|
| *B. cereus* (اندوفتالمیت) | بتالاکتام‌ها ← **ونکومایسین** (± کلیندامایسین) |
| *P. aeruginosa* (قرنیه، گوش) | (ماژول ۰۱) |
| گروه *S. anginosus* | (حساس به پنی‌سیلین، با استثناهای نادر) |
| *Enterococcus* (صفاق) | سفالوسپورین‌ها ← در پریتونیت ثانویه/ثالثیه پوشش مستقل |
| *Candida* (صفاق، PD) | خارج از دامنه (ضدقارچی) |
