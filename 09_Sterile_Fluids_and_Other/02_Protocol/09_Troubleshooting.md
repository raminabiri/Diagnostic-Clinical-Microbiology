# پروتکل ۹: خطاهای رایج و عیب‌یابی — مایعات، چشم، گوش، مغز استخوان

## ۱. پیش‌آزمایشی
| خطا | پیامد | اصلاح |
|---|---|---|
| کشت آسیت/PD فقط روی پلیت (بدون BCB) | **حساسیت پایین** (حدود ۴۰–۵۰٪) | BCB در کنار بیمار |
| فقط BCB بدون لولهٔ سلول/گرم | تفسیر SBP/PD ناممکن | دو ظرف |
| سواب از مایع | حجم کم | سرنگ/لوله |
| تأخیر شمارش سلولی | لیز ← PMN کاذب پایین | ≤ ۱ ساعت |
| لولهٔ اگزالات/پودردار برای کریستال | کریستال‌های مصنوعی | هپارین/EDTA |
| قطرهٔ آنتی‌بیوتیک پیش از خراش قرنیه | کشت منفی | نمونه پیش از درمان (یا ۱۲–۲۴ ساعت قطع طبق چشم‌پزشک) |
| سواب کانال گوش برای اوتیت میانی | فلور کانال | تمپانوسنتز |
| مغز استخوان در EDTA برای AFB | مهار برخی سیستم‌ها | هپارین/BCB مایکوباکتری |

## ۲. آزمایشی
| خطا | پیامد | اصلاح |
|---|---|---|
| عدم کشت بی‌هوازی پلور/صفاق ثانویه | از دست رفتن بی‌هوازی‌ها و *S. anginosus* | آگار بی‌هوازی |
| کشت قرنیه: تفسیر همهٔ کلنی‌ها (حتی خارج از خطوط) | گزارش آلودگی | فقط روی «C»‌ها |
| انکوباسیون کوتاه ویتره | از دست رفتن *C. acnes* | بی‌هوازی ۷–۱۴ روز |
| بدون MTM/CA برای ملتحمهٔ نوزاد | از دست رفتن گنوکوک | پنل نوزاد |
| کشت مایع مفصل کودک فقط روی SBA | از دست رفتن *K. kingae* | BCB + PCR |
| بدون میکروسکوپ پلاریزه | اشتباه کریستال | تجهیز/ارجاع |
