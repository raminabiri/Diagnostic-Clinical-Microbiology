# پروتکل ۲: انتقال، پذیرش و رد — مایعات استریل، چشم، گوش، مغز استخوان

## ۱. انتقال
| نمونه | دما | زمان |
|---|---|---|
| مایع در سرنگ/لولهٔ استریل | دمای اتاق | **≤ ۱۵ دقیقه–۲ ساعت** (گرم و سلول: ≤ ۱ ساعت) |
| مایع در **BCB** | دمای اتاق | مانند کشت خون (⛔ یخچال، ⛔ پیش‌انکوباسیون) |
| مایع مفصل برای کریستال | دمای اتاق | ≤ ۲۴ ساعت (کریستال CPPD با زمان کم می‌شود) |
| pH پلور | سرنگ گاز خون روی یخ | فوری |
| نمونه‌های چشم (پلیت‌های تلقیح‌شده) | دمای اتاق | **فوری** به انکوباتور |
| ویتره/زلالیه | دمای اتاق | **فوری** (حجم بسیار کم) |
| سواب ملتحمه/گوش (ESwab) | دمای اتاق | ≤ ۲ ساعت (تا ۲۴ ساعت در Amies) |
| کشت گنوکوک (چشم نوزاد) | دمای اتاق؛ ⛔ یخچال | فوری |
| مغز استخوان (BCB) | دمای اتاق | مانند کشت خون |

## ۲. معیار پذیرش
- **نوع مایع** و محل (پلور راست، آسیت، زانوی چپ…)
- همراه‌بودن **لولهٔ شمارش سلولی** (برای تفسیر کشت)
- بالین: سیروز، دیالیز صفاقی، پروتز، جراحی چشم، لنز تماسی، نقص ایمنی، ظن TB/بروسلا

## ۳. معیار رد و اقدام
| مشکل | اقدام |
|---|---|
| **سواب** از مایع پلور/صفاق/مفصل (وقتی مایع موجود است) | قید/رد + درخواست مایع |
| مایع در **لولهٔ حاوی ضدانعقاد** برای کشت (سیترات/اگزالات) | پردازش با قید (برخی ضدانعقادها باکتری‌کش‌اند) |
| مایع در **لولهٔ ژل‌دار/فعال‌کنندهٔ لخته** | قید |
| **فقط BCB** بدون لوله برای گرم/سلول | پردازش + پیام (تفسیر SBP/PD بدون شمارش سلولی دشوار است) |
| مایع **کیسهٔ تخلیه** (درن‌ها) | رد (کلونیزه) + درخواست نمونهٔ آسپیره |
| **سواب کانال گوش** برای اوتیت میانی | رد/قید |
| نمونهٔ چشمی دیررس | ⛔ رد نشود (غیرقابل تکرار)؛ قید |
| ⛔ نمونه‌های **ویتره، زلالیه، تمپانوسنتز، مغز استخوان** هرگز به‌علت تأخیر رد نشوند | قید |

## ۴. اولویت‌بندی حجم کم (ویتره/مفصل کودک)
1. **گرم** (یک قطره)
2. **کشت باکتری** (پلیت‌ها + BCB اطفال)
3. **PCR** (16S/اختصاصی) — باقیمانده یا قطعهٔ منجمد
4. قارچ
5. سایر
