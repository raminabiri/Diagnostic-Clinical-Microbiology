# پروتکل ۸: کنترل کیفی و ایمنی زیستی — مایعات، چشم، گوش، مغز استخوان

## ۱. QC
| مورد | کنترل |
|---|---|
| محیط‌ها | طبق ماژول‌های ۰۱، ۰۵، ۰۶ (SBA، CA، MAC، MTM، بی‌هوازی) |
| BCB | ماژول ۰۱ |
| سیتوسانتریفیوژ | کنترل کیفیت لام دوره‌ای |
| **میکروسکوپ پلاریزه** (کریستال) | لام کنترل اورات/CPPD؛ کالیبراسیون جبران‌کنندهٔ قرمز |
| شمارش سلولی مایعات | کنترل‌های مایع بدن تجاری (شمارنده)؛ لام نئوبار |
| پلیت‌های چشم (کوچک) | استریلیتی و رشد مانند محیط‌های استاندارد؛ تاریخ انقضا (در بخش چشم) |
| PCR 16S | کنترل منفی استخراج و NTC در هر ران |

## ۲. شاخص‌های کیفیت
| شاخص | هدف |
|---|---|
| درصد مایعات صفاق/PD تلقیح‌شده در BCB | بیش از ۹۰٪ |
| نرخ کشت‌منفی پریتونیت PD | **کمتر از ۱۵٪** (ISPD) |
| TAT گرم مایعات استریل | ≤ ۱ ساعت |
| درصد مایعات با لولهٔ شمارش سلولی همراه | بیش از ۹۰٪ |
| درصد سواب به‌جای مایع | کاهش |

## ۳. ایمنی زیستی ☣️
| موقعیت | الزام |
|---|---|
| مایعات عمومی | BSL-2؛ باز کردن در BSC (پاشش) |
| مغز استخوان (ظن بروسلا) | ☣️ BSC؛ کشت BSL-3/ارجاع (ماژول ۰۱) |
| مایعات با ظن TB | BSC؛ کشت BSL-3 |
| *N. gonorrhoeae* (چشم) | محافظ چشم |
| تیزها (سوزن‌های پاراسنتز/آسپیراسیون) | ظرف تیز؛ ⛔ درپوش مجدد |
