# پروتکل ۷: گزارش‌دهی — مایعات استریل، چشم، گوش، مغز استخوان

## ۱. یافته‌های نیازمند اطلاع فوری 📞
| یافته |
|---|
| **هر گرم مثبت** از مایعات استریل (مفصل، پلور، صفاق، پریکارد) |
| **فلور مخلوط در گرم مایع صفاق** (پریتونیت ثانویه/پرفوراسیون) |
| **هر رشد** در ویتره/زلالیه؛ **گرم مثبت** ویتره (به‌ویژه *B. cereus*) |
| **دیپلوکوک گرم منفی** در ملتحمهٔ نوزاد/بزرگسال (گنوکوک) |
| گرم مثبت قرنیه (کراتیت) |
| *Brucella*، *S.* Typhi در مغز استخوان (+ بهداشت) |
| AFB/Xpert مثبت در هر مایع |
| کشت مثبت مایع مفصل/صفاق/پلور (اولین) |

## ۲. جملات استاندارد
| موقعیت | جمله |
|---|---|
| SBP | «*Escherichia coli* از مایع آسیت (بطری کشت خون). PMN آسیت: ۸۰۰/µL؛ سازگار با پریتونیت باکتریایی خودبه‌خودی.» |
| پریتونیت ثانویه | «رشد چندمیکروبی (*E. coli*، *Enterococcus faecalis*، *Bacteroides fragilis* group)؛ مطرح‌کنندهٔ پریتونیت ثانویه (پرفوراسیون/آبسه).» |
| فقط BCB بدون سلول | «شمارش سلولی ارسال نشده؛ تفسیر کشت مایع صفاق بدون PMN محدود است.» |
| مفصل با کریستال | «کریستال‌های اورات دیده شد. وجود کریستال، آرتریت سپتیک هم‌زمان را رد نمی‌کند؛ کشت در جریان است.» |
| کشت منفی مفصل جوان | «کشت منفی؛ در ظن آرتریت گنوکوکی، کشت/NAAT از سرویکس/اورترا/حلق/رکتوم توصیه می‌شود.» |
| قرنیه | «*P. aeruginosa* روی خطوط تلقیح (رشد معنی‌دار).» |
| ملتحمهٔ نوزاد | «*N. gonorrhoeae* جدا شد. بررسی و درمان مادر و شریک.» |
| گوش (سواب کانال برای OM) | «سواب کانال خارجی برای تشخیص اوتیت میانی مناسب نیست (فلور کانال).» |

## ۳. نمونهٔ گزارش (پریتونیت PD)
```
نمونه: افلوئنت دیالیز صفاقی (کدر) — ماندگاری ۴ ساعت
شمارش: WBC ۱۲۰۰/µL، PMN ۸۵٪
گرم: PMN فراوان؛ کوکسی گرم مثبت خوشه‌ای کم
کشت (BCB هوازی، ۱۸ ساعت): Staphylococcus epidermidis
آنتی‌بیوگرام:
  اکساسیلین (سفوکسیتین)  R
  ونکومایسین (MIC)       1     S
  ریفامپین              S
  TMP-SMX              S
  لینزولید              S
توضیح: سازگار با پریتونیت مرتبط با دیالیز صفاقی (معیارهای ISPD).
```
