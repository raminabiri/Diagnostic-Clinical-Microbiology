# جداول استاندارد تشخیص عفونت خون — از انتخاب بیمار تا گزارش نهایی

در ادامه، تمامی جداول استاندارد موردنیاز برای راه‌اندازی و اجرای سرویس کشت خون را در ۱۰ بخش ارائه می‌دهم. این جداول بر اساس CLSI M47 (نمونه‌گیری)، CLSI M100 Ed36 (آنتی‌بیوگرام)، CDC (کنترل کیفیت)، و EUCAST تدوین شده‌اند.

---

## بخش ۱: انتخاب بیمار و اندیکاسیون‌های کشت خون

### جدول ۱-۱: اندیکاسیون‌های کشت خون در بزرگسالان

| اندیکاسیون | توضیح | اولویت |
| :--- | :--- | :--- |
| تب ≥۳۸٫۳°C یا هیپوترمی <۳۶°C | همراه با لرز، تاکی‌کاردی، یا افت فشار | بالا |
| شوک سپتیک | افت فشار نیازمند وازوپرسور + لاکتات >۲ mmol/L | بسیار بالا |
| نوتروپنی با تب | ANC <۵۰۰/µL + تب ≥۳۸°C | بسیار بالا |
| کاتتر مرکزی با علائم عفونت | تب، لرز، قرمزی یا ترشح از محل کاتتر | بالا |
| اندوکاردیت مشکوک | سوفل جدید، آمبولی، کشت خون مثبت مکرر | بسیار بالا |
| پنومونی شدید | نیاز به ICU، نارسایی تنفسی | بالا |
| پیلونفریت پیچیده | تب + درد پهلو + سپسیس | بالا |
| عفونت داخل‌شکمی | پریتونیت، آبسه، کولانژیت | بالا |
| مننژیت باکتریال | سفتی گردن، اختلال هوشیاری، پتشی | بسیار بالا |
| استئومیلیت/دیسکیت | تب + درد موضعی + کشت خون مثبت | متوسط |
| عفونت پروتز/گرافت | تب + درد موضعی + کشت خون مثبت | بالا |
| نوزادان با تب یا هیپوترمی | سن <۲۸ روز + تب ≥۳۸°C یا <۳۶°C | بسیار بالا |

### جدول ۱-۲: مواردی که کشت خون توصیه نمی‌شود

| وضعیت | توضیح | دلیل |
| :--- | :--- | :--- |
| تب خفیف بدون علائم سیستمیک | تب <۳۸°C، بیمار پایدار | احتمال BSI پایین |
| عفونت ویروسی تأییدشده | آنفولانزا، RSV، کووید-۱۹ | کشت خون مثبت نمی‌شود |
| عفونت موضعی بدون سپسیس | سلولیت محدود، اوتیت میانی | BSI بعید است |
| بیمار با کشت‌های مکرراً منفی | ≥۳ ست کشت منفی در ۴۸ ساعت | Yield بسیار پایین |
| التهاب غیرعفونی | پانکراتیت، لوپوس، درگ فیور | کشت خون مثبت نمی‌شود |
