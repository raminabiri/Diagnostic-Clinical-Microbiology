# تئوری: عفونت‌های باکتریایی دستگاه گوارش

## ۱. سندرم‌ها

| سندرم | تعریف/ویژگی | عوامل باکتریایی اصلی |
|---|---|---|
| **اسهال آبکی حاد** | بیش از ۳ بار مدفوع شل در ۲۴ ساعت، بدون خون؛ اغلب خودمحدود | ETEC (اسهال مسافران)، EPEC (شیرخواران)، EAEC، *V. cholerae*، *C. perfringens*، *B. cereus*؛ (اغلب ویروسی) |
| **اسهال خونی (دیسانتری)/التهابی** | خون و موکوس، تب، تنسموس، لکوسیت/لاکتوفرین مثبت | ***Shigella***، ***Campylobacter***، ***Salmonella*** غیرتیفوئیدی، **STEC** (بدون تب بارز)، EIEC، *Yersinia*، *C. difficile*؛ (انگل: *E. histolytica*) |
| **تب روده‌ای** | تب طول‌کشیده، اغلب بدون اسهال | *S.* Typhi/Paratyphi (ماژول ۰۱: کشت خون) |
| **اسهال مرتبط با آنتی‌بیوتیک / CDI** | اسهال در بیمار با مصرف اخیر آنتی‌بیوتیک/بستری؛ تا کولیت پسودوممبرانو و مگاکولون توکسیک | ***C. difficile*** (۱۵–۲۵٪ اسهال مرتبط با آنتی‌بیوتیک) |
| **مسمومیت غذایی توکسینی** | شروع سریع (۱–۶ ساعت: استفراغ؛ ۸–۱۶ ساعت: اسهال) پس از غذای مشترک | *S. aureus* (انتروتوکسین از پیش‌ساخته)، *B. cereus* (امتیک/اسهالی)، *C. perfringens*، *C. botulinum* (عصبی) |
| **سندرم همولیتیک–اورمیک (HUS)** | کم‌خونی همولیتیک میکروآنژیوپاتیک + ترومبوسیتوپنی + نارسایی کلیه، ۵–۱۳ روز پس از اسهال (اغلب خونی) | **STEC** (O157:H7 و غیر O157)، *S. dysenteriae* نوع ۱ |
| **گاستریت/زخم پپتیک** | مزمن | ***H. pylori*** |
| **پسودوآپاندیسیت/لنفادنیت مزانتر** | | *Yersinia enterocolitica* |
| **ورود کلونیزاسیون مقاوم** | بدون بیماری؛ کنترل عفونت | CRE، VRE، ESBL |

## ۲. عوامل بر اساس سرنخ بالینی/اپیدمیولوژیک

| سرنخ | عوامل محتمل |
|---|---|
| مرغ نیم‌پز، تخم‌مرغ، لبنیات غیرپاستوریزه | *Salmonella*، *Campylobacter* |
| همبرگر نیم‌پز، سبزیجات خام، شیر خام، تماس با دام | **STEC** |
| مهدکودک، مردان دارای رابطهٔ جنسی با مردان (MSM)، شیوع در جمعیت متراکم | ***Shigella*** (دوز عفونی بسیار کم: ۱۰–۱۰۰ ارگانیسم) |
| غذای دریایی خام، آب شور | *V. parahaemolyticus*، *V. vulnificus*، *Plesiomonas*، *Aeromonas* |
| آب آلوده، شیوع اسهال آبکی شدید (برنج‌آب) | ***V. cholerae*** O1/O139 |
| گوشت خوک، شیر، پسودوآپاندیسیت، اضافه‌بار آهن | *Y. enterocolitica* |
| برنج سرخ‌کرده (استفراغ ۱–۶ ساعت) | *B. cereus* امتیک |
| گوشت پخته‌شده در حجم زیاد و نگهداری گرم (اسهال ۸–۱۶ ساعت) | *C. perfringens* |
| سالاد، شیرینی خامه‌ای (استفراغ ۱–۶ ساعت) | *S. aureus* |
| آنتی‌بیوتیک اخیر (به‌ویژه کلیندامایسین، فلوروکینولون، سفالوسپورین)، بستری، PPI | ***C. difficile*** |
| سفر به کشورهای کم‌درآمد | ETEC، *Campylobacter*، *Shigella*، *Salmonella*، تیفوئید |
| نقص ایمنی، HIV | *Salmonella* (باکتریمی)، *Campylobacter*، *C. difficile*، MAC (خارج از دامنه) |

## ۳. پاتوژنز (خلاصه)

| مکانیسم | مثال |
|---|---|
| **توکسین از پیش‌ساخته در غذا** | *S. aureus*، *B. cereus* امتیک (سرولید) ← شروع سریع، بدون تب |
| **انتروتوکسین (ترشحی)** | *V. cholerae* (CT)، ETEC (LT/ST) ← اسهال آبکی |
| **تهاجم به مخاط** | *Shigella*، EIEC، *Campylobacter*، *Salmonella* ← اسهال التهابی |
| **سیتوتوکسین** | STEC (Stx1/Stx2؛ **Stx2** با HUS مرتبط‌تر است)، *C. difficile* (TcdA/TcdB، ± توکسین دوتایی در سویه ۰۲۷) |
| **چسبندگی (Attaching–effacing)** | EPEC، STEC (ژن *eae*) |
| **تهاجم سیستمیک** | *S.* Typhi، *Salmonella* در نقص ایمنی، *Y. enterocolitica* |

## ۴. علائم و شدت
- **علائم هشدار:** تب ≥ ۳۸٫۵ °C، اسهال خونی، دهیدراتاسیون شدید، درد شکم شدید، بیش از ۷ روز، سن بیش از ۶۵ یا کمتر از ۶ ماه، نقص ایمنی، بارداری، شیوع (Outbreak).
- **CDI شدید:** لکوسیتوز ≥ ۱۵٬۰۰۰/µL یا کراتینین بیش از ۱٫۵ mg/dL؛ **فولمینانت:** افت فشار، ایلئوس، مگاکولون.
- **HUS:** کاهش ادرار، رنگ‌پریدگی، پتشی، چند روز پس از اسهال؛ کاهش پلاکت و شیستوسیت‌ها در گسترش خون.

## ۵. تشخیص بالینی و زمان درخواست آزمایش

| موقعیت | آزمایش |
|---|---|
| اسهال آبکی کمتر از ۷ روز بدون علائم هشدار | **معمولاً آزمایش لازم نیست** (IDSA 2017) |
| اسهال خونی، تب، علائم هشدار، شیوع، کارکنان غذا/بهداشت/مهدکودک | کشت مدفوع (یا پنل مولکولی) **+ شیگاتوکسین/STEC** |
| بستری بیش از ۳ روز با اسهال جدید | **فقط *C. difficile*** (قانون ۳ روز) |
| ≥ ۳ مدفوع شل در ۲۴ ساعت + آنتی‌بیوتیک/بستری اخیر | *C. difficile* |
| تب طول‌کشیده | کشت خون (تیفوئید)، ± مدفوع |
| دیس‌پپسی/زخم | *H. pylori*: تست تنفسی اوره (UBT) یا آنتی‌ژن مدفوع؛ در آندوسکوپی: بیوپسی (تست اوره‌آز سریع، بافت‌شناسی، کشت/PCR در مقاومت) |
| مسمومیت غذایی گروهی | مدفوع و غذا (آزمایشگاه بهداشت/مرجع)؛ گزارش به بهداشت |
| شیوع اسهال آبکی شدید (ظن وبا) | 📞 بهداشت + کشت TCBS/APW + تست سریع |

## ۶. درمان (برای آگاهی آزمایشگاه)
- بیشتر اسهال‌ها: آبرسانی؛ آنتی‌بیوتیک لازم نیست.
- *Shigella*: آزیترومایسین، سیپروفلوکساسین یا سفتریاکسون (بر اساس حساسیت؛ مقاومت گسترده).
- *Campylobacter*: آزیترومایسین (در شدید/پرخطر).
- *Salmonella* غیرتیفوئیدی: درمان **فقط** در پرخطرها (شیرخوار کمتر از ۳ ماه، بیش از ۵۰–۶۵ سال با بیماری عروقی، نقص ایمنی، پروتز، شدید). درمان در سایرین حامل‌بودن را طولانی می‌کند.
- ⛔ **STEC: آنتی‌بیوتیک توصیه نمی‌شود** (احتمال افزایش خطر HUS)؛ ضدحرکت‌های روده هم نه.
- *C. difficile*: فیداکسومایسین یا ونکومایسین خوراکی؛ مترونیدازول فقط در نبود دسترسی (IDSA/SHEA 2021).
- *H. pylori*: رژیم‌های چهاردارویی (بیسموت) یا بر اساس آنتی‌بیوگرام/مقاومت کلاریترومایسین.
