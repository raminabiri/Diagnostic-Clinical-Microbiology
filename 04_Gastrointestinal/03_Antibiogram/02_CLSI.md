# آنتی‌بیوگرام پاتوژن‌های گوارشی بر اساس CLSI

> **مرجع:** CLSI M100 (Enterobacterales، بخش *Salmonella*/*Shigella*)، **M45** (*Campylobacter*، *Vibrio*، *Aeromonas*، *Plesiomonas*، *H. pylori*)، M11 (بی‌هوازی).
> ⚠️ با نسخهٔ جاری تطبیق دهید.

## ۱. پنل بر اساس ارگانیسم

| ارگانیسم | پنل CLSI | ⛔ گزارش نشود | نکته |
|---|---|---|---|
| ***Shigella*** (مدفوع) | آمپی‌سیلین، **سیپروفلوکساسین/لووفلوکساسین**، **TMP-SMX**، **سفتریاکسون**، **آزیترومایسین** (فقط **ECV**: *S. flexneri* ≤ 16، *S. sonnei* ≤ 8 = جمعیت وحشی) | آمینوگلیکوزیدها، سفالوسپورین نسل ۱–۲، سفامایسین | آزیترومایسین «NWT» (غیروحشی) ← احتمال شکست درمان |
| ***Salmonella*** غیرتیفوئیدی (مدفوع، پرخطر) | آمپی‌سیلین، سیپروفلوکساسین (**نقاط برش *Salmonella***)، TMP-SMX، ± سفتریاکسون، آزیترومایسین | همان | |
| *Salmonella* خارج‌روده‌ای / *S.* Typhi / Paratyphi | + **سفتریاکسون**، **آزیترومایسین** (*S.* Typhi: S ≤ 16، R ≥ 32)، کلرامفنیکل، مروپنم (XDR) | همان | ماژول ۰۱ |
| ***Campylobacter jejuni/coli*** (M45) | **اریترومایسین** (پیش‌بینی آزیترومایسین)، **سیپروفلوکساسین**، تتراسایکلین/داکسی‌سایکلین | TMP-SMX، بتالاکتام‌ها | مقاومت به فلوروکینولون اغلب بیش از ۵۰٪ (جنوب و جنوب‌شرق آسیا تا بیش از ۸۰٪) |
| ***V. cholerae*** (M45) | آمپی‌سیلین، **تتراسایکلین** (پیش‌بینی داکسی‌سایکلین)، TMP-SMX، سولفونامید، کلرامفنیکل، سیپروفلوکساسین، آزیترومایسین | | داکسی‌سایکلین تک‌دوز، آزیترومایسین (کودکان و بارداری) |
| *Vibrio* غیر وبا (M45) | سفوتاکسیم/سفتازیدیم، سیپروفلوکساسین/لووفلوکساسین، تتراسایکلین، TMP-SMX، آمیکاسین | آمپی‌سیلین (*V. parahaemolyticus*) | *V. vulnificus* (زخم/سپسیس): داکسی‌سایکلین + سفتازیدیم |
| ***Aeromonas*** (M45) | سفپیم، سفتریاکسون، سیپروفلوکساسین، TMP-SMX، آمیکاسین/جنتامایسین، (کارباپنم با تذکر CphA) | آمپی‌سیلین، سفازولین | |
| *Plesiomonas* (M45) | سفتریاکسون، سیپروفلوکساسین، TMP-SMX | آمپی‌سیلین | |
| *Y. enterocolitica* (M100 Enterobacterales) | TMP-SMX، سیپروفلوکساسین، سفتریاکسون، داکسی‌سایکلین، جنتامایسین (سیستمیک) | آمپی‌سیلین، آموکسی‌کلاو، سفازولین | |
| ***H. pylori*** (M45) | **فقط کلاریترومایسین** نقطهٔ برش CLSI دارد (آگار دایلوشن: S ≤ 0.25، I = 0.5، R ≥ 1) | | سایر داروها: از EUCAST استفاده کنید (فایل EUCAST) یا MIC بدون تفسیر |
| *C. difficile* (M11) | مترونیدازول (بی‌هوازی)؛ ونکومایسین و فیداکسومایسین نقطهٔ برش CLSI ندارند | | فقط مرجع |

## ۲. نقاط برش سیپروفلوکساسین *Salmonella* (CLSI)

| روش | S | I | R |
|---|---|---|---|
| MIC (µg/mL) | ≤ 0.06 | 0.12–0.5 | ≥ 1 |
| دیسک ۵ µg (mm) | ≥ 31 | 21–30 | ≤ 20 |

> نالیدیکسیک اسید (غربالگری قدیمی) **حذف شده** و به‌تنهایی کافی نیست.

## ۳. انتخاب پنل بر اساس عوامل بیمار

### ۳-۱) سن

| گروه | ملاحظه |
|---|---|
| شیرخوار کمتر از ۳ ماه | *Salmonella* غیرتیفوئیدی **درمان می‌شود** ← AST کامل (آمپی‌سیلین، سفتریاکسون، آزیترومایسین، TMP-SMX) |
| کودکان | *Shigella*: آزیترومایسین، سفتریاکسون، سیپروفلوکساسین (WHO استفاده در کودکان را برای شیگلوز می‌پذیرد)؛ وبا: آزیترومایسین؛ ⛔ تتراسایکلین (کمتر از ۸ سال، جز داکسی‌سایکلین کوتاه‌مدت) |
| بیش از ۵۰–۶۵ سال با بیماری عروقی/پروتز | *Salmonella* درمان (خطر آئورتیت عفونی) ← AST |

### ۳-۲) جنس و بارداری

| وضعیت | ملاحظه |
|---|---|
| بارداری | ⛔ فلوروکینولون، تتراسایکلین؛ گزارش **آزیترومایسین، سفتریاکسون، آمپی‌سیلین**؛ *Listeria* را در نظر بگیرید |
| MSM | *Shigella* **XDR** (مقاوم به سیپروفلوکساسین، آزیترومایسین، TMP-SMX، سفتریاکسون) ← پنل کامل + کارباپنم + اطلاع به بهداشت |

### ۳-۳) بیماری زمینه‌ای و شرایط

| شرایط | ملاحظه |
|---|---|
| نقص ایمنی، HIV، پیوند، شیمی‌درمانی | *Salmonella*، *Campylobacter*: درمان و AST |
| سیکل‌سل، آسپلنی | *Salmonella* (استئومیلیت) |
| سیروز | *Vibrio vulnificus* |
| مسافرت (جنوب آسیا) | *Campylobacter* FQ-R؛ *Shigella*/*Salmonella* XDR؛ *S.* Typhi XDR |
| شکست درمان *H. pylori* | کشت + AST (کلاریترومایسین، مترونیدازول، آموکسی‌سیلین، لووفلوکساسین، تتراسایکلین، ریفابوتین) |
| CDI عودکننده | AST روتین نه؛ مرجع برای پایش |

## ۴. قوانین LIS
1. *Salmonella*/*Shigella* ⇒ سرکوب آمینوگلیکوزیدها، سفالوسپورین نسل ۱–۲، سفامایسین‌ها.
2. *Salmonella* ⇒ نقاط برش اختصاصی فلوروکینولون.
3. *Shigella* ⇒ آزیترومایسین با ECV و جملهٔ «WT/NWT».
4. *Campylobacter* ⇒ سرکوب TMP-SMX و بتالاکتام‌ها.
5. *Y. enterocolitica* ⇒ سرکوب آمپی‌سیلین، آموکسی‌کلاو، سفازولین.
6. *Aeromonas* ⇒ کارباپنم با تذکر CphA.
7. STEC ⇒ بدون AST (جملهٔ عدم درمان).
