# پروتکل ۷: گزارش‌دهی نتایج گوارشی

## ۱. اصول
1. نتیجهٔ منفی باید **دامنهٔ بررسی‌شده** را ذکر کند.
2. پاتوژن‌های روده‌ای اغلب **واجب‌الگزارش**اند ← هم پزشک، هم مرکز بهداشت.
3. نتایج مولکولی: **تفسیر کلونیزاسیون** و انجام **کشت بازتابی**.
4. آنتی‌بیوگرام **فقط** وقتی درمان مطرح است (فایل آنتی‌بیوگرام).

## ۲. مقادیر/یافته‌های نیازمند اطلاع فوری 📞

| یافته | گیرندهٔ اطلاع |
|---|---|
| ***V. cholerae* O1/O139** (یا RDT مثبت در شیوع) | پزشک + **مرکز بهداشت (فوری)** |
| **STEC / شیگاتوکسین مثبت** | پزشک (خطر HUS؛ اجتناب از آنتی‌بیوتیک) + بهداشت |
| *S.* Typhi/Paratyphi | پزشک + بهداشت |
| *Shigella* (به‌ویژه *S. dysenteriae*) | پزشک + بهداشت |
| *Salmonella* یا *Shigella* در کارکنان غذا، مهدکودک، کادر درمان | بهداشت |
| **خوشه** از یک پاتوژن (شیوع محتمل) | بهداشت + کنترل عفونت |
| *C. difficile* مثبت در بیمار بستری | کنترل عفونت (احتیاطات تماسی) |
| CRE در غربالگری | کنترل عفونت |
| ظن **بوتولیسم** | 📞 فوری (پزشک، بهداشت، مرجع) |

## ۳. جملات استاندارد

| موقعیت | جمله |
|---|---|
| منفی | «*Salmonella*، *Shigella*، *Campylobacter* و *E. coli* O157 جدا نشد. شیگاتوکسین شناسایی نشد.» |
| *Salmonella* | «*Salmonella* سروگروه D جدا شد (سروتایپ در آزمایشگاه مرجع). در گاستروانتریت بدون عارضه درمان آنتی‌بیوتیکی معمولاً توصیه نمی‌شود، مگر در بیماران پرخطر.» |
| *Shigella* | «*Shigella sonnei* (گروه D). آنتی‌بیوگرام پیوست.» |
| *Campylobacter* | «*Campylobacter jejuni*.» |
| STEC | «***E. coli* تولیدکنندهٔ شیگاتوکسین (STEC)** O157 / Stx2 شناسایی شد. ⚠️ درمان آنتی‌بیوتیکی و ضدحرکت روده توصیه نمی‌شود (افزایش خطر HUS). پایش علائم HUS. بیماری واجب‌الگزارش؛ ایزوله به آزمایشگاه مرجع ارسال شد.» |
| *C. difficile* Tox+ | «توکسین *C. difficile* شناسایی شد.» |
| *C. difficile* NAAT+/Tox– | «ژن توکسین *C. difficile* (سویهٔ توکسیژنیک) شناسایی شد، ولی توکسین آزاد شناسایی نشد. ممکن است بیانگر **کلونیزاسیون** یا CDI باشد؛ تفسیر بر اساس بالین.» |
| *C. difficile* رد نمونهٔ فرم‌دار | «نمونه شکل‌دار است؛ آزمایش *C. difficile* فقط روی مدفوع شل انجام می‌شود.» |
| قانون ۳ روز | «بیمار بیش از ۳ روز بستری است؛ کشت روتین مدفوع بازده ندارد. آزمایش *C. difficile* پیشنهاد می‌شود. در صورت شرایط خاص (شیوع، نقص ایمنی) با آزمایشگاه تماس بگیرید.» |
| پنل مولکولی EPEC | «*E. coli* انتروپاتوژن (EPEC) شناسایی شد. اهمیت بالینی در بزرگسالان نامشخص است.» |
| *H. pylori* آنتی‌ژن + | «آنتی‌ژن *H. pylori* در مدفوع: مثبت (عفونت فعال).» |
| *H. pylori* ریشه‌کنی | «برای تأیید ریشه‌کنی، آزمایش حداقل ۴ هفته پس از پایان درمان و ۲ هفته پس از قطع PPI انجام شود. سرولوژی برای این منظور مناسب نیست.» |
| غربالگری CRE | «*Klebsiella pneumoniae* مقاوم به کارباپنم (OXA-48) در سواب رکتال: **کلونیزاسیون**؛ احتیاطات تماسی.» |

## ۴. نمونهٔ گزارش

```
آزمایشگاه میکروب‌شناسی — کشت مدفوع
---------------------------------------------------------------
بیمار: [نام]  سن/جنس: ۶ سال/دختر  بخش: اورژانس اطفال
نمونه: مدفوع (Cary-Blair)  ظاهر: خونی–موکوسی
بالین: اسهال خونی ۳ روزه، بدون تب

لاکتوفرین: مثبت
شیگاتوکسین (EIA روی براث GN): مثبت  [📞 ۱۴:۲۰ به دکتر … — بازخوانی]

کشت:
  SMAC: کلنی‌های سوربیتول منفی، آگلوتیناسیون O157 مثبت
  شناسایی: Escherichia coli O157 (H7: در آزمایشگاه مرجع)
  Salmonella، Shigella، Campylobacter: جدا نشد

توضیحات:
  ⚠️ آنتی‌بیوتیک و داروهای ضدحرکت روده توصیه نمی‌شوند.
  پایش CBC (پلاکت، شیستوسیت) و کراتینین برای سندرم همولیتیک–اورمیک.
  مورد به مرکز بهداشت گزارش شد؛ ایزوله به آزمایشگاه مرجع ارسال شد.
  آنتی‌بیوگرام انجام نشد (درمان آنتی‌بیوتیکی اندیکاسیون ندارد).
```
