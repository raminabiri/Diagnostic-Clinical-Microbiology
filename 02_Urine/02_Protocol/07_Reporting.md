# پروتکل ۷: گزارش‌دهی کشت ادرار

## ۱. اصول
1. **نوع نمونه** در گزارش ذکر شود.
2. **شمارش به‌صورت دسته‌ای** (CFU/mL) برای هر ارگانیسم.
3. **نام کامل** ارگانیسم‌های معنی‌دار؛ فلور با عبارت کلی.
4. **گزارش انتخابی آنتی‌بیوتیک‌ها** بر اساس ارگانیسم و ترجیحاً سندرم (سیستیت در برابر پیلونفریت/سیستمیک).
5. **جملات تفسیری** برای کمک به تصمیم و جلوگیری از درمان ASB.

## ۲. زمان‌بندی

| مرحله | زمان | محتوا |
|---|---|---|
| غربالگری/بررسی مستقیم | همان روز | پیوری، باکتری، گرم (در صورت انجام) |
| کشت اولیه | ۱۸–۲۴ ساعت | «رشد/عدم رشد» + شناسایی احتمالی و CFU |
| نهایی | ۲۴–۷۲ ساعت | شناسایی + AST |

## ۳. مقادیر/یافته‌های نیازمند اطلاع فوری 📞
- ارگانیسم با **مقاومت مهم** در بیمار بستری: **CRE**، VRE، *A. baumannii* مقاوم به کارباپنم (+ کنترل عفونت)
- *S. aureus* در ادرار بیمار تب‌دار بدون کاتتر (پیشنهاد کشت خون)
- *Salmonella* Typhi/Paratyphi
- نتیجه‌ای که با درمان فعلی بیمار بستری **مقاوم** است (طبق سیاست محلی)
- (CLSI/CAP: کشت ادرار معمولاً مقدار بحرانی تلفنی ندارد، مگر موارد بالا)

## ۴. جملات استاندارد

| موقعیت | جمله |
|---|---|
| بدون رشد | «پس از ۲۴ ساعت رشدی مشاهده نشد (< ۱۰³ CFU/mL).» (با لوپ ۱۰ µL: «< ۱۰² CFU/mL») |
| رشد معنی‌دار | «*Escherichia coli* ≥ ۱۰⁵ CFU/mL.» |
| شمارش پایین با اهمیت بالقوه | «*E. coli* ۱۰³–۱۰⁴ CFU/mL. در بیمار علامت‌دار (سیستیت یا مرد) ممکن است معنی‌دار باشد.» |
| آلودگی | «**رشد مخلوط ≥ ۳ نوع ارگانیسم** بدون غلبهٔ آشکار؛ احتمال آلودگی نمونه. در صورت تداوم علائم، نمونهٔ جدید با روش صحیح ارسال شود.» |
| فلور | «فلور ادراری–تناسلی (< ۱۰⁴ CFU/mL).» |
| نمونهٔ کیسه کودک | «نمونه با کیسهٔ ادراری گرفته شده است. **نتیجهٔ منفی UTI را با احتمال بالا رد می‌کند**، ولی نتیجهٔ مثبت باید با نمونهٔ کاتتر یا SPA تأیید شود.» |
| سلول سنگفرشی فراوان | «سلول‌های اپی‌تلیال سنگفرشی فراوان: احتمال آلودگی.» |
| ASB (بیمار بدون علامت، غیرباردار) | «در صورت نبود علائم ادراری، این یافته **باکتریوری بدون علامت** است و درمان آنتی‌بیوتیکی (به‌جز بارداری و پیش از جراحی اورولوژیک) توصیه نمی‌شود (IDSA 2019).» |
| کاتتر | «نمونه از کاتتر ادراری دائم. باکتریوری در کاتتر طولانی‌مدت شایع است؛ تفسیر فقط با علائم بالینی.» |
| *S. aureus* | «*Staphylococcus aureus* در ادرار بدون کاتتر ممکن است ناشی از باکتریمی باشد؛ کشت خون توصیه می‌شود.» |
| GBS در بارداری | «*Streptococcus agalactiae* (گروه B) ≥ ۱۰⁴ CFU/mL. باکتریوری GBS در بارداری نشانهٔ کلونیزاسیون شدید است؛ پروفیلاکسی حین زایمان توصیه می‌شود.» |
| نیتروفورانتوئین/فسفومایسین | «**فقط برای سیستیت (UTI تحتانی)**؛ برای پیلونفریت، باکتریمی یا پروستاتیت مناسب نیست.» |
| *P. mirabilis* مکرر | «ارگانیسم اوره‌آز مثبت؛ ارزیابی سنگ/انسداد در صورت عود.» |
| آنتی‌بیوتیک قبلی | «رشد کم/مهارشده؛ با توجه به مصرف آنتی‌بیوتیک، تفسیر با احتیاط.» |

## ۵. نمونهٔ گزارش‌ها

### الف) سیستیت ساده (زن ۲۸ ساله)
```
نمونه: ادرار میانی تمیز (MSU)       آزمایش مستقیم: WBC ۲۵–۳۰/HPF؛ باکتری فراوان
کشت: Escherichia coli  ≥ ۱۰⁵ CFU/mL

آنتی‌بیوگرام (CLSI M100، نسخهٔ جاری):
  نیتروفورانتوئین              S   (فقط سیستیت)
  فسفومایسین                   S   (فقط سیستیت)
  تری‌متوپریم–سولفامتوکسازول     R
  سفازولین (جانشین سفالوسپورین‌های خوراکی در UTI ساده)   S
  آموکسی‌سیلین–کلاوولانات       S
  سیپروفلوکساسین               R
```

### ب) پیلونفریت (مرد ۶۰ ساله، تب) — همان *E. coli* ESBL
```
کشت: Escherichia coli ≥ ۱۰⁵ CFU/mL — تولیدکنندهٔ ESBL
  سفتریاکسون                    R
  پیپراسیلین–تازوباکتام          S
  ارتاپنم                        S
  مروپنم                        S
  جنتامایسین                    S
  آمیکاسین                      S
  سیپروفلوکساسین               R
  تری‌متوپریم–سولفامتوکسازول     R
توضیح: نیتروفورانتوئین و فسفومایسین (خوراکی) برای پیلونفریت/پروستاتیت مناسب نیستند و گزارش نشده‌اند.
پیشنهاد: کشت خون در صورت تب.
```

## ۶. گزارش اصلاحی
مانند سایر ماژول‌ها: برچسب «اصلاحیه»، نتیجهٔ قبلی و جدید، تماس با پزشک، ثبت عدم انطباق.
