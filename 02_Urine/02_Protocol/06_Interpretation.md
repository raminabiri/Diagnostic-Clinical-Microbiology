# پروتکل ۶: تفسیر کشت ادرار

## ۱. سه پرسش محوری
1. **نوع نمونه** چیست؟ (MSU، کاتتر، SPA، کیسه)
2. **سندرم بالینی** چیست؟ (بدون علامت، سیستیت، پیلونفریت، CAUTI، کودک تب‌دار، بارداری)
3. **ارگانیسم(ها)** چه هستند و چند نوع؟ (اوروپاتوژن اولیه، ثانویه، یا فلور)

## ۲. دسته‌بندی ارگانیسم‌ها

| گروه | ارگانیسم‌ها |
|---|---|
| **اوروپاتوژن اولیه** | *E. coli*، *S. saprophyticus* (در زنان جوان)، *Salmonella* (هر تعداد گزارش شود) |
| **اوروپاتوژن ثانویه** | *Klebsiella*، *Enterobacter*، *Citrobacter*، *Proteus*، *Morganella*، *Serratia*، *P. aeruginosa*، *Enterococcus*، *S. aureus*، GBS، *Aerococcus urinae*، *C. urealyticum* |
| **مشکوک/معمولاً فلور** | CoNS (غیر *saprophyticus*)، استرپتوکوک‌های ویریدانس، *Lactobacillus*، *Corynebacterium* (غیر *urealyticum*)، *Gardnerella*، *Bifidobacterium*، بی‌هوازی‌ها |

## ۳. آستانه‌های معنی‌دار (CFU/mL)

| موقعیت | نمونه | آستانه | منبع |
|---|---|---|---|
| **سیستیت حاد در زن** | MSU | **≥ ۱۰³** اوروپاتوژن (حتی ≥ ۱۰² کلیفرم در مطالعات کلاسیک) | IDSA / ASM؛ Stamm |
| **پیلونفریت حاد** | MSU | **≥ ۱۰⁴** | IDSA |
| **UTI علامت‌دار در مرد** | MSU | **≥ ۱۰³** | IDSA |
| **ASB در زن** (مثلاً بارداری) | MSU | **≥ ۱۰⁵** همان ارگانیسم در **دو نمونهٔ متوالی** (در عمل بسیاری از مراکز بارداری را با یک نمونه می‌سنجند) | IDSA 2019 |
| ASB در مرد | MSU | ≥ ۱۰⁵ در یک نمونه | IDSA 2019 |
| ASB در نمونهٔ کاتتر | کاتتر | ≥ ۱۰² | IDSA 2019 |
| **CAUTI** (بیمار علامت‌دار) | کاتتر | **≥ ۱۰³** | IDSA 2009 |
| **کودک ۲–۲۴ ماه** | کاتتر یا SPA | **≥ ۵۰٬۰۰۰** یک اوروپاتوژن + **پیوری/باکتریوری** در آزمایش ادرار | AAP 2011/2016 |
| کودک (اروپا) | MSU تمیز | ≥ ۱۰⁵ (برخی ≥ ۱۰⁴ با علائم) | EAU/NICE |
| | کاتتر | ≥ ۱۰³–۱۰⁴ | |
| **SPA (هر سن)** | SPA | **هر رشدی** از اوروپاتوژن (حتی ۱۰²) | |
| سیستوسکوپی/نفروستومی | | هر رشد معنی‌دار با بالین | |
| **GBS در بارداری** | MSU | **گزارش در شمارش پایین** (≥ ۱۰⁴ طبق ASM؛ برخی راهنماها هر شمارش) | CDC/ACOG |

> ⚠️ **آستانه بدون بالین معنی ندارد.** ۱۰⁵ *E. coli* در سالمند بدون علامت = ASB (درمان نشود). ۱۰³ *E. coli* در زن جوان با سوزش ادرار = سیستیت.

## ۴. الگوریتم تفسیر رشد (MSU، بزرگسال)

| الگوی رشد | تفسیر | شناسایی/AST |
|---|---|---|
| **۱ اوروپاتوژن ≥ آستانهٔ سندرم** | UTI یا ASB (بالین) | ✅ ID + AST |
| **۲ اوروپاتوژن، هر دو ≥ ۱۰⁵** | ممکن است واقعی (کاتتر، UTI پیچیده) یا آلودگی | ✅ هر دو (به‌ویژه کاتتر/سالمند/cUTI) یا طبق سیاست: ID + AST هر دو اگر بیمار علامت‌دار و نمونه کاتتر |
| ۲ اوروپاتوژن، یکی **غالب** (۱۰⁵) و دیگری کم (≤ ۱۰⁴) | غالب معنی‌دار | ✅ فقط غالب؛ دیگری «حضور دارد» |
| **≥ ۳ نوع ارگانیسم** بدون غلبهٔ آشکار | **آلودگی** (در MSU) | ❌ «رشد مخلوط ≥ ۳ ارگانیسم؛ احتمال آلودگی؛ تکرار نمونه در صورت تداوم علائم» |
| ≥ ۳ نوع با یک اوروپاتوژن **≥ ۱۰⁵ غالب** | | ممکن است ID + AST اوروپاتوژن غالب (سیاست محلی) |
| فلور (لاکتوباسیل، CoNS، ویریدانس) | آلودگی/فلور | ❌ «فلور ادراری–تناسلی» |
| **عدم رشد** + پیوری | **پیوری استریل** (بخش ۶) | |
| رشد کم (کمتر از آستانه) + آنتی‌بیوتیک قبلی | UTI تحت درمان | گزارش با قید |

> 🔬 در **نمونه‌های کاتتر طولانی‌مدت**، رشد چندمیکروبی واقعی شایع است (بیوفیلم). ولی درمان فقط با علائم. بهتر است کاتتر تعویض و نمونه از کاتتر جدید گرفته شود.

## ۵. ارگانیسم‌های «پیام‌دار»

| ارگانیسم | پیام |
|---|---|
| ***S. aureus*** (بدون کاتتر) | منشأ **هماتوژن** را رد کنید ← **کشت خون** (باکتریمی/اندوکاردیت/آبسهٔ کلیه) |
| ***Salmonella*** | کریر یا عفونت سیستمیک؛ شیستوزومیازیس در مناطق آندمیک؛ واجب‌الگزارش (تیفوئید) |
| *C. urealyticum* | سیستیت قلیایی رسوب‌دار (Encrusted)؛ MDR؛ ونکومایسین |
| *Aerococcus urinae* | سالمندان؛ گاه باکتریمی و اندوکاردیت |
| *Actinotignum schaalii* | سالمندان، UTI با کشت روتین «منفی»؛ رشد در CO₂/بی‌هوازی ۴۸ ساعت |
| GBS در زن باردار | **پروفیلاکسی حین زایمان** (هر شمارش)، غربالگری ۳۶ هفته لازم نیست |
| *P. aeruginosa* در فرد سرپایی بدون ابزار | نادر؛ ابزار ادراری، ناهنجاری ساختاری؟ |
| کاندیدا | معمولاً کلونیزاسیون (کاتتر، آنتی‌بیوتیک، دیابت)؛ در نوتروپنی/نوزاد/پیش از اورولوژی ممکن است مهم باشد |
| *Proteus*/*Morganella* مکرر | سنگ عفونی (استروویت) |

## ۶. پیوری استریل (پیوری با کشت روتین منفی)

| علت | آزمایش پیشنهادی |
|---|---|
| **آنتی‌بیوتیک قبلی** (شایع‌ترین) | بررسی سابقه |
| عفونت‌های مقاربتی | NAAT ادرار اول جریان (*C. trachomatis*، *N. gonorrhoeae*، *M. genitalium*، *T. vaginalis*) |
| **سل ادراری** | ۳ نمونهٔ ادرار اول صبح برای کشت AFB + Xpert |
| ارگانیسم‌های سخت‌رشد | کشت ۴۸ ساعتهٔ CO₂/بی‌هوازی (*Actinotignum*، *Aerococcus*، *Corynebacterium*)؛ *Ureaplasma* |
| غیرعفونی | سنگ، نفریت بینابینی دارویی (ائوزینوفیلوری)، تومور، بیماری کاوازاکی (کودک)، لوپوس، کاتتر |

## ۷. تطبیق با بررسی مستقیم

| وضعیت | تفسیر |
|---|---|
| گرم ≥ ۱ باکتری/OIF ولی کشت منفی | آنتی‌بیوتیک، ارگانیسم سخت‌رشد (بی‌هوازی، *Actinotignum*)، اشتباه برچسب، مهار با ضدعفونی‌کننده یا اسید بوریک |
| کشت ≥ ۱۰⁵ ولی بدون پیوری | ASB، نوتروپنی، **تأخیر در انتقال (رشد ثانویه)** |
| سلول سنگفرشی فراوان + کشت مخلوط | آلودگی ← آموزش بیمار و تکرار |
| WBC cast | پیلونفریت ← داروی سیستمیک |
