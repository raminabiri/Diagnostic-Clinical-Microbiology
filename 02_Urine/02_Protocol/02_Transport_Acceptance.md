# پروتکل ۲: انتقال، نگهداری، پذیرش و رد نمونهٔ ادرار

## ۱. اصل محوری
ادرار **محیط کشت خوبی** است. در دمای اتاق، باکتری‌ها هر ۲۰–۴۰ دقیقه دو برابر می‌شوند ← **شمارش کاذب بالا** (آلودگی کم‌تعداد به‌ظاهر «معنی‌دار» می‌شود) یا **رشد بیش از حد** فلور. هم‌زمان لکوسیت‌ها لیز می‌شوند.

## ۲. شرایط انتقال

| وضعیت | حداکثر زمان تا کشت | توضیح |
|---|---|---|
| ظرف بدون نگهدارنده، **دمای اتاق** | **≤ ۲ ساعت** | |
| ظرف بدون نگهدارنده، **یخچال (۲–۸ °C)** | **≤ ۲۴ ساعت** | |
| **لولهٔ حاوی اسید بوریک** (مثلاً BD Vacutainer C&S، حدود ۱٫۵–۲٪) در دمای اتاق | **≤ ۴۸ ساعت** (طبق IFU) | ⚠️ **لوله باید تا خط تعیین‌شده پر شود.** پرنشدن ← غلظت بالای اسید بوریک ← مهار برخی باکتری‌ها (*P. aeruginosa*، انتروکوک، برخی گرم منفی‌ها) و کاندیدا |
| نمونهٔ SPA یا کاتتر کودک (حجم کم) | فوراً یا یخچال | در لوله‌های اسید بوریک ریخته نشود (پرنشدن) |
| سل ادراری | یخچال | ≤ ۲۴ ساعت |
| NAAT (کلامیدیا/گنوره) | طبق کیت (ظرف انتقال مخصوص) | |

> 🔬 **اسید بوریک** رشد را متوقف و ارگانیسم‌ها را حفظ می‌کند، ولی لکوسیت‌ها را برای میکروسکوپی حفظ نمی‌کند. برای آزمایش ادرار (UA) لوله‌های جداگانه با نگهدارندهٔ مناسب لازم است.

## ۳. معیار پذیرش
- ظرف استریل سالم، درپوش محکم، **بدون نشت**
- برچسب روی ظرف با دو شناسه، مطابق درخواست
- **نوع نمونه** مشخص
- زمان و دما در محدوده
- حجم کافی (حداقل حدود ۱ mL برای کشت؛ لولهٔ بوریک پر تا خط)

## ۴. معیار رد و اقدام

| مشکل | اقدام | جملهٔ گزارش/پیام |
|---|---|---|
| **بیش از ۲ ساعت در دمای اتاق بدون نگهدارنده** | **رد** و درخواست نمونهٔ جدید | «نمونه بیش از ۲ ساعت بدون سردکردن نگهداری شده است؛ شمارش کلنی قابل اعتماد نیست. نمونهٔ جدید ارسال شود.» |
| بیش از ۲۴ ساعت در یخچال | رد | |
| لولهٔ بوریک **پرنشده** | پردازش با قید (اگر نمونهٔ جدید ممکن نیست) یا رد | «لولهٔ نگهدارنده پر نشده؛ احتمال مهار رشد.» |
| ظرف بدون برچسب / عدم تطابق | **رد** (ادرار قابل تکرار است) | تماس با بخش |
| نشت / ظرف آلودهٔ بیرونی | رد | ☣️ |
| **نمونه از کیسهٔ کاتتر** | رد | «نمونه از کیسهٔ جمع‌آوری ارسال شده؛ از پورت نمونه‌گیری مجدداً ارسال شود.» |
| **نوک کاتتر Foley** | رد | «کشت نوک کاتتر ادراری ارزش تشخیصی ندارد.» |
| ادرار ۲۴ ساعته برای کشت | رد | |
| **نمونه‌های تکراری** همان روز (بدون دلیل) | فقط یکی پردازش | مدیریت تشخیصی |
| نمونهٔ کیسهٔ کودک | پذیرش برای **غربالگری** | جملهٔ تفسیری (فایل گزارش) |

> ⚠️ **استثنا:** نمونه‌های **غیرقابل تکرار** (SPA، سیستوسکوپی، نفروستومی، نمونه پیش از آنتی‌بیوتیک در بیمار بدحال) رد نمی‌شوند. با پزشک تماس بگیرید و با قید پردازش کنید.

## ۵. مدیریت تشخیصی (Diagnostic stewardship) 🔬
سیاست‌های مؤثر برای کاهش کشت‌های بی‌ارزش و درمان ASB:
- **کشت بازتابی (Reflex culture):** کشت فقط اگر غربالگری (پیوری ≥ حد آستانه، LE یا نیتریت مثبت، یا فلوسیتومتری) مثبت باشد. **استثنا:** بارداری، کودک کمتر از ۲ سال، نوتروپنی، پیوند کلیه، پیش از جراحی اورولوژیک.
- **کشت مشروط** در بیماران کاتتردار فقط با علائم.
- حذف «کشت ادرار روتین در پذیرش بیمارستان» و «تست بهبود» پس از درمان سیستیت ساده.
