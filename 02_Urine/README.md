# ماژول ۰۲: میکروب‌شناسی ادرار و عفونت دستگاه ادراری (UTI)

## معرفی
این ماژول تشخیص آزمایشگاهی **عفونت‌های باکتریایی دستگاه ادراری** را پوشش می‌دهد:
- نمونه‌گیری (MSU، کاتتر، SPA، کیسهٔ کودک)
- انتقال و پذیرش
- غربالگری (دیپ‌استیک، میکروسکوپی، فلوسیتومتری)
- کشت کمّی و **تفسیر شمارش کلنی بر اساس نوع نمونه و بیمار**
- شناسایی
- آنتی‌بیوگرام **سندرم‌محور** (سیستیت، پیلونفریت، پروستاتیت، CAUTI)
- گزارش‌دهی

> دامنه: باکتری‌ها، شامل سل ادراری در حد تشخیص. آنالیز شیمیایی و نفرولوژیک ادرار (کست‌ها، کریستال‌ها، پروتئینوری) فقط در حد ارتباط با عفونت آمده است. کاندیدوری فقط در حد تشخیص افتراقی.

## مخاطب
از کارشناس علوم آزمایشگاهی تا دستیار میکروب‌شناسی. نکات سطح بالا با برچسب **🔬 پیشرفته**.

## اهداف یادگیری
1. روش نمونه‌گیری مناسب را بر اساس بیمار (زن، مرد، کودک، نوزاد، کاتتر، بارداری) انتخاب و آموزش دهید.
2. معیارهای پذیرش، رد و نگهداری (یخچال، اسید بوریک) را اجرا کنید.
3. دیپ‌استیک (LE، نیتریت)، میکروسکوپی و گرم ادرار را تفسیر و محدودیت‌ها را بیان کنید.
4. کشت کمّی با لوپ کالیبره انجام دهید و CFU/mL را محاسبه کنید.
5. **آستانهٔ معنی‌دار** را بر اساس نوع نمونه و سندرم بالینی تعیین کنید (باکتریوری بدون علامت، سیستیت، پیلونفریت، CAUTI، کودک).
6. رشد خالص، رشد دوگانه و آلودگی را افتراق دهید و تصمیم بگیرید چه چیزی شناسایی و آنتی‌بیوگرام شود.
7. پنل آنتی‌بیوگرام را گونه‌محور و سندرم‌محور انتخاب و داروهای «فقط ادراری» را درست گزارش کنید.
8. پیوری استریل، کاندیدوری و ارگانیسم‌های «پیام‌دار» (*S. aureus*، *Salmonella*، *C. urealyticum*) را تفسیر کنید.

## ابزارهای آموزشی برای مدرس

### الف) معیار نمره‌دهی سناریوها (Rubric) — از ۱۰

| معیار | ۰ | ۱ | ۲ |
|---|---|---|---|
| کیفیت نمونه | ارزیابی نشده/نادرست | ذکر شده، استدلال ناقص | نوع نمونه، انتقال و پذیرش درست تفسیر شده |
| بررسی مستقیم | نادیده گرفته/نادرست | تفسیر بخشی از یافته‌ها | یافته‌ها با کیفیت نمونه و عفونت مرتبط شده |
| کشت و CFU/mL | محاسبه/تفسیر نادرست | خواندن درست بدون بالین | گونه، الگوی رشد، CFU و بالین یکپارچه |
| آنتی‌بیوگرام | پنل نامرتبط/ناایمن | پنل پایه درست، محدودیت‌ها ناگفته | پنل گونه‌محور و سندرم‌محور کامل |
| گزارش نهایی | مبهم/نامناسب | قابل‌قبول ولی ناقص | دقیق، کوتاه، با جملهٔ تفسیری لازم |

تفسیر نمره: ۹–۱۰ عالی؛ ۷–۸ خوب؛ ۵–۶ قابل‌قبول؛ کمتر از ۵ نیازمند بازآموزی.

### ب) چک‌لیست مهارت عملی (OSPE) — از ۲۴
(۰ = انجام نشد، ۱ = با راهنمایی، ۲ = مستقل و صحیح)

| # | مهارت |
|---|---|
| ۱ | برچسب و نوع نمونه را بررسی می‌کند |
| ۲ | معیارهای پذیرش/رد را اعمال می‌کند |
| ۳ | نمونه را پیش از کشت درست مخلوط می‌کند |
| ۴ | لوپ کالیبرهٔ مناسب (۱ یا ۱۰ µL) را بر اساس نوع نمونه انتخاب می‌کند |
| ۵ | کشت کمّی را با تکنیک صحیح انجام می‌دهد |
| ۶ | پلیت را درست برچسب و انکوبه می‌کند |
| ۷ | CFU/mL را درست محاسبه می‌کند |
| ۸ | رشد خالص را از مخلوط تفکیک می‌کند |
| ۹ | ارگانیسم را برای پنل AST درست دسته‌بندی می‌کند |
| ۱۰ | محدودیت داروهای «فقط ادراری» را بیان می‌کند |
| ۱۱ | گزارش نهایی کوتاه و قابل‌فهم می‌نویسد |
| ۱۲ | ایمنی زیستی و دفع پسماند را رعایت می‌کند |

### ج) جلسهٔ ۹۰ دقیقه‌ای پیشنهادی
پیش‌آزمون (۱۰ دقیقه) ← نمونه‌گیری و پذیرش (۱۵) ← بررسی مستقیم و دیپ‌استیک (۱۵) ← کشت کمّی و CFU (۲۰) ← آنتی‌بیوگرام و گزارش انتخابی (۱۵) ← حل گروهی سناریو (۱۰) ← جمع‌بندی و پس‌آزمون (۵).
