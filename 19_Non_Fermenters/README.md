# ۱۹. باسیل‌های گرم منفی غیرتخمیری (Non-Fermenters)

## دامنه
باسیل‌ها/کوکوباسیل‌های گرم منفی که گلوکز را **تخمیر نمی‌کنند** (TSI یا KIA: **K/K** یا K/NC؛ OF: اکسیداتیو یا غیرواکنش‌گر). بیشتر **محیطی** (آب، خاک، محلول‌ها، تجهیزات بیمارستانی) و **فرصت‌طلب**؛ مقاومت ذاتی و اکتسابی بالا.

| گروه | جنس/گونه‌های مهم |
|---|---|
| **اکسیداز منفی** | ***Acinetobacter baumannii*** complex، *A. lwoffii*؛ ***Stenotrophomonas maltophilia*** |
| ***Pseudomonas*** (اکسیداز +) | ***P. aeruginosa***، *P. fluorescens*، *P. putida*، *P. stutzeri* |
| ***Burkholderia*** | ***B. cepacia* complex** (BCC)، *B. gladioli*؛ ***B. pseudomallei*** ☣️، *B. mallei* ☣️ |
| **سایر اکسیداز +** | ***Achromobacter xylosoxidans***، *Alcaligenes faecalis*، ***Elizabethkingia*** (*E. meningoseptica*، *E. anophelis*)، *Chryseobacterium*، *Sphingomonas paucimobilis*، *Ralstonia pickettii*، *Brevundimonas*، *Shewanella*، *Moraxella* (غیر از *catarrhalis*) |
| خارج از این ماژول | *M. catarrhalis* ← [16](../16_Gram_Negative_Cocci/README.md)؛ تخمیرکنندگان اکسیداز + ← [18](../18_Oxidase_Positive_Fermenters/README.md)؛ *Bordetella*، *Brucella*، *Francisella*، *Legionella* ← [20](../20_Fastidious_GNB/README.md) |

## اهمیت بالینی (خلاصه)
| ارگانیسم | بیماری |
|---|---|
| ***P. aeruginosa*** | پنومونی وابسته به ونتیلاتور، باکتریمی، UTI مرتبط با سوند، **سوختگی**، **CF**، اوتیت خارجی بدخیم (دیابت)، کراتیت (لنز تماسی)، فولیکولیت جکوزی، استئومیلیت پا (زخم سوراخ‌شدگی با کفش ورزشی) |
| ***A. baumannii*** | **VAP**، باکتریمی، عفونت زخم (سربازان، زلزله)؛ **CRAB** (مقاومت به کارباپنم) شایع در ICUهای ایران |
| ***S. maltophilia*** | باکتریمی و پنومونی در **نوتروپنی**، ICU، پس از **کارباپنم**؛ CF |
| ***B. cepacia* complex** | **CF** («سندرم سپاسیا»: افت سریع ریوی + باکتریمی)؛ بیماری گرانولوماتوز مزمن (CGD)؛ **طغیان‌ها از محلول‌های آلوده** |
| ***B. pseudomallei*** ☣️ | **ملیوئیدوز** (جنوب شرق آسیا، شمال استرالیا، شبه‌قاره)؛ پنومونی، آبسه‌های متعدد، سپسیس؛ دیابت عامل خطر اصلی |
| ***Achromobacter*** | CF؛ باکتریمی مرتبط با کاتتر |
| ***Elizabethkingia*** | **مننژیت نوزادی**؛ پنومونی و باکتریمی در ICU؛ الگوی مقاومت غیرعادی |
| *Ralstonia*، *Sphingomonas*، *Burkholderia* | **کاذب‌طغیان (pseudo-outbreak)** و باکتریمی از **محلول‌ها و ضدعفونی‌کننده‌های آلوده** |

## ایمنی ☣️
***B. pseudomallei*** و ***B. mallei***: باسیل گرم منفی (گاه رنگ‌پذیری دوقطبی)، **اکسیداز +**، کلنی **خشک و چروکیده** در ۴۸–۷۲ ساعت، **مقاوم به جنتامایسین و کولیستین/پلی‌میکسین** ولی **حساس به آموکسی‌کلاو** ← **کار در BSC**، **بدون سیستم خودکار و MALDI-TOF**، ارجاع (پروتکل Sentinel) ← [12_Identification_Tests/03 بخش ۳.۱۲](../12_Identification_Tests/03_Disk_and_Growth_Tests.md). سیستم‌های خودکار ممکن است آن را *B. cepacia* یا *Pseudomonas* گزارش کنند.
