# بخش آنتی‌بیوگرام: سنجش حساسیت ضدمیکروبی (AST)

## معرفی
این بخش مرجع مشترک **آزمون حساسیت ضدمیکروبی** برای کل پروژه است. ماژول‌های نمونه (۰۱ تا ۰۹) و ماژول‌های ارگانیسم برای روش‌ها، تست‌های مکانیسم مقاومت و نقاط برش به این بخش ارجاع می‌دهند. **هر روش فقط یک بار** اینجا شرح داده می‌شود.

## استانداردهای مبنا (نسخه‌های جاری)

| منبع | نسخه | اعتبار |
|---|---|---|
| **CLSI M100** — Performance Standards for AST | **ویرایش ۳۶ (M100-Ed36)**، ژانویهٔ ۲۰۲۶ | جایگزین Ed35 (۲۰۲۵) |
| CLSI M02 (دیسک)، M07 (رقت)، M11 (بی‌هوازی)، M45 (سخت‌رشدها)، M24 (مایکوباکتری/نوکاردیا) | ویرایش‌های جاری | |
| **EUCAST Breakpoint Tables** | **نسخهٔ ۱۶٫۱**، ۲۴ ژوئن ۲۰۲۶ | تا ۳۱ دسامبر ۲۰۲۶ |
| EUCAST Expert Rules، Expected Resistant Phenotypes، Guidelines for detection of resistance mechanisms، RAST | نسخه‌های جاری | |
| **IDSA 2026 Guidance** — درمان عفونت‌های گرم منفی مقاوم (ESBL-E، AmpC-E، CRE، DTR-*P. aeruginosa*، CRAB، *S. maltophilia*) | ۲۰۲۶ | جایگزین نسخهٔ ۲۰۲۴ |

> ⚖️ **حق نشر:** متن کامل CLSI M100 دارای حق نشر است و در این مخزن قرار نمی‌گیرد. در این بخش فقط **خلاصه، تفسیر آموزشی و نقاط برش منتخب** با ذکر شمارهٔ جدول آمده است. برای کار بالینی همیشه به سند رسمی مراجعه کنید. جداول EUCAST رایگان‌اند: www.eucast.org
> ⚠️ **نقاط برش هر سال تغییر می‌کنند.** در هر فایل، نسخهٔ مبنا ذکر شده است.
