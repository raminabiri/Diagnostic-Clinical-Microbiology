# مقاومت در انتروکوک‌ها: VRE، HLAR، آمپی‌سیلین، داپتومایسین، لینزولید

> مبنا: CLSI M100-Ed36 (**Table 2D**، **Table 3I**، **Table 3L**، Appendix A، B و G)؛ EUCAST v16.1 (جدول Enterococcus).

## ۱. مقاومت‌های ذاتی (CLSI Appendix B؛ EUCAST Expected Resistant Phenotypes)
- **همهٔ انتروکوک‌ها (CLSI B4):** سفالوسپورین‌ها، آمینوگلیکوزیدها (به‌جز آزمون HLAR)، کلیندامایسین، تری‌متوپریم و TMP-SMX، فوزیدیک اسید؛ به‌علاوهٔ آزترئونام، پلی‌میکسین‌ها و نالیدیکسیک اسید. ⚠️ **هشدار CLSI:** سفالوسپورین‌ها، آمینوگلیکوزیدها، کلیندامایسین و TMP-SMX ممکن است در آزمایشگاه فعال به نظر برسند ولی از نظر بالینی **بی‌اثرند** و **نباید S گزارش شوند**.
- ***E. faecalis***: **کینوپریستین–دالفوپریستین** (*lsa*).
- ***E. faecium***: سطح پایین‌تر حساسیت به بتالاکتام‌ها (PBP5)، **آمینوگلیکوزید سطح متوسط** (AAC(6')-Ii: توبرامایسین، آمیکاسین، کانامایسین ← حتی بدون HLAR، سینرژی ندارند).
- ***E. gallinarum* و *E. casseliflavus***: ***vanC*** ← ونکومایسین **سطح پایین** (MIC ۸–۱۶)، تیکوپلانین S؛ **از نظر کنترل عفونت VRE محسوب نمی‌شوند** (CLSI 3I). EUCAST: ونکومایسین «–».

## ۲. بتالاکتام‌ها

| | CLSI Ed36 | EUCAST v16.1 |
|---|---|---|
| آمپی‌سیلین | MIC **S ≤ ۸ / R ≥ ۱۶**؛ دیسک ۱۰ µg S ≥ ۱۷ / R ≤ ۱۶ | **S ≤ ۴ / R > ۴**؛ دیسک **۲ µg**: ≥ ۱۰ |
| پنی‌سیلین | MIC S ≤ ۸ / R ≥ ۱۶ | از آمپی‌سیلین استنتاج |

- **آمپی‌سیلین پیش‌بینی‌کنندهٔ آموکسی‌سیلین** است (CLSI). EUCAST: ایزولهٔ حساس به آمپی‌سیلین ← حساس به آمپی‌سیلین–سولباکتام، آموکسی‌کلاو و پیپ–تازو (بدون سود اضافهٔ مهارکننده).
- *E. faecalis* با **آمپی‌سیلین R در دیسک** ← **MIC تأییدی** (EUCAST)؛ نادر است ← بررسی شناسایی (*E. faecium* اشتباه شناخته‌شده؟).
- **بتالاکتاماز** در انتروکوک **بسیار نادر** ← MIC آمپی‌سیلین آن را نشان نمی‌دهد؛ نیتروسفین فقط در موارد خاص (CLSI Table 2D).
- **سینرژی با آمپی‌سیلین بالا (CLSI 3L):** انتروکوک با **پنی‌سیلین ≤ ۶۴** یا **آمپی‌سیلین ≤ ۳۲** ممکن است با دوز بالا + جنتامایسین یا استرپتومایسین (بدون HLAR) کشته شود. با **پنی‌سیلین ≥ ۱۲۸** یا **آمپی‌سیلین ≥ ۶۴** ممکن است نه ← درخواست پزشک برای **MIC واقعی** در ایزوله‌های خون و CSF پذیرفته شود.

## ۳. مقاومت به ونکومایسین (VRE)

### ۳.۱ ژنوتیپ‌ها

| نوع | ونکومایسین MIC | تیکوپلانین | ژن | گونه |
|---|---|---|---|---|
| **VanA** | **≥ ۶۴** (بالا) | **R** | *vanA* (Tn1546؛ قابل‌انتقال) | *E. faecium* (و *faecalis*) |
| **VanB** | **۴ تا ≥ ۱۰۰۰** (متغیر) | **S** (القاکننده نیست) | *vanB* | *E. faecium*، *faecalis* |
| **VanC** | **۸–۱۶** | S | *vanC1/C2-3* (ذاتی) | *E. gallinarum*، *E. casseliflavus* |
| VanD، E، G، L، M، N | متغیر | | | نادر |

> ⚠️ **VanB با MIC پایین** (۴–۸) می‌تواند از دست سیستم‌های خودکار و حتی دیسک فرار کند ← دقت در خوانش.

### ۳.۲ نقاط برش

| | CLSI Ed36 | EUCAST v16.1 |
|---|---|---|
| ونکومایسین MIC | **S ≤ ۴؛ I ۸–۱۶؛ R ≥ ۳۲** | ***E. faecalis/faecium*: S ≤ ۴ / R > ۴**؛ *E. casseliflavus/gallinarum*: «–» |
| ونکومایسین دیسک | **۳۰ µg**: S ≥ ۱۷؛ I ۱۵–۱۶؛ R ≤ ۱۴ | **۵ µg**: *faecalis/faecium* ≥ **۱۲**؛ سایر ≥ ۱۵ |
| تیکوپلانین | (Inv.) MIC S ≤ ۸؛ I ۱۶؛ R ≥ ۳۲؛ دیسک ۳۰ µg ≥ ۱۴ | S ≤ ۲ / R > ۲؛ دیسک ۳۰ ≥ ۱۶ |

### ۳.۳ خوانش دیسک (نکتهٔ کلیدی)
- **CLSI:** **۲۴ ساعت کامل**؛ **نور عبوری**؛ **هر مه یا رشدی در هاله = R**. هالهٔ بینابینی ← **MIC**.
- **EUCAST:** ایزوله‌های حساس **لبهٔ تیز** دارند و درون هاله **کلنی ندارند**. لبهٔ **مبهم** یا کلنی درون هاله یا تردید ← **PCR تأییدی یا R**، حتی اگر هاله ≥ ۱۲ mm. **پیش از ۲۴ ساعت S گزارش نشود.**

### ۳.۴ آگار غربالگری ونکومایسین (CLSI Table 3I)
- **BHI آگار + ونکومایسین ۶ µg/mL**؛ **۱–۱۰ µL** از ۰٫۵ مک‌فارلند؛ ۳۵ ± ۲°C، **۲۴ ساعت**.
- **> ۱ کلنی** = **VRE احتمالی** ← **MIC** + **تحرک و رنگدانه** برای جدا کردن *E. gallinarum* (متحرک) و *E. casseliflavus* (متحرک، زرد) که اغلب روی این پلیت رشد می‌کنند.
- QC: *E. faecalis* ATCC 29212 (S) و **ATCC 51299** (R؛ *vanB*).

### ۳.۵ غربالگری کلونیزاسیون VRE (کنترل عفونت)
محیط‌های **کروموژنیک VRE** (سوآب رکتال)؛ **PCR** *vanA/vanB* (⚠️ *vanB* در باکتری‌های بی‌هوازی روده مثل *Clostridium* ← مثبت کاذب PCR مستقیم از مدفوع).

## ۴. مقاومت سطح بالا به آمینوگلیکوزیدها (HLAR) — CLSI Table 3L

### ۴.۱ منطق
آمینوگلیکوزید به‌تنهایی بر انتروکوک اثر ندارد (نفوذ کم). **داروی مؤثر بر دیواره** (آمپی‌سیلین، پنی‌سیلین، ونکومایسین) نفوذ را بالا می‌برد ← **سینرژی باکتری‌کش** (برای **اندوکاردیت**). **آنزیم‌های تغییردهندهٔ آمینوگلیکوزید** (AAC(6')-Ie-APH(2'')-Ia برای جنتامایسین؛ ANT(6) برای استرپتومایسین) سینرژی را از بین می‌برند.

### ۴.۲ روش‌ها

| | جنتامایسین HLAR | استرپتومایسین HLAR |
|---|---|---|
| **دیسک** (MHA؛ ۱۶–۱۸ ساعت) | **۱۲۰ µg**: **۶ mm = R**؛ **۷–۹ = نامشخص** (← رقت)؛ **≥ ۱۰ = S** | **۳۰۰ µg**: همان معیارها |
| **BMD** (BHI broth؛ ۲۴ ساعت) | **۵۰۰ µg/mL**: **هر رشد = R** | **۱۰۰۰ µg/mL**: هر رشد = R؛ **۲۴–۴۸ ساعت** (اگر در ۲۴ ساعت S بود ← انکوباسیون مجدد) |
| **آگار دایلوشن** (BHI آگار؛ لکهٔ ۱۰ µL از ۰٫۵ مک‌فارلند) | **۵۰۰ µg/mL**: **> ۱ کلنی = R** | **۲۰۰۰ µg/mL**؛ ۲۴–۴۸ ساعت |
| **QC** | *E. faecalis* ATCC 29212 (S؛ دیسک **۱۶–۲۳ mm**)؛ ATCC 51299 (R) | ATCC 29212 (S؛ دیسک **۱۴–۲۰ mm**)؛ ATCC 51299 (R) |

### ۴.۳ گزارش
- **R (HLAR)** ← **سینرژی با داروی دیواره‌ای وجود ندارد**.
- **S** ← سینرژی با داروی دیواره‌ای **حساس** وجود دارد.
- **جنتامایسین HLAR** ← R به سایر آمینوگلیکوزیدها **به‌جز استرپتومایسین** (جداگانه آزمون شود).
- **EUCAST:**
  - غربالگری جنتامایسین (دیسک **۳۰ µg**): **MIC ≤ ۱۲۸** یا هاله **≥ ۸ mm** = وحشی (سینرژی محتمل)؛ **MIC > ۱۲۸** یا هاله **کمتر از ۸** = آنزیم (بدون سینرژی).
  - استرپتومایسین (دیسک ۳۰۰): **MIC ≤ ۵۱۲** یا هاله **≥ ۱۴** = وحشی.

## ۵. داپتومایسین

| گونه | CLSI Ed36 |
|---|---|
| ***E. faecium*** | **SDD ≤ ۴؛ R ≥ ۸** (دستهٔ S ندارد؛ SDD برای عفونت جدی با دوز بالا ۸–۱۲ mg/kg؛ مشاورهٔ عفونی) |
| سایر انتروکوک‌ها | **S ≤ ۲؛ I ۴؛ R ≥ ۸** |

- **فقط MIC** با Ca²⁺ ۵۰ mg/L. برای ایزوله‌های **تنفسی تحتانی** روتین گزارش نشود.
- EUCAST: **IE**.

## ۶. لینزولید و تدیزولید
- CLSI: لینزولید MIC **S ≤ ۲؛ I ۴؛ R ≥ ۸**؛ دیسک ۳۰ µg **S ≥ ۲۳؛ I ۲۱–۲۲؛ R ≤ ۲۰**. EUCAST: S ≤ ۴ / R > ۴؛ دیسک ۱۰ µg ≥ ۲۰.
- سازوکارها: جهش 23S (G2576T)، ***optrA*** (به‌ویژه *E. faecalis*؛ فنیکل‌ها + اکسازولیدینون‌ها)، ***poxtA***، *cfr*.
- لینزولید R ← Appendix A (تأیید، ارجاع).

## ۷. داروهای ادراری
- **نیتروفورانتوئین (U)**:
  - CLSI: MIC **S ≤ ۳۲؛ I ۶۴؛ R ≥ ۱۲۸**؛ دیسک ۳۰۰ µg
  - EUCAST (*E. faecalis*، فقط UTI ساده): S ≤ ۶۴ / R > ۶۴
- **فسفومایسین (U)** — CLSI: **فقط *E. faecalis***؛ MIC S ≤ ۶۴، I ۱۲۸، R ≥ ۲۵۶؛ دیسک ۲۰۰ µg.

## ۸. الگوریتم گزارش انتروکوک خون/اندوکاردیت
1. **شناسایی تا گونه** (*faecalis* در برابر *faecium*).
2. آمپی‌سیلین (MIC در اندوکاردیت)، ونکومایسین (MIC)، **HLAR جنتامایسین و استرپتومایسین**.
3. اگر VRE: لینزولید، داپتومایسین (MIC)، تیگسایکلین (برای غیرخونی)، (اورتاوانسین/دالباوانسین فقط *E. faecalis* حساس به ونکومایسین — CLSI).
4. **سرکوب**: سفالوسپورین‌ها، کلیندامایسین، TMP-SMX، آمینوگلیکوزیدها (به‌جز HLAR).
