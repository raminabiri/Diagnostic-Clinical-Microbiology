# از نتیجهٔ آزمایشگاه تا درمان: راهنمای IDSA 2026

> مبنا: **IDSA 2026 Guidance on the Treatment of Antimicrobial-Resistant Gram-Negative Infections** (ESBL-E، AmpC-E، CRE، DTR-*P. aeruginosa*، CRAB، *S. maltophilia*). خلاصهٔ «Suggested approach»ها برای **دستیار میکروب‌شناسی**: هدف این است که بدانید کدام نتیجهٔ آزمایشگاهی کدام تصمیم درمانی را راه می‌اندازد. تصمیم درمانی با **پزشک عفونی** است.
> ⚠️ IDSA فرض می‌کند فعالیت آزمایشگاهی داروی پیشنهادی **نشان داده شده** است (AST). الگوهای مقاومت منطقه‌ای (ایران: شیوع بالای **OXA-48** و **NDM** در *K. pneumoniae*، و OXA-23 در *A. baumannii*) باید در نظر گرفته شوند.

## ۱. تعاریف (پیوند با آزمایشگاه)

| اصطلاح | تعریف IDSA 2026 | آزمون آزمایشگاهی لازم |
|---|---|---|
| **ESBL-E** | *E. coli*، *K. pneumoniae*، *K. oxytoca* با **سفتریاکسون R (MIC ≥ ۴)** به‌عنوان جانشین (آزمون ESBL روتین لازم نیست) | AST سفتریاکسون |
| **AmpC-E (خطر متوسط)** | ***E. cloacae* complex، *K. aerogenes*، *C. freundii*، (*H. alvei*)** | **شناسایی گونه** |
| **CRE** | Enterobacterales مقاوم به کارباپنم (و/یا تولیدکنندهٔ کارباپنماز) | AST کارباپنم‌ها + **نوع کارباپنماز** |
| **DTR-*P. aeruginosa*** | غیرحساس به **همهٔ**: آزترئونام، سفپیم، سفتازیدیم، سیپروفلوکساسین، ایمی‌پنم، لووفلوکساسین، مروپنم و پیپ–تازو | AST کامل |
| **CRAB** | *A. baumannii* complex مقاوم به کارباپنم | AST + (OXA-23/24/58) |
| ***S. maltophilia*** | | AST (TMP-SMX، لووفلوکساسین، مینوسایکلین، سفیدروکول) |

## ۲. ESBL-E

| موقعیت | ترجیحی | جایگزین / نکته |
|---|---|---|
| **سیستیت ساده (uUTI)** | آمینوگلیکوزید (تک‌دوز)، **گپوتیداسین**، نیتروفورانتوئین، پیومسیلینام، **سولوپنم**، TMP-SMX | فسفومایسین خوراکی (فقط *E. coli*)؛ در صورت ناچاری: فلوروکینولون، سفپیم–انمتازوباکتام، کارباپنم |
| **cUTI** | TMP-SMX، سیپروفلوکساسین، لووفلوکساسین (اگر S) | سفپیم–انمتازوباکتام یا کارباپنم (اگر آن‌ها ممکن نیست)؛ جایگزین: فسفومایسین وریدی، آمینوگلیکوزیدها، **پیپ–تازو** (غیربحرانی، بدون باکتریمی) |
| **خارج از مجاری ادراری** (باکتریمی، شکمی، پوست، پنومونی) | **ارتاپنم، ایمی‌پنم، مروپنم** (بیمار بحرانی یا **هیپوآلبومینمی** کمتر از ۲٫۵ g/dL: ایمی‌پنم/مروپنم) | سفپیم–انمتازوباکتام؛ پس از پاسخ ← خوراکی سیپرو/لوو/TMP-SMX (اگر S) |
| **پیپ–تازو** | uUTI تجربی با بهبود ← ادامه | **خارج از مجاری ادراری توصیه نمی‌شود، حتی اگر S** |
| **سفپیم** | uUTI تجربی با بهبود ← ادامه | cUTI و خارج از مجاری ادراری **پرهیز، حتی اگر S** |
| **سفامایسین‌ها** (سفوکسیتین، سفوتتان) | توصیه نمی‌شود | |
| **داروهای ضد CRE** (CZA، MEV، IMR، C/T، ATM-AVI، سفیدروکول) | **برای مقاومت به کارباپنم ذخیره شوند** | |

**⇐ پیام برای آزمایشگاه:**
- برای ESBL-E، **پیپ–تازو و سفپیم S** را با یادداشت گزارش کنید (یا طبق سیاست Stewardship سرکوب کنید).
- AST **TMP-SMX، فلوروکینولون‌ها، نیتروفورانتوئین، فسفومایسین، پیومسیلینام و (در صورت دسترس) گپوتیداسین** برای ادرار.

## ۳. AmpC-E (خطر متوسط القای *ampC*)

| دارو | توصیه |
|---|---|
| **سفپیم** | **ترجیحی** اگر MIC **≤ ۸** (S یا SDD) |
| سفتریاکسون/سفوتاکسیم/سفتازیدیم | برای عفونت **تهاجمی** توصیه نمی‌شود؛ عفونت خفیف تجربی با بهبود و کنترل منبع ← ادامه شاید معقول |
| **پیپ–تازو** | برای عفونت تهاجمی **توصیه نمی‌شود** |
| **سفتولوزان–تازوباکتام** | **توصیه نمی‌شود** |
| داروهای ضد CRE | ذخیره |
| **غیربتالاکتام‌ها** (TMP-SMX، فلوروکینولون‌ها، آمینوگلیکوزیدها) | مؤثر اگر S (سوبسترای AmpC نیستند) |

**⇐ پیام برای آزمایشگاه:** شناسایی دقیق گونه (MALDI-TOF) + **یادداشت AmpC القایی** در گزارش + سفپیم را حتماً آزمون کنید.

## ۴. CRE

| موقعیت | ترجیحی | جایگزین |
|---|---|---|
| **uUTI** | آمینوگلیکوزید (تک‌دوز)، سیپرو، لوو، نیتروفورانتوئین، TMP-SMX (احتمال حساسیت پایین) | کولیستین، فسفومایسین خوراکی (*E. coli*)، گپوتیداسین، پیومسیلینام؛ داروهای وریدی جدید فقط در صورت ناچاری |
| **cUTI** | سیپرو، لوو، TMP-SMX؛ یا **ATM-AVI، سفیدروکول، CZA، IMR، MEV** (به‌ویژه بیمار ناپایدار) | فسفومایسین وریدی؛ آمینوگلیکوزید یک‌بار در روز (آمیکاسین، جنتامایسین، **پلازومایسین**، توبرامایسین) |
| **غیرکارباپنمازی**، مروپنم/ایمی‌پنم **MIC ≤ ۱** و ارتاپنم **≥ ۱** | **مروپنم یا ایمی‌پنم با انفوزیون طولانی** | |
| غیرکارباپنمازی، مقاوم به همهٔ کارباپنم‌ها | ATM-AVI، CZA، IMR، MEV | |
| **KPC** | **CZA، IMR، MEV** (مقاومت در حین درمان: CZA حدود ۱۰٪؛ IMR/MEV کمتر از ۳٪) | ATM-AVI، سفیدروکول، اراواسایکلین، تایگسایکلین (این دو آخر نه برای خون/ادرار) |
| **NDM** | **ATM-AVI** یا **سفیدروکول** | CZA + آزترئونام (اگر ATM-AVI نیست)؛ اراواسایکلین/تایگسایکلین (نه خون/ادرار) |
| **OXA-48-like** | **CZA** | ATM-AVI، سفیدروکول، اراواسایکلین، تایگسایکلین |
| **تتراسایکلین‌ها** | جایگزین وقتی بتالاکتام‌ها ممکن نیستند | **نه برای UTI و باکتریمی** |
| **درمان ترکیبی** (بتالاکتام + آمینوگلیکوزید/FQ/فسفومایسین/تتراسایکلین/پلی‌میکسین) | **روتین توصیه نمی‌شود** | |

**⇐ پیام برای آزمایشگاه:**
1. **نوع کارباپنماز را سریع تعیین کنید** (ICT ۵‌گانه یا PCR): انتخاب دارو بر اساس مکانیسم **به‌علاوهٔ** AST است.
2. **AST داروهای جدید** (CZA، MEV، IMR، ATM-AVI، سفیدروکول) را در دسترس قرار دهید؛ در غیر این صورت ارجاع.
3. برای NDM: **ATM-AVI** یا روش **ATM + CZA (CLSI 3D)**.
4. ژن کارباپنماز **جای AST را نمی‌گیرد**.

## ۵. DTR-*P. aeruginosa*

| موقعیت | ترجیحی | جایگزین |
|---|---|---|
| حساس به بتالاکتام‌های سنتی **و** کارباپنم | **بتالاکتام سنتی** (آزترئونام، سفپیم، سفتازیدیم، پیپ–تازو) بر کارباپنم ارجح است | |
| مقاوم به کارباپنم، حساس به بتالاکتام سنتی | بتالاکتام سنتی با **دوز بالا و انفوزیون طولانی** | بیمار بحرانی/کنترل منبع ضعیف: بتالاکتام جدید (سفیدروکول، CZA، C/T، IMR) |
| **cUTI** با DTR | سفیدروکول، CZA، C/T، IMR | آمیکاسین یا توبرامایسین یک‌بار در روز |
| خارج از مجاری ادراری با DTR | **CZA، C/T، IMR** (**پنومونی: C/T ترجیحی**) | سفیدروکول |
| *P. aeruginosa* با **KPC** | سفیدروکول، CZA، IMR | |
| *P. aeruginosa* با **MBL** (VIM، NDM، IMP) | **سفیدروکول** | |
| **مقاومت در حین درمان** | حدود **۲۰٪** با بتالاکتام‌های جدید ← **AST تکراری** در ایزوله‌های بعدی | |
| درمان ترکیبی | توصیه نمی‌شود اگر حساسیت به یکی از داروهای جدید تأیید شده باشد | |
| آنتی‌بیوتیک استنشاقی | روتین توصیه نمی‌شود | |

**⇐ پیام برای آزمایشگاه:** AST **C/T، CZA، IMR و سفیدروکول** برای هر DTR-PA؛ آزمون کارباپنماز در *P. aeruginosa* مقاوم به کارباپنم (به‌ویژه **VIM** در منطقه).

## ۶. CRAB

| دارو | جایگاه |
|---|---|
| **سولباکتام–دورلوباکتام + ایمی‌پنم یا مروپنم** | **ترجیحی** برای عفونت تهاجمی |
| آمپی‌سیلین–سولباکتام **دوز بالا** (سولباکتام ۹ g/روز) + حداقل یک داروی دیگر | **پل موقت** تا دسترسی به سولباکتام–دورلوباکتام |
| **سفیدروکول** + داروی دیگر | جایگزین |
| **مینوسایکلین** + داروی دیگر | جایگزین |
| **پلی‌میکسین B** + داروی دیگر | جایگزین |
| آنتی‌بیوتیک استنشاقی | روتین توصیه نمی‌شود |

**⇐ پیام برای آزمایشگاه:**
- AST **سولباکتام–دورلوباکتام** (CLSI Ed36: سطح ۳، پلکانی زیر کارباپنم‌ها؛ S ≤ ۴/۴).
- مینوسایکلین (CLSI S ≤ ۱)، سفیدروکول (MIC اگر هالهٔ ≤ ۱۴)، کولیستین/پلی‌میکسین (BMD).
- IDSA: آزمون‌های رایج برای حساسیت **سولباکتام** نادقیق‌اند. فقط حدود ۱۰٪ CRAB به سولباکتام حساس‌اند.
- Carba NP و mCIM برای *Acinetobacter* **معتبر نیستند** ← PCR OXA.

## ۷. *S. maltophilia*

| دارو | جایگاه |
|---|---|
| **سفیدروکول (تک‌دارویی)** | **ترجیحی** (بیشتر بر پایهٔ مدل‌های حیوانی) |
| **آزترئونام–اویباکتام** (ترجیحاً + داروی دوم) | جایگزین |
| **لووفلوکساسین** (جزء ترکیب) | جایگزین |
| **مینوسایکلین** (جزء ترکیب) | جایگزین |
| **TMP-SMX** (جزء ترکیب) | جایگزین |
| **سفتازیدیم** | **توصیه نمی‌شود** (بتالاکتامازهای ذاتی L1/L2) |

**⇐ پیام برای آزمایشگاه:** سفتازیدیم را برای *S. maltophilia* **گزارش نکنید** (EUCAST: «–»). TMP-SMX: رشد درون هاله نادیده گرفته شود. ATM + CZA (CLSI 3D) یا ATM-AVI.

## ۸. جدول جمع‌بندی: «نتیجه ← اقدام آزمایشگاه»

| نتیجهٔ آزمایشگاه | اقدام فوری |
|---|---|
| *E. coli*/*Klebsiella* سفتریاکسون R در خون | تماس با پزشک؛ یادداشت «ESBL احتمالی؛ پیپ–تازو و سفپیم توصیه نمی‌شود»؛ AST کارباپنم‌ها |
| *Enterobacter* در خون | یادداشت AmpC القایی؛ گزارش سفپیم |
| کارباپنم R در Enterobacterales | ICT/PCR کارباپنماز؛ AST داروهای جدید؛ کنترل عفونت |
| NDM | ATM-AVI یا ATM + CZA؛ سفیدروکول |
| *P. aeruginosa* DTR | AST C/T، CZA، IMR، سفیدروکول؛ آزمون کارباپنماز |
| CRAB | AST سولباکتام–دورلوباکتام، مینوسایکلین، سفیدروکول، پلی‌میکسین (BMD) |
| *S. maltophilia* | سرکوب سفتازیدیم؛ AST TMP-SMX، لووفلوکساسین، مینوسایکلین، سفیدروکول |
