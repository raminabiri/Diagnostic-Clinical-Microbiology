# AST سریع (Rapid AST)

> مبنا: CLSI M100-Ed36 **Tables 3F-1 تا 3F-4** (دیسک مستقیم از کشت خون)؛ EUCAST **RAST** (روش و جداول جداگانه در eucast.org)؛ مرور منابع.

## ۱. چرا؟
در سپسیس، هر ساعت تأخیر در درمان مؤثر مرگ‌ومیر را بالا می‌برد. AST معمول از کلنی: کشت مثبت ← زیرکشت (۱۸–۲۴ ساعت) ← AST (۱۶–۲۰ ساعت) = **۲ تا ۳ روز**. روش‌های سریع این زمان را به **۴ تا ۱۸ ساعت** پس از مثبت شدن کاهش می‌دهند.

## ۲. CLSI: دیسک دیفیوژن مستقیم از کشت خون مثبت (Table 3F-1)

| جزء | مشخصات |
|---|---|
| **ارگانیسم‌ها** | **Enterobacterales**، ***P. aeruginosa***، ***Acinetobacter*** spp. (گرم منفی) |
| **نمونه** | براث کشت خون **مثبت با باسیل گرم منفی**، حداکثر **۸ ساعت** پس از هشدار دستگاه |
| **روش** | وارونه کردن ۵–۱۰ بار ← ضدعفونی درپوش، سوزن ۲۰G ← **۴ قطره** روی MHA ← پخش با سواب در ۳ جهت ← ۳–۵ دقیقه (حداکثر ۱۵) ← دیسک‌ها ← انکوباسیون ظرف ۱۵ دقیقه. **پلیت خلوص** هم‌زمان |
| **انکوباسیون** | ۳۵ ± ۲°C، هوا؛ **۸–۱۰ ساعت یا ۱۶–۱۸ ساعت** (بسته به دارو؛ Tables 3F-2 تا 3F-4) |
| **خوانش** | طبق M02؛ دو هاله ← **هالهٔ داخلی** |
| **تفسیر** | **فقط پس از شناسایی** (Enterobacterales، *P. aeruginosa* یا *Acinetobacter*)؛ با **نقاط برش ویژهٔ 3F** (نه Table 2)؛ ارگانیسم دیگر ← گزارش نشود |
| **گزارش** | **فقط دسته** (S/SDD/I/R)، نه قطر هاله |
| **باطل** | رشد مخلوط، چمن ناپیوسته، رشد خیلی ضعیف ← AST استاندارد از کلنی |
| **QC** | QC معمول دیسک (روزانه یا IQCP)؛ دامنه‌های **خوانش زودهنگام (۸–۱۰ ساعت)** اختیاری و برای آموزش/صلاحیت |

| جزء | مشخصات |
|---|---|
| **ارگانیسم‌ها** | *E. coli*، *K. pneumoniae*، *P. aeruginosa*، *A. baumannii*، *S. aureus*، *E. faecalis*، *E. faecium*، *S. pneumoniae* (فهرست با هر نسخه گسترش می‌یابد) |
| **روش** | **۱۲۵ ± ۲۵ µL** براث کشت خون مثبت روی MHA (پنوموکوک: MH-F)، پخش، دیسک‌های **استاندارد EUCAST**، انکوباسیون **۳۵ ± ۱°C** |
| **زمان خوانش** | **۴، ۶، ۸ ساعت** (و ۱۶–۲۰ ساعت) — نقاط برش **ویژهٔ هر زمان** |
| **ATU** | در RAST پهن‌تر است ← نتایج در ATU گزارش نشوند؛ در زمان بعدی دوباره خوانده شوند |
| **شرط** | شناسایی سریع (MALDI-TOF مستقیم یا PCR)؛ آزمایشگاه باید در **سنجش صلاحیت** شرکت کند |

## ۴. روش‌های نوین تجاری (خلاصه)

| فناوری | نمونه | زمان |
|---|---|---|
| **میکروسکوپی تک‌سلولی (morphokinetic)** — Accelerate Pheno | کشت خون مثبت؛ ID با FISH + MIC | ID حدود ۱٫۵ ساعت، AST حدود ۷ ساعت |
| **رشد سریع + تصویربرداری** — dRAST، ASTar، Reveal (VITEK REVEAL) | کشت خون مثبت؛ MIC فنوتیپی | ۴–۷ ساعت |
| **MALDI-TOF** (هیدرولیز کارباپنم، DOT-MGA) | کلنی/براث | ۱–۴ ساعت (پژوهشی/محدود) |
| **فلوسایتومتری** (FASTinov) | کشت خون مثبت | حدود ۲ ساعت |
| **آزمون‌های مولکولی سریع** (BioFire BCID2، Verigene، ePlex) | کشت خون مثبت؛ ژن‌های مقاومت (*mecA/C*، *vanA/B*، *bla*CTX-M، KPC، NDM، VIM، IMP، OXA-48-like، *mcr-1*) | ۱ ساعت ← [07_Molecular](../07_Molecular/01_Molecular_Resistance.md) |

## ۵. اصول گزارش‌دهی AST سریع
1. **گزارش اولیه** با برچسب «نتیجهٔ مقدماتی؛ AST استاندارد در حال انجام».
2. **ناهمخوانی** با AST استاندارد ← اصلاح گزارش و **تماس با پزشک**.
3. کشت خون **چندمیکروبی** ← روش مستقیم معتبر نیست.
4. اثر واقعی بر بیمار فقط با **پیوند به برنامهٔ Stewardship** (اطلاع فوری به تیم عفونی) به دست می‌آید.
