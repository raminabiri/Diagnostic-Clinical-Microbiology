# جداول مقایسه‌ای نقاط برش: CLSI M100-Ed36 در برابر EUCAST v16.1

> ⚖️ این جداول **منتخب و آموزشی**‌اند و کل جداول را بازتولید نمی‌کنند. همهٔ اعداد با متن CLSI M100-Ed36 (ژانویهٔ ۲۰۲۶) و EUCAST v16.1 (۲۴ ژوئن ۲۰۲۶) تطبیق داده شده‌اند. برای کار بالینی همیشه به سند رسمی مراجعه کنید.
> **قرارداد نمایش:** CLSI = «S ≤ x؛ SDD/I؛ R ≥ y» · EUCAST = «S ≤ x / R > y» (I = بین آن‌ها) · «(x)» = نقطهٔ برش پرانتزی EUCAST (ECOFF؛ فقط ترکیبی) · «–» = نامناسب/R بدون تست · IE = شواهد ناکافی · «^» = دارو در ادرار تغلیظ می‌شود (CLSI).

## تغییرات مهم نسخه‌های ۲۰۲۶

### CLSI M100-Ed36 (ژانویهٔ ۲۰۲۶)
- **آزترئونام–اویباکتام** (Enterobacterales): S ≤ ۴/۴؛ I^ ۸/۴؛ R ≥ ۱۶/۴؛ دیسک ۳۰/۲۰ µg (سطح ۳).
- ***Acinetobacter***: بازنگری **آمیکاسین، جنتامایسین، توبرامایسین** (دیسک و MIC)؛ **سولباکتام–دورلوباکتام** سطح ۳، پلکانی زیر کارباپنم‌ها.
- ***N. gonorrhoeae***: سفتریاکسون و سفیکسیم **I و R افزوده شد**؛ **نقاط برش دیسک حذف شد**.
- **استرپتوکوک بتا**: نقطهٔ برش MIC برای **TMP-SMX** (فقط عفونت پوست، فقط BMD).
- **دیسک مستقیم از کشت خون (3F)**: پیپراسیلین–تازوباکتام برای Enterobacterales؛ سفپیم: **I ← SDD**.
- *S. maltophilia*: بازنگری دیسک سفیدروکول.
- QC: کونتزولید؛ Appendix H: سفیدروکول (ID-CAMHB)، اگزباکاز.

### EUCAST v16.0 (ژانویه) و v16.1 (ژوئن ۲۰۲۶)
- **گپوتیداسین** افزوده شد (Enterobacterales، استاف، انتروکوک؛ UTI ساده).
- **TMP-SMX** و تری‌متوپریم در Enterobacterales، استاف، استرپتوکوک‌ها، *H. influenzae*، *M. catarrhalis*، *Acinetobacter* و *Aeromonas* **بازنگری شد** (Enterobacterales به‌جز *Serratia*: **S ≤ ۰٫۵ / R > ۰٫۵**).
- **داپتومایسین** در استاف: فقط برای ***S. aureus*** معتبر است.
- **بی‌هوازی‌ها** در دو برگهٔ جدا (گرم منفی/گرم مثبت) با جداول جدید گونه‌ای (*F. nucleatum*، *C. innocuum*، *Finegoldia*، *Parvimonas*…).
- یادداشت کارباپنم Enterobacterales: «بدون مهارکنندهٔ فعال علیه کارباپنماز مربوطه» افزوده شد.
- پنوموکوک: فلوچارت بتالاکتام‌ها در اندوکاردیت/مننژیت به‌روز شد.
