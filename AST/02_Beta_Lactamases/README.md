## اصل مهم در CLSI و EUCAST
> **با نقاط برش جاری، کشف ESBL یا AmpC برای گزارش بالینی لازم نیست.** نتیجهٔ سفالوسپورین‌ها و آزترئونام **همان‌طور که آزمون شده‌اند** گزارش می‌شوند (CLSI Table 3A، NOTE 1؛ EUCAST Enterobacterales، یادداشت ۱ سفالوسپورین‌ها). کشف و تعیین مکانیسم برای **کنترل عفونت، اپیدمیولوژی و انتخاب درمان** (مثلاً بین داروهای جدید) است.
> - همین قاعده برای **کارباپنمازها** در CLSI صادق است: «Carba NP یا mCIM مثبت ← تغییری در تفسیر کارباپنم لازم نیست» (Tables 3B، 3C).
> - **EUCAST:** اگر کارباپنماز کشف شود، پاسخ بالینی به کارباپنم‌ها (بدون مهارکنندهٔ مؤثر) ممکن است مختل باشد، **حتی اگر S یا I** باشد؛ داروهای دیگر ترجیح دارند.
