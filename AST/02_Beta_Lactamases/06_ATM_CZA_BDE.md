# آزترئونام + سفتازیدیم–اویباکتام و آزترئونام–اویباکتام

> مبنا: CLSI M100-Ed36 **Table 3D** (Broth Disk Elution، **موقت/Provisional**)، Table 2A-1 (آزترئونام–اویباکتام، **جدید Ed36**)؛ EUCAST v16.1؛ IDSA 2026 (NDM-E و *S. maltophilia*).

## ۱. منطق
- **MBL**ها (NDM، VIM، IMP) آزترئونام را **هیدرولیز نمی‌کنند**.
- ولی ایزوله‌های MBL تقریباً همیشه **ESBL، AmpC یا OXA-48** هم دارند که آزترئونام را تخریب می‌کنند.
- **اویباکتام** این آنزیم‌های سرینی را مهار می‌کند ← آزترئونام از تخریب محفوظ می‌ماند.
- ⇐ ترکیب **آزترئونام + اویباکتام** (به شکل ATM + CZA یا داروی ترکیبی **آزترئونام–اویباکتام**، Emblaveo®) برای **MBL** و ***S. maltophilia*** (L1 = MBL، L2 = کلاس A).

## ۲. نقاط برش آزترئونام–اویباکتام (Enterobacterales)

| | CLSI M100-Ed36 (جدید) | EUCAST v16.1 |
|---|---|---|
| **MIC (µg/mL)** | **S ≤ ۴/۴؛ I^ ۸/۴؛ R ≥ ۱۶/۴** | **S ≤ ۴؛ R > ۴** (اویباکتام ثابت ۴ mg/L) |
| **دیسک ۳۰/۲۰ µg** | **S ≥ ۲۵؛ I^ ۲۲–۲۴؛ R ≤ ۲۱** | S ≥ ۲۵؛ R < ۲۵؛ **ATU ۲۲–۲۴** |
| یادداشت | هالهٔ **۲۲–۲۴ mm** ← **MIC تأییدی** (برای پرهیز از I نادرست) | |

- *P. aeruginosa*: EUCAST = **IE**. *S. maltophilia*: EUCAST = **IE** (ولی ECOFF: مقاومت اکتسابی با **MIC > ۸** یا هالهٔ **کمتر از ۲۱ mm**). سایر گروه‌ها: «–».
- CLSI Appendix A: **آزترئونام–اویباکتام I/R در Enterobacterales** ← تأیید و گزارش (نادر).

## ۳. روش BDE برای ATM + CZA (CLSI Table 3D)

| جزء | مشخصات |
|---|---|
| **ارگانیسم** | **Enterobacterales و *S. maltophilia*** |
| **کاربرد** | ایزوله‌های MDR، به‌ویژه **تولیدکنندگان MBL** |
| **محیط** | **CAMHB، لوله‌های ۵ mL** |
| **دیسک‌ها** | آزترئونام **۳۰ µg**؛ سفتازیدیم–اویباکتام **۳۰/۲۰ µg** |
| **غلظت نهایی** | **آزترئونام ۶، سفتازیدیم ۶، اویباکتام ۴ µg/mL** |
| **لوله‌ها** | **GC** (کنترل رشد)، **ATM**، **CZA**، **ATM + CZA** (یک دیسک از هر کدام) |
| **روش** | لوله‌ها و دیسک‌ها هم‌دمای اتاق ← افزودن دیسک‌ها ← ورتکس ملایم ← **رهاسازی ۳۰–۶۰ دقیقه** در دمای اتاق ← افزودن **۲۵ µL** سوسپانسیون ۰٫۵ مک‌فارلند (نهایی ≈ **۷٫۵ × ۱۰⁵ CFU/mL**) ← کشت خلوص ← ورتکس آرام، شل کردن درپوش |
| **انکوباسیون** | **۳۳–۳۵°C**، هوا، **۱۶–۲۰ ساعت** |
| **تفسیر** | GC باید کدر باشد. هر **کدورت با چشم = رشد**. **بدون رشد = حساس**؛ **رشد = غیرحساس** |
| **الگوی ناسازگار** (مثلاً ATM بدون رشد ولی CZA و ATM+CZA رشد) | تکرار (آلودگی، غلظت، **ناسازگاری دیسک/محیط سازنده**، خطای تلقیح) |

## ۴. روش‌های جایگزین (غیر CLSI)
- **نوار گرادیان روی هم (Strip stacking):** نوار CZA ۱۰ دقیقه گذاشته و برداشته می‌شود؛ نوار آزترئونام در همان جا؛ MIC آزترئونام در حضور اویباکتام خوانده می‌شود.
- **نوار ATM روی MHA حاوی اویباکتام ۴ mg/L** یا **CZA ۸/۴**.
- **دیسک‌های مجاور** (هم‌افزایی).
- نتیجه با نقاط برش **آزترئونام** (CLSI: S ≤ ۴ برای Enterobacterales) تفسیر می‌شود؛ ⚠️ این روش‌ها استاندارد CLSI نیستند.

## ۵. ارتباط با درمان (IDSA 2026)
- **NDM-E:** **آزترئونام–اویباکتام** یا **سفیدروکول** ترجیحی؛ در نبود آزترئونام–اویباکتام ← **CZA + آزترئونام**.
- ***S. maltophilia***: آزترئونام–اویباکتام **ترجیحاً همراه داروی دوم** = جایگزین؛ **سفیدروکول تک‌دارویی** = ترجیحی.
- KPC و OXA-48: آزترئونام–اویباکتام **جایگزین** است.
