# CLSI در برابر EUCAST

> مبنا: CLSI M100-Ed36 (2026) و EUCAST Breakpoint Tables v16.1 (2026).

## ۱. قاعدهٔ طلایی
> **در یک گزارش و برای یک ایزوله، فقط یک استاندارد.** روش آزمایش (محیط، دیسک، تلقیح) هم باید با همان استاندارد هماهنگ باشد. دیسک‌ها و محیط‌های دو استاندارد گاه متفاوت‌اند (مثلاً محتوای دیسک یا محیط سخت‌رشدها)، و نقاط برش یکی را نمی‌توان با روش دیگری به کار برد.

## ۲. مقایسهٔ ساختاری

| ویژگی | CLSI M100-Ed36 | EUCAST v16.1 |
|---|---|---|
| ماهیت | سازمان غیرانتفاعی؛ اسناد **پولی** | کمیتهٔ اروپایی (ESCMID)؛ اسناد **رایگان** |
| به‌روزرسانی | سالانه (ژانویه) | سالانه (ژانویه) + نسخه‌های میانی (مثلاً v16.1، ژوئن ۲۰۲۶) |
| واحد MIC | µg/mL | mg/L (عدداً یکسان) |
| نمایش نقطهٔ برش | S ≤ x؛ I؛ R ≥ y (دیسک: S ≥ ، R ≤) | **S ≤ x؛ R > y** (دیسک: S ≥ ، R <)؛ I = بین آن دو (نوشته نمی‌شود) |
| دسته‌ها | S، SDD، I (و I^)، R، NS | S، I (حساس با مواجههٔ افزایش‌یافته)، R |
| مبنای دوز | جدول «Table 2 Dosages» برای نقاط برش جدید/بازنگری‌شده | «Dosages»: دوز **استاندارد** و **بالا** برای همهٔ داروها |
| عدم قطعیت فنی | توصیه‌های تأییدی پراکنده (مثلاً «MIC تأییدی برای هالهٔ ۲۰–۲۲ mm سفتازیدیم–اویباکتام») | **ATU** رسمی (MIC و/یا محدودهٔ هاله) |
| داروهای «بی‌اثر» | «Warning» و Appendix B (مقاومت ذاتی) | **«–»** (گزارش R بدون تست) و Expected Resistant Phenotypes |
| شواهد ناکافی | بدون نقطهٔ برش؛ ارجاع به FDA STIC | **«IE»** + راهنمای «When there are no breakpoints» |
| ECOFF | ECV (Appendix F)؛ گاه برای گزارش (مثلاً آزیترومایسین *Shigella*) | ECOFF (پایگاه دادهٔ آنلاین MIC)؛ نقاط برش **در پرانتز** |
| انتخاب داروها | **Tables 1A–1J**: سطوح ۱ تا ۴ + «U» (ادرار) | جدول انتخاب ندارد؛ لیست داروها بر اساس کلاس + Expert Rules |
| محیط سخت‌رشدها | HTM (هموفیلوس، و MH-F برای برخی داروها)، MHA + ۵٪ خون گوسفند، GC agar + مکمل (گنوکوک)، CAMHB-LHB | **MH-F** (MH + ۵٪ خون اسب دفیبرینه + ۲۰ mg/L β-NAD) برای استرپتوکوک‌ها، هموفیلوس، موراکسلا، لیستریا، پاستورلا، کامپیلوباکتر و… |
| دیسک دیفیوژن بی‌هوازی | ندارد (فقط MIC، M11) | **دارد** (FAA-HB) برای گونه‌های منتخب |
| AST سریع از کشت خون | دیسک مستقیم (Tables 3F-1 تا 3F-4): Enterobacterales، *P. aeruginosa*، *Acinetobacter* | **RAST** (۴، ۶، ۸، ۱۶–۲۰ ساعت) برای گونه‌های منتخب |
| مایکوباکتری | M24 (سند جدا) | جدول *M. tuberculosis* (روش مرجع BMD در 7H9) |

## ۴. انتخاب استاندارد در آزمایشگاه
- معیارها: الزام ملی، دسترسی به اسناد (EUCAST رایگان)، سازگاری دیسک‌ها/محیط‌ها/سیستم خودکار، و آموزش.
- اگر سیستم خودکار با یک استاندارد کالیبره شده است، تغییر استاندارد **اعتبارسنجی مجدد** می‌خواهد.
- برای ارگانیسم‌هایی که یک استاندارد نقطهٔ برش ندارد (مثلاً *H. pylori* که در CLSI فقط کلاریترومایسین دارد)، استفاده از استاندارد دیگر برای **آن ارگانیسم** مجاز است، با ذکر در گزارش.
