# ۱۴. کوکسی‌های گرم مثبت کاتالاز منفی

## دامنه
| گروه | جنس/گونه‌های مهم |
|---|---|
| **استرپتوکوک‌های β-همولیتیک** | *S. pyogenes* (A)، *S. agalactiae* (B)، *S. dysgalactiae* subsp. *equisimilis* (SDSE؛ C/G)، *S. equi* (C، زئونوز)، *S. anginosus* group (کلنی ریز) |
| ***S. pneumoniae*** | |
| **استرپتوکوک‌های ویریدانس** | گروه‌های *mitis*، *sanguinis*، *salivarius*، *mutans*، *anginosus*؛ گروه **_S. bovis_/_gallolyticus_** |
| ***Enterococcus*** | *E. faecalis*، *E. faecium*؛ *E. gallinarum*، *E. casseliflavus* (*vanC*) |
| **جنس‌های مشابه** | *Aerococcus* (*A. urinae*، *A. viridans*، *A. sanguinicola*)، ***Abiotrophia*/*Granulicatella*** (NVS)، *Gemella*، *Lactococcus*، *Leuconostoc*، *Pediococcus*، *Globicatella*، *Weissella* |

## اهمیت بالینی (خلاصه)
- **GAS:** فارنژیت، سلولیت، **فاشئیت نکروزان**، **STSS**؛ عوارض غیرچرکی (تب روماتیسمی، گلومرولونفریت). **همیشه حساس به پنی‌سیلین**.
- **GBS:** **سپسیس و مننژیت نوزادی** (زودرس/دیررس)، عفونت پس از زایمان، عفونت در سالمندان و دیابتی‌ها؛ غربالگری بارداری.
- **SDSE (C/G):** شبیه GAS در بزرگسالان (سلولیت، باکتریمی).
- **پنوموکوک:** پنومونی، مننژیت، باکتریمی، اوتیت/سینوزیت.
- **ویریدانس:** **اندوکاردیت دریچهٔ طبیعی**؛ باکتریمی در **نوتروپنی** (گروه *mitis*، اغلب مقاوم به پنی‌سیلین)؛ *S. anginosus* group ← **آبسه** (مغز، کبد، ریه).
- ***S. gallolyticus*** (*S. bovis* biotype I) ← اندوکاردیت + **ارتباط با سرطان کولون** (کولونوسکوپی).
- **انتروکوک:** UTI، عفونت شکمی، باکتریمی، **اندوکاردیت**؛ VRE.
- ***Abiotrophia*/*Granulicatella*:** **اندوکاردیت کشت‌منفی**.
- ***Aerococcus urinae*:** UTI در **سالمندان مرد**، باکتریمی، اندوکاردیت.
