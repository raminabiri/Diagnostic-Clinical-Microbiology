📚 محتوای این مخزن
این پروژه یک مرجع کامل و گام‌به‌گام برای آموزش تشخیص آزمایشگاهی عفونت‌های ادراری (UTI) از دیدگاه میکروب‌شناسی بالینی است.

سرفصل‌های اصلی
بخش	توضیحات
پاتوفیزیولوژی عفونت ادراری	مکانیسم‌های عفونت، عوامل خطر، پاتوژنز و طبقه‌بندی UTI ساده و پیچیده
نمونه‌گیری ادرار	انواع روش‌ها (MSU، سوپراپوبیک، کاتتر، کیسه کودکان)، شرایط حمل و نگهداری، معیارهای پذیرش و رد نمونه
بررسی مستقیم و لام	Wet mount، رنگ‌آمیزی گرم مستقیم، شناسایی WBC، RBC، اپی‌تلیال، باکتری، قارچ و تریکوموناس
آنالیز ادرار (دیپ‌استیک)	تفسیر LE، نیتریت، خون، پروتئین و سایر پارامترها در ارتباط با عفونت
کشت ادرار	محیط‌های کشت (Blood agar، MacConkey، CLED، Chromogenic)، روش کشت با لوپ کالیبره، انکوباسیون و شناسایی کلونی‌ها
شمارش کلونی (CFU/mL)	محاسبه CFU/mL، آستانه‌های تفسیر بر اساس نوع بیمار و نمونه، تمایز آلودگی از عفونت واقعی
آنتی‌بیوگرام ادرار	انتخاب پنل دیسک بر اساس گونه باکتری، محل عفونت، عوامل خطر مقاومت، محدودیت‌های بیمار (بارداری، کلیه، آلرژی) و قواعد گزارش
تطبیق نتایج و گزارش‌دهی	الگوریتم تفسیر ترکیبی دیپ‌استیک، میکروسکوپی، کشت و آنتی‌بیوگرام؛ گزارش نهایی و کامنت‌های بالینی

🧠 اصول طراحی آموزشی
این پروژه بر اساس این اصول طراحی شده است:

تمرکز بر میکروب‌شناسی: حذف مباحث بیوشیمیایی و پاتولوژی غیرمرتبط با تشخیص میکروبی.

الگوریتم‌محور: استفاده از فلوچارت و جدول تصمیم‌گیری برای انتخاب پنل آنتی‌بیوگرام.

مبتنی بر استاندارد: ارجاع به CLSI یا EUCAST برای breakpoints و تفسیر S/I/R.

مورد-محور: سناریوهای بالینی واقعی برای تمرین تفسیر ترکیبی نتایج.

آماده چاپ: جدول‌های خلاصه برای نصب در آزمایشگاه و استفاده روزمره.
