۲. الگوریتم تفسیر گام‌به‌گام
گام ۱: بررسی دیپ‌استیک (LE و نیتریت)
| الگوی دیپ‌استیک | احتمال UTI          | اقدام بعدی                                                                |
| --------------- | ------------------- | ------------------------------------------------------------------------- |
| LE− و نیتریت−   | پایین (<۵٪)         | در صورت علائم خفیف: احتمالاً UTI نیستدر صورت علائم شدید: میکروسکوپی + کشت |
| LE+ و نیتریت−   | متوسط (۳۰–۵۰٪)      | میکروسکوپی (WBC، باکتری) + کشت                                            |
| LE− و نیتریت+   | متوسط-بالا (۵۰–۷۰٪) | کشت ادرار (احتمال باکتری غیرتبدیل‌کننده نیتریت)                           |
| LE+ و نیتریت+   | بالا (>۸۰٪)         | کشت ادرار برای تأیید و آنتی‌بیوگرام                                       |

گام ۲: بررسی میکروسکوپی رسوب
| یافته میکروسکوپی              | تفسیر                      | هم‌خوانی با دیپ‌استیک             |
| ----------------------------- | -------------------------- | --------------------------------- |
| WBC≥۱۰ /HPF + باکتری↑         | پیوری باکتریال → UTI محتمل | LE+ تأیید می‌کند                  |
| WBC≥۱۰ /HPF + باکتری−         | استریل پیوری               | LE+ ولی نیتریت− معمولاً؛ کشت منفی |
| RBC↑ + کست RBC                | گلومرولونفریت              | خون+++، پروتئین+++، LE−           |
| اپی‌تلیال سکواموس↑ (>۱۰ /LPF) | آلودگی نمونه               | کشت مختلط محتمل                   |
| باکتری↑ بدون WBC              | باکتریوری بدون التهاب      | LE−، کشت مثبت ولی بدون علائم      |

گام ۳: بررسی رنگ‌آمیزی گرم
| یافته گرم                  | تفسیر                             | اقدام                             |
| -------------------------- | --------------------------------- | --------------------------------- |
| باسیل گرم‌منفی زیاد (+++)  | E.coli، Klebsiella، Proteus محتمل | کشت روی MAC/CLED → آنتی‌بیوگرام   |
| کوکی گرم‌مثبت خوشه‌ای      | S.saprophyticus، S.aureus         | کشت روی Blood agar → تست کوآگولاز |
| کوکی گرم‌مثبت زنجیره‌ای    | Enterococcus، Streptococcus       | کشت روی Blood agar → تست کاتالاز  |
| باکتری کم + اپی‌تلیال زیاد | آلودگی نمونه                      | تکرار نمونه‌گیری                  |





گام ۴: بررسی کشت ادرار (CFU/mL و نوع پاتوژن)

| یک پاتوژن ≥۱۰⁵ CFU/mL + LE+ + WBC↑      | UTI قطعی             | "Significant growth of E.coli (≥10⁵ CFU/mL), consistent with UTI" + آنتی‌بیوگرام           |

۴. الگوریتم تصمیم‌گیری نهایی (خلاصه تصویری)
شک به UTI
│
├─ دیپ‌استیک: LE و نیتریت؟
│   ├─ LE− / Nitrite− → احتمال UTI پایین
│   │   └─ علائم خفیف؟ → خیر: رد UTI / بله: میکروسکوپی + کشت
│   ├─ LE+ / Nitrite− → میکروسکوپی + کشت
│   ├─ LE− / Nitrite+ → کشت
│   └─ LE+ / Nitrite+ → کشت + آنتی‌بیوگرام
│
├─ میکروسکوپی: WBC، باکتری، اپی‌تلیال؟
│   ├─ WBC↑ + باکتری↑ → UTI محتمل
│   ├─ WBC↑ + باکتری− → استریل پیوری
│   ├─ اپی‌تلیال↑ → آلودگی نمونه
│   └─ RBC cast + پروتئین+++ → گلومرولونفریت
│
├─ کشت: CFU/mL و نوع پاتوژن؟
│   ├─ یک پاتوژن ≥۱۰⁵ + علائم → UTI قطعی
│   ├─ یک پاتوژن ۱۰³–۱۰⁵ + علائم → UTI محتمل
│   ├─ یک پاتوژن ≥۱۰⁵ بدون علائم → باکتریوری بدون علامت (درمان فقط در بارداری/قبل جراحی)
│   └─ رشد مختلط (>۲ گونه) → آلودگی نمونه
│
└─ گزارش نهایی + آنتی‌بیوگرام (در صورت UTI)
