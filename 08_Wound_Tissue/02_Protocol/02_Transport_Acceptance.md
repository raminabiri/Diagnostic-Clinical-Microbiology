# پروتکل ۲: انتقال، پذیرش و رد — زخم، بافت، استخوان، ایمپلنت

## ۱. انتقال

| نمونه | ظرف | دما | حداکثر زمان |
|---|---|---|---|
| بافت/استخوان | ظرف استریل (± چند قطره سالین استریل برای جلوگیری از خشکی) | دمای اتاق | **≤ ۲ ساعت**؛ برای بی‌هوازی بهتر: ≤ ۳۰ دقیقه یا محیط انتقال بی‌هوازی |
| بافت (تأخیر) | محیط انتقال بی‌هوازی | دمای اتاق | ≤ ۲۴ ساعت |

| آسپیره در سرنگ (درپوش، بدون سوزن) | | دمای اتاق | ≤ ۲ ساعت |
| بطری کشت خون (تلقیح‌شده در اتاق عمل) | | دمای اتاق | طبق ماژول ۰۱ |
| ESwab | | دمای اتاق/۴ °C | ≤ ۴۸ ساعت |

| نمونهٔ PCR (16S) | ظرف استریل/منجمد | ۴ °C یا ۲۰– تا ۷۰– °C | |

## ۲. پذیرش
- **تعداد و شماره‌گذاری** نمونه‌های PJI (همه با هم ثبت شوند تا تفسیر «≥ ۲ از ۵» ممکن باشد)
- محل، نوع ایمپلنت، آنتی‌بیوتیک
- درخواست‌های ویژه (AFB، قارچ، بروسلا، طولانی)

## ۳. معیار رد و اقدام

| مشکل | اقدام |
|---|---|
| **سواب برای PJI یا استئومیلیت** | پردازش با **قید جدی** («سواب برای تشخیص PJI/استئومیلیت مناسب نیست»)؛ آموزش جراحی |
| **سواب سطحی پای دیابتی پیش از دبریدمان** | رد یا قید + درخواست بافت |
| **سواب سینوس/فیستول** برای استئومیلیت | قید (هم‌خوانی ضعیف) |
| بافت/استخوان در **فرمالین** | رد (میکروب‌شناسی)؛ پیشنهاد PCR روی بلوک پارافینی |
| کشت **زخم تازهٔ تروماتیک بدون عفونت** | رد |
| ⛔ هیچ نمونهٔ **جراحی/استخوانی** به‌علت تأخیر رد نشود | قید و پردازش |
| ایمپلنت در ظرف غیراستریل | قید (آلودگی) |
| تنها **یک نمونهٔ بافتی** برای PJI | پردازش؛ پیام: «تفسیر ارگانیسم‌های کم‌حدت با یک نمونه محدود است؛ ۳–۵ نمونه توصیه می‌شود.» |

## ۴. اولویت‌بندی بافت/استخوان کوچک
1. **کشت باکتری** (هوازی + بی‌هوازی، یا BCB)
2. **بافت‌شناسی** (بخش پاتولوژی؛ نمونهٔ جدا)
3. AFB/بروسلا (در ظن)
4. قارچ
5. PCR 16S (باقیمانده/منجمد)
