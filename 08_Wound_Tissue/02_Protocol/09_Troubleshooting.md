# پروتکل ۹: خطاهای رایج و عیب‌یابی — زخم، بافت، استخوان، ایمپلنت

## ۱. پیش‌آزمایشی
| خطا | پیامد | اصلاح |
|---|---|---|
| سواب برای PJI/استئومیلیت | حساسیت پایین، آلودگی | ۳–۵ بافت؛ سونیکیشن |
| یک نمونهٔ بافتی | تفسیر CoNS ناممکن | ≥ ۳ (ترجیحاً ۵) |
| ابزار مشترک برای همهٔ نمونه‌ها | **آلودگی متقاطع** ← «≥ ۲ نمونهٔ مثبت» کاذب | ابزار جدا |
| آنتی‌بیوتیک پیش از نمونه‌گیری | کشت منفی | دورهٔ بدون آنتی‌بیوتیک؛ پروفیلاکسی پس از نمونه |
| سواب سطحی پای دیابتی پیش از دبریدمان | گزارش کلونیزه‌کننده‌ها | کورتاژ/بیوپسی پس از دبریدمان |
| سواب سینوس برای استئومیلیت | عدم هم‌خوانی با استخوان | بیوپسی استخوان |
| بافت در فرمالین | کشت ناممکن | دو ظرف |
| ایمپلنت در کیسهٔ نشتی | آلودگی/خطر | ظرف سخت |

## ۲. آزمایشی
| خطا | پیامد | اصلاح |
|---|---|---|
| انکوباسیون ۵ روزه در PJI شانه | از دست رفتن *C. acnes* | ۱۴ روز (بی‌هوازی/براث) |
| عدم استفاده از BCB/براث | حساسیت کمتر | BCB برای بافت هموژنیزه |
| شناسایی CoNS فقط «CoNS» بدون گونه/AST در هر نمونه | مقایسهٔ ایزوله‌ها ناممکن | MALDI + AST |
| SCV *S. aureus* گزارش‌شده به‌عنوان CoNS | درمان اشتباه | MALDI؛ انکوباسیون طولانی‌تر |
| آلودگی آزمایشگاهی در هموژنیزه | مثبت کاذب | کنترل منفی پردازش؛ BSC؛ بیدهای یک‌بارمصرف |
| هموژنیزه‌کردن طولانی در هوای آزاد | از دست رفتن بی‌هوازی‌ها | سرعت |
| *K. kingae* روی SBA فقط | از دست رفتن | BCB + PCR |
| بیوپسی مهره بدون AFB/بروسلا در ایران | از دست رفتن TB/بروسلوز | پنل بر اساس اپیدمیولوژی |
| کمّی سوختگی بدون وزن بافت | CFU/g نامعتبر | وزن‌کردن |
| شمارش سونیکیشن بدون محاسبهٔ حجم/تغلیظ | آستانهٔ غلط | پروتکل مکتوب |

## ۳. پس‌آزمایشی
| خطا | پیامد | اصلاح |
|---|---|---|
| گزارش CoNS تک‌نمونه بدون جملهٔ آلودگی | درمان طولانی غیرضروری | جملهٔ تفسیری |
| عدم جمع‌بندی تجمیعی نمونه‌های PJI | تفسیر دشوار برای جراح | گزارش تجمیعی |
| گزارش نهایی منفی پیش از ۱۴ روز | از دست رفتن *C. acnes* | گزارش مقدماتی |
| عدم گزارش ریفامپین برای استافیلوکوک ایمپلنت | درمان بیوفیلم ناقص | پنل ایمپلنت |
| نگهداری‌نکردن ایزوله‌ها | امکان مقایسه در عود از بین می‌رود | ۳ ماه نگهداری |
