# پروتکل ۸: کنترل کیفی و ایمنی زیستی — زخم، بافت، استخوان، ایمپلنت

## ۱. QC
| مورد | کنترل |
|---|---|
| محیط‌ها (SBA، CA، MAC، بی‌هوازی، براث) | مانند ماژول‌های ۰۱ و ۰۷؛ براث تیوگلیکولات: *B. fragilis* ATCC 25285 + *S. aureus* ATCC 25923 |
| **کنترل منفی پردازش** (Sterility/procedural blank) | **روزانه یا با هر سری PJI**: براث/سالین استریل از همان مسیر هموژنیزه/سونیکیشن ← کشت (تشخیص آلودگی محیطی/ابزار) |
| **هموژنایزر/بیدها/قیچی‌ها** | استریلیزاسیون و پایش (اندیکاتور) |
| **حمام سونیکیشن** | کالیبراسیون توان/فرکانس؛ اعتبارسنجی با سویهٔ بیوفیلم‌ساز (مثلاً *S. epidermidis* ATCC 35984 روی دیسک) |
| انکوباسیون طولانی | پایش خشکی پلیت‌ها (کیسه/رطوبت) |
| بطری‌های کشت خون برای بافت | QC سیستم (ماژول ۰۱) |
| AST | سویه‌های QC استاندارد؛ ریفامپین: *S. aureus* ATCC 25923/29213 |

## ۲. شاخص‌های کیفیت
| شاخص | هدف |
|---|---|
| درصد revisionهای PJI با ≥ ۳ نمونهٔ بافتی | بیش از ۹۰٪ |
| درصد PJIهای ارسال‌شده با سواب | کاهش به نزدیک صفر |
| نرخ «آلودگی» (تک‌نمونه با CoNS/*C. acnes*) | پایش (افزایش ← بررسی اتاق عمل/آزمایشگاه) |
| رشد در کنترل منفی پردازش | صفر |
| درصد کشت‌های پای دیابتی از بافت (در برابر سواب) | افزایش |

## ۳. ایمنی زیستی ☣️
| موقعیت | الزام |
|---|---|
| هموژنیزه/سونیکیشن | **BSC** (آئروسل)؛ ظرف دربسته |
| ابزار برنده (قیچی استخوان، اسکالپل) | احتیاط؛ ظرف تیز |
| ***Brucella*** (اسپوندیلیت، PJI در ایران) | ☣️ **BSL-3** برای کشت؛ بیوپسی‌های مشکوک در BSC؛ ⛔ سیستم خودکار؛ مواجهه ← پروفیلاکسی (ماژول ۰۱) |
| ***M. tuberculosis*** | BSL-3 برای کشت |
| *A. baumannii*/CRE سوختگی | BSL-2؛ ضدعفونی سطوح (پایداری محیطی بالا) |
| بافت‌های پریون (جراحی مغز؛ نادر) | خارج از دامنه (دستورالعمل ویژه) |
