# تئوری: عفونت‌های زخم، بافت عمقی، استخوان و ایمپلنت

## ۱. عفونت محل جراحی (SSI)

| نوع (CDC/NHSN) | تعریف (ظرف ۳۰ روز، یا ۹۰ روز با ایمپلنت) | عوامل |
|---|---|---|
| **سطحی** | پوست و زیرجلد برش | *S. aureus*، CoNS، استرپتوکوک‌ها |
| **عمقی** | فاسیا و عضله | *S. aureus*، Enterobacterales، انتروکوک |
| **اندام/فضا** | هر ناحیهٔ عمقی‌تر (آبسهٔ داخل‌شکمی، مدیاستینیت، PJI) | وابسته به نوع جراحی: پاک (پوست: استافیلوکوک)، تمیز–آلوده (روده: گرم منفی‌ها، بی‌هوازی‌ها، انتروکوک) |

> نقش آزمایشگاه: نمونهٔ **عمقی/جراحی**، نه سواب سطحی؛ داده‌ها برای **نظام مراقبت SSI** و کنترل عفونت.

## ۲. زخم‌های تروماتیک
| زخم | عوامل |
|---|---|
| تازه آلوده به خاک | *Clostridium*، *Bacillus*، Enterobacterales، (*C. tetani*: تشخیص بالینی) |
| زخم‌های جنگی/انفجار | ***A. baumannii*** (MDR)، *P. aeruginosa*، *K. pneumoniae*، قارچ‌های محیطی (موکورمایکوز) |
| شکستگی باز | *S. aureus*، گرم منفی‌ها، *Clostridium* |
| آب شیرین/شور | *Aeromonas*، *Vibrio*، *Shewanella* (ماژول ۰۷) |

## ۳. زخم‌های مزمن
| زخم | ویژگی میکروبی |
|---|---|
| **پای دیابتی** | خفیف/زودرس: **کوکسی‌های گرم مثبت** (*S. aureus*، استرپتوکوک‌های بتا)؛ مزمن/درمان‌شده: **چندمیکروبی** (+ Enterobacterales، *P. aeruginosa*، **بی‌هوازی‌ها** در نکروز/ایسکمی)؛ **استئومیلیت** در حدود ۲۰٪ عفونت‌ها |
| زخم فشاری (بستر) | چندمیکروبی، بی‌هوازی‌ها (ناحیهٔ ساکرال: فلور روده) |
| زخم وریدی | کلونیزاسیون گسترده؛ عفونت فقط با بالین |

> **کلونیزاسیون ≠ عفونت.** همهٔ زخم‌های مزمن کلونیزه‌اند. **تشخیص عفونت بالینی است** (IWGDF/IDSA): ≥ ۲ نشانهٔ التهاب (قرمزی، گرمی، تورم، درد، ترشح چرکی) ← کشت فقط از زخم‌های **عفونی بالینی**.

## ۴. سوختگی
- روزهای اول: گرم مثبت‌ها (پوست)؛ پس از حدود ۵ روز: گرم منفی‌ها (***P. aeruginosa***، *A. baumannii*، *K. pneumoniae*)؛ بعدتر قارچ‌ها.
- **عفونت مهاجم زخم سوختگی:** باکتری در **بافت زنده زیر اسکار** (بافت‌شناسی = استاندارد) ± **کشت کمّی ≥ ۱۰⁵ CFU/g بافت**.
- ریسک سپسیس بالا؛ کنترل عفونت حیاتی.

## ۵. استئومیلیت

| نوع | سن/زمینه | عوامل |
|---|---|---|
| **هماتوژن کودکان** | متافیز استخوان‌های بلند | ***S. aureus*** (± MRSA، PVL)، GAS، ***Kingella kingae*** (کمتر از ۴ سال؛ کشت دشوار)، *S. pneumoniae*؛ **سیکل‌سل: *Salmonella*** |
| **مهره‌ای (اسپوندیلودیسکیت) بزرگسالان** | | *S. aureus*، Enterobacterales (منشأ ادراری)، استرپتوکوک‌ها، **CoNS/*C. acnes*** (پس از جراحی)، ***Brucella*** (ایران: شایع، ناحیهٔ کمری)، ***M. tuberculosis*** (بیماری پات، ناحیهٔ توراسیک) |
| **مجاورتی** (پای دیابتی، زخم فشاری) | | چندمیکروبی |
| **پس از تروما/شکستگی/جراحی (FRI)** | | *S. aureus*، CoNS، گرم منفی‌ها |
| **مزمن** | سکستروم، فیستول | *S. aureus*، *P. aeruginosa*، بی‌هوازی‌ها |
| معتاد تزریقی | ستون فقرات، مفاصل ساکروایلیاک/استرنوکلاویکولار | *S. aureus*، *P. aeruginosa* |

## ۶. عفونت مفصل مصنوعی (PJI)

| نوع (زمان پس از جراحی) | پاتوژنز | عوامل |
|---|---|---|
| **زودرس** (کمتر از ۳ ماه) | تلقیح حین جراحی (ارگانیسم‌های پرحدت) | *S. aureus*، گرم منفی‌ها، چندمیکروبی |
| **تأخیری** (۳ تا ۱۲–۲۴ ماه) | تلقیح حین جراحی (کم‌حدت) | **CoNS** (*S. epidermidis*)، ***C. acnes*** (به‌ویژه **شانه**)، انتروکوک |
| **دیررس** (بیش از ۱۲–۲۴ ماه) | **هماتوژن** | *S. aureus*، استرپتوکوک‌ها، گرم منفی‌ها |

- **بیوفیلم** روی ایمپلنت ← ارگانیسم‌ها **کم‌تعداد، با رشد کند، و فنوتیپ‌های تغییریافته (SCV)** ← نیاز به **چند نمونهٔ بافتی، سونیکیشن، انکوباسیون طولانی**.
- **PJI کشت‌منفی** (۷–۱۵٪): آنتی‌بیوتیک قبلی، ارگانیسم‌های سخت‌رشد (*C. acnes*، *Mycoplasma*، قارچ‌ها، مایکوباکتری‌ها، بروسلا)، روش نامناسب.

## ۷. علائم بالینی
- **SSI:** قرمزی، ترشح، باز شدن زخم، تب.
- **پای دیابتی:** علائم التهاب ممکن است در نوروپاتی/ایسکمی کم باشد؛ **probe-to-bone مثبت** ← استئومیلیت محتمل.
- **استئومیلیت:** درد موضعی، تب (هماتوژن)، افزایش ESR/CRP؛ MRI.
- **PJI:** درد مداوم، شل‌شدن پروتز، **سینوس ترشحی** (معیار اصلی)، تورم، تب (زودرس/هماتوژن).
- **بروسلوز استخوانی:** کمردرد، تب موجی، تماس با دام؛ ساکروایلییت.

## ۸. تشخیص بالینی (خلاصه)

| موقعیت | آزمایش‌های کلیدی |
|---|---|
| SSI | کشت **بافت/آسپیرهٔ عمقی** حین دبریدمان |
| پای دیابتی عفونی | **بافت پس از دبریدمان** (کورتاژ قاعدهٔ زخم/بیوپسی)؛ ⛔ سواب سطحی پیش از دبریدمان؛ استئومیلیت: **بیوپسی استخوان** (کشت + بافت‌شناسی) |
| استئومیلیت مهره‌ای | **کشت خون** (مثبت در حدود ۵۰–۷۰٪) + **بیوپسی CT-guided** (کشت باکتری، AFB، قارچ، بافت‌شناسی) + **سرولوژی بروسلا** (ایران) |
| PJI | آسپیرهٔ مفصل (شمارش سلول، کشت، ماژول ۰۹) + CRP/ESR + **۳–۵ نمونهٔ بافت پری‌پروستتیک** حین جراحی + **سونیکیشن ایمپلنت** + بافت‌شناسی (نوتروفیل در میدان HPF) |
| سوختگی | بیوپسی کمّی + بافت‌شناسی در ظن عفونت مهاجم |
| شکستگی باز | ⛔ کشت روتین زخم پیش از دبریدمان (پیش‌بینی‌کننده نیست) |

## ۹. اهمیت
- این عفونت‌ها **درمان طولانی (۶ هفته تا ۳ ماه یا بیشتر)** و اغلب **جراحی** دارند ← دقت میکروبی و AST صحیح تعیین‌کننده است.
- **نمونهٔ نامناسب** (سواب سطحی) ← درمان طولانی علیه کلونیزه‌کننده‌ها و از دست رفتن پاتوژن واقعی.
