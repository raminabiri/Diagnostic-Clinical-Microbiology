# آنتی‌بیوگرام — زخم، بافت، استخوان، ایمپلنت: اصول

> 📚 **مرجع مشترک روش‌ها و مکانیسم‌های مقاومت:** بخش [AST](../../AST/README.md): روش‌های فنوتیپی، بتالاکتامازها (ESBL، AmpC، کارباپنماز)، سایر مقاومت‌ها، QC، مقایسهٔ نقاط برش CLSI M100-Ed36 و EUCAST v16.1، و پیوند با درمان (IDSA 2026).


## ۱. ویژگی‌های AST در عفونت‌های استخوان و ایمپلنت
1. **درمان طولانی و اغلب خوراکی** (کارآزمایی **OVIVA**: پس از دورهٔ کوتاه وریدی، خوراکی غیرکهتر از وریدی) ← گزارش **داروهای خوراکی با فراهمی زیستی بالا** اهمیت دارد: فلوروکینولون‌ها، TMP-SMX، لینزولید، داکسی‌سایکلین، کلیندامایسین، ریفامپین (ترکیبی)، (آموکسی‌سیلین/آموکسی‌کلاو برای استرپتوکوک/انتروکوک).
2. **بیوفیلم:** برای استافیلوکوک‌ها در ایمپلنت باقیمانده (DAIR یا یک‌مرحله‌ای)، **ریفامپین** (همیشه ترکیبی) نقش کلیدی دارد؛ برای گرم منفی‌ها **فلوروکینولون‌ها** (فعال علیه بیوفیلم).
3. **CoNS:** AST کامل (اغلب MRSE و چندمقاومتی).
4. **ونکومایسین MIC** برای استافیلوکوک‌ها؛ **داپتومایسین MIC** (گزینهٔ وریدی).
5. **چندمیکروبی** (پای دیابتی): AST پاتوژن‌های اصلی، نه همهٔ ارگانیسم‌ها.

## ۲. داروهای کلیدی و ملاحظات

| دارو | کاربرد | ملاحظهٔ آزمایشگاهی |
|---|---|---|
| **ریفامپین** | استافیلوکوک (و *C. acnes*) با ایمپلنت | **هرگز تک‌دارو** (مقاومت سریع)؛ گزارش با تذکر؛ مقاومت ← پیامد بدتر DAIR |
| **فلوروکینولون‌ها** (لووفلوکساسین، سیپروفلوکساسین، موکسی‌فلوکساسین) | گرم منفی‌ها (بیوفیلم)، همراه ریفامپین برای استافیلوکوک | سیپروفلوکساسین برای استافیلوکوک ضعیف‌تر است؛ لووفلوکساسین ارجح |
| **TMP-SMX** | استافیلوکوک، Enterobacterales (خوراکی) | |
| **داکسی‌سایکلین/مینوسایکلین** | استافیلوکوک (CLSI: تتراسایکلین S ⇒ داکسی/مینو S) | |
| **لینزولید** | MRSA، VRE (خوراکی) | سمیت در دورهٔ طولانی (بیش از ۲ هفته) — بالینی |
| **کلیندامایسین** | استافیلوکوک، استرپتوکوک، بی‌هوازی‌ها | **D-test**؛ مقاومت بی‌هوازی‌ها رو به افزایش |
| **داپتومایسین** | MRSA/CoNS/VRE (وریدی) | MIC |
| **سفازولین/نافسیلین** | MSSA | از اکساسیلین استنتاج |
| **بتالاکتام + بازدارنده** | چندمیکروبی/پای دیابتی | |
| **مترونیدازول** | بی‌هوازی‌ها | ⛔ *C. acnes* (مقاوم ذاتی) |
| **فسفومایسین وریدی** | (ترکیبی؛ اروپا) | EUCAST نقطهٔ برش IV |
