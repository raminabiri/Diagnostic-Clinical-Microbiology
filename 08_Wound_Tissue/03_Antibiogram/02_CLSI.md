# آنتی‌بیوگرام — زخم، بافت، استخوان، ایمپلنت بر اساس CLSI

> **مرجع:** CLSI M100 (نسخهٔ جاری)، M11 (بی‌هوازی‌ها شامل *C. acnes*)، M45 (*Corynebacterium*، *Kingella*، *Brucella*). ⚠️ با نسخهٔ جاری تطبیق دهید.

## ۱. پنل بر اساس ارگانیسم

| ارگانیسم | پنل | نکته |
|---|---|---|
| ***S. aureus*/CoNS** (2C) | سفوکسیتین، ونکومایسین (MIC)، **ریفامپین**، **لووفلوکساسین/موکسی‌فلوکساسین**، **TMP-SMX**، **تتراسایکلین** (⇒ داکسی/مینو)، کلیندامایسین (+ D-test)، لینزولید، داپتومایسین (MIC)، سفتارولین | CoNS ونکومایسین: S ≤ 4 |
| استرپتوکوک‌های بتا (2H-1) | (پنی‌سیلین: تست اختیاری)، سفتریاکسون، کلیندامایسین (+ D-test)، اریترومایسین، ونکومایسین، لووفلوکساسین | |
| ویریدانس (2H-2) | پنی‌سیلین (MIC)، سفتریاکسون، ونکومایسین | |
| ***Enterococcus*** (2D) | آمپی‌سیلین، ونکومایسین، (HLAR در ترکیب)، لینزولید، داپتومایسین (MIC)، (تتراسایکلین/داکسی، فقط با احتیاط) | ⛔ سفالوسپورین‌ها، TMP-SMX |
| **Enterobacterales** (2A) | سیپروفلوکساسین/لووفلوکساسین، TMP-SMX، سفتریاکسون، سفپیم، پیپ–تازو، آموکسی‌کلاو، ارتاپنم/مروپنم، جنتامایسین/آمیکاسین | |
| ***P. aeruginosa*** (2B-1) | سیپروفلوکساسین/لووفلوکساسین، سفتازیدیم، سفپیم، پیپ–تازو، مروپنم، آزترئونام، توبرامایسین | |
| ***A. baumannii*** (2B-2) | آمپی‌سیلین–سولباکتام، مروپنم، آمیکاسین، سیپروفلوکساسین، TMP-SMX، مینوسایکلین، کولیستین (BMD) | زخم جنگی/سوختگی |

| *B. fragilis* گروه (M11) | مترونیدازول، پیپ–تازو، آمپی‌سیلین–سولباکتام، کارباپنم، کلیندامایسین، موکسی‌فلوکساسین | پای دیابتی/زخم فشاری؛ معمولاً مرجع |
| *Corynebacterium striatum* (M45) | ونکومایسین، پنی‌سیلین، سفتریاکسون، سیپروفلوکساسین، کلیندامایسین، TMP-SMX، تتراسایکلین، ریفامپین، لینزولید، داپتومایسین | |
| *K. kingae* (M45، HACEK) | بتالاکتاماز؛ آمپی‌سیلین، سفتریاکسون | |
| *Brucella* | (روتین نه؛ M45 در مرجع BSL-3) | |

## ۲. انتخاب پنل بر اساس عوامل بیمار

### ۲-۱) سن
| گروه | ملاحظه |
|---|---|
| کودکان (استئومیلیت هماتوژن) | *S. aureus*: سفالکسین/سفازولین (MSSA)، کلیندامایسین (± D-test)، TMP-SMX؛ *K. kingae*: بتالاکتام‌ها؛ ⛔ فلوروکینولون/تتراسایکلین (جز ضرورت) |
| سالمندان (PJI) | پنل ایمپلنت؛ تداخل دارویی ریفامپین (بالینی) |

### ۲-۲) جنس و بارداری
| وضعیت | ملاحظه |
|---|---|
| بارداری | ⛔ فلوروکینولون، تتراسایکلین؛ ریفامپین با احتیاط |
| جنس | تأثیری ندارد |

### ۲-۳) بیماری زمینه‌ای و شرایط
| شرایط | ملاحظه |
|---|---|
| **ایمپلنت باقیمانده (DAIR)** | **ریفامپین** (استافیلوکوک)، **فلوروکینولون** (گرم منفی) |
| **پای دیابتی** | پنل گرم مثبت + گرم منفی؛ بی‌هوازی‌ها (معمولاً تجربی)؛ MRSA در سابقه |
| **سوختگی** | *P. aeruginosa*/*A. baumannii*/*K. pneumoniae* MDR: پنل کامل + کارباپنماز + کولیستین BMD؛ ونکومایسین/لینزولید برای MRSA |
| **زخم جنگی/انفجار** | *A. baumannii* MDR؛ (موکورمایکوز افتراقی) |
| **نارسایی کلیه** | پنل تغییر نمی‌کند |
| **سیکل‌سل** | *Salmonella*: سیپروفلوکساسین (نقاط برش *Salmonella*)، سفتریاکسون، TMP-SMX (⛔ آمینوگلیکوزید/سفالوسپورین نسل ۱–۲) |
| **اسپوندیلیت بروسلایی/سلی** | ارجاع؛ AST مرجع |
| **آلرژی بتالاکتام** | ونکومایسین، داپتومایسین، لینزولید، کلیندامایسین، فلوروکینولون، TMP-SMX |
