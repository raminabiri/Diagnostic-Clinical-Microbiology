# گروه ۴: محیط‌های انتخابی اختصاصی پاتوژن

> وقتی پاتوژن هدف **مشخص** است (مدفوع، تناسلی، تنفسی CF، لژیونلا، سیاه‌سرفه، دیفتری)، محیط اختصاصی آن به کشت اولیه اضافه می‌شود. ترتیب این فایل بر اساس **نوع نمونه** است.

## فهرست
- **الف. مدفوع:** SS · XLD · HE · بریلیانت گرین و DCA · کروموژنیک *Salmonella* · SMAC · TCBS · CIN · کمپیلوباکتر
- **ب. تناسلی:** تایر–مارتین و مشتقات
- **ج. تنفسی:** BCYE · BCSA/OFPBL · سترامید · ریگان–لو و بوردت–ژانگو · تلوریت/تینزدیل و لوفلر
- **د. سایر:** مانیتول نمک

---

# الف. محیط‌های مدفوع (Enteric media)

> اصل مشترک: **مهار گرم مثبت‌ها و کلیفرم‌ها** + **افتراق غیرتخمیرکننده‌های لاکتوز** (*Salmonella*، *Shigella*) + **H₂S** (*Salmonella*). انتخابی بودن از کم به زیاد: **MAC < HE ≈ XLD < SS < BGA**. برای *Shigella* محیط‌های **کمتر انتخابی** (XLD، HE، MAC) بهترند.

## الف۱. SS (Salmonella–Shigella)
| جزء | نقش |
|---|---|
| نمک‌های صفراوی، **بریلیانت گرین**، سیترات | مهار گرم مثبت‌ها و کلیفرم‌ها |
| لاکتوز + **نوترال رد** | تخمیر ← صورتی |
| **تیوسولفات سدیم + سیترات آهن (فریک)** | تولید **H₂S** ← **مرکز سیاه** |

| ظاهر | مثال |
|---|---|
| بی‌رنگ، **مرکز سیاه** | *Salmonella* (اکثر)، *Proteus* (H₂S+) |
| بی‌رنگ، بدون سیاهی | *Shigella*، *S.* Paratyphi A (H₂S منفی)، برخی *S.* Typhi (H₂S ضعیف) |
| صورتی (مهار نسبی) | کلیفرم‌ها |

- QC: *S.* Typhimurium ATCC 14028 (بی‌رنگ، مرکز سیاه)؛ *S. flexneri* ATCC 12022 (بی‌رنگ)؛ *E. coli* ATCC 25922 (مهار نسبی، صورتی)؛ *E. faecalis* ATCC 29212 (مهار).
- ⚠️ **بیش از حد انتخابی برای *Shigella*** (به‌ویژه *S. dysenteriae* و *S. sonnei*) ← به‌تنهایی استفاده نشود.

## الف۲. XLD (Xylose–Lysine–Deoxycholate)
### اساس (منطق سه‌مرحله‌ای)
| جزء | نقش |
|---|---|
| **سدیم دزوکسی‌کولات** | مهار گرم مثبت‌ها |
| **زایلوز**، لاکتوز، ساکارز | تقریباً **همهٔ** Enterobacterales به‌جز ***Shigella*** زایلوز را تخمیر می‌کنند ← اسید ← **زرد** |
| **لیزین** | *Salmonella* پس از مصرف زایلوز، لیزین را **دکربوکسیله** می‌کند ← قلیایی ← **بازگشت به قرمز** |
| تیوسولفات + سیترات آهن آمونیوم | H₂S ← **مرکز سیاه** |
| **فنل رد** | شناساگر (اسید زرد؛ قلیایی قرمز) |

### تفسیر
| ظاهر | تفسیر | مثال |
|---|---|---|
| **قرمز با مرکز سیاه** | زایلوز + سپس لیزین دکربوکسیلاز + H₂S | ***Salmonella*** |
| **قرمز، بدون سیاهی** | زایلوز منفی، لیزین منفی | ***Shigella***، *S.* Paratyphi A، *Providencia* |
| **زرد** | تخمیر لاکتوز/ساکارز (اسید زیاد؛ قلیایی‌سازی لیزین را می‌پوشاند) | *E. coli*، *Klebsiella*، *Enterobacter*، *Citrobacter* |
| زرد با مرکز سیاه | | *Citrobacter freundii*، *Proteus* (برخی) |
| قرمز-صورتی، **بدون** مرکز سیاه، کلنی بزرگ | | *Pseudomonas* |

- QC: *S.* Typhimurium ATCC 14028 (قرمز، مرکز سیاه)؛ *S. flexneri* ATCC 12022 (قرمز)؛ *E. coli* ATCC 25922 (زرد، مهار نسبی)؛ *E. faecalis* ATCC 29212 (مهار).
- ⚠️ *Salmonella* H₂S منفی یا **لاکتوز مثبت** (نادر) به‌صورت قرمز بدون سیاهی یا زرد دیده می‌شوند. پلیت را در **۱۸–۲۴ ساعت** بخوانید (دیرتر ← قلیایی شدن کاذب).

## الف۳. Hektoen Enteric (HE)
| جزء | نقش |
|---|---|
| نمک‌های صفراوی | مهار گرم مثبت‌ها |
| **لاکتوز، ساکارز، سالیسین** | تخمیر ← اسید |
| **بروموتیمول بلو + اسید فوشین** | اسید ← **زرد تا نارنجی**؛ قلیایی ← **آبی-سبز** |
| تیوسولفات + سیترات آهن آمونیوم | H₂S ← مرکز سیاه |

| ظاهر | مثال |
|---|---|
| **آبی-سبز با مرکز سیاه** | *Salmonella* |
| **آبی-سبز** (بدون سیاهی)، مرطوب | *Shigella* |
| **زرد تا صورتی-نارنجی** با هالهٔ صفرا | *E. coli*، *Klebsiella* و سایر تخمیرکننده‌ها |
| سبز-آبی تا قهوه‌ای، مسطح | *Pseudomonas* |

- QC: *S.* Typhimurium ATCC 14028 (آبی-سبز، مرکز سیاه)؛ *S. flexneri* ATCC 12022 (آبی-سبز)؛ *E. coli* ATCC 25922 (زرد-نارنجی، مهار نسبی)؛ *E. faecalis* ATCC 29212 (مهار).

## الف۴. بریلیانت گرین (BGA) و دزوکسی‌کولات–سیترات (DCA)
| محیط | اساس | کاربرد | تفسیر |
|---|---|---|---|
| **BGA** | **بریلیانت گرین** (بسیار انتخابی) + لاکتوز/ساکارز + فنل رد | ***Salmonella* غیرتیفوئیدی** (به‌ویژه پس از غنی‌سازی) | *Salmonella*: **صورتی-قرمز** روی زمینهٔ قرمز؛ تخمیرکننده‌ها: زرد-سبز با هالهٔ زرد. ⚠️ ***S.* Typhi و *Shigella* مهار می‌شوند** |
| **DCA** | دزوکسی‌کولات + سیترات + لاکتوز + نوترال رد + سیترات آهن | *Salmonella* و *Shigella* | بی‌رنگ (± مرکز سیاه برای *Salmonella*)؛ تخمیرکننده‌ها صورتی |

- QC BGA: *S.* Typhimurium ATCC 14028 (صورتی-قرمز)؛ *E. coli* ATCC 25922 (مهار یا زرد-سبز).
- *S.* Typhi: **بیسموت سولفیت آگار (Wilson–Blair)** کلنی‌های **سیاه با جلای فلزی** («چشم خرگوش») می‌دهد (کاربرد محدود).

## الف۵. کروموژنیک *Salmonella*
(CHROMagar Salmonella، SM-ID2، Brilliance Salmonella)
- سوبسترای **C8-استراز** یا آنزیم‌های دیگر ← *Salmonella* **ارغوانی/صورتی-بنفش**؛ کلیفرم‌ها آبی یا بی‌رنگ؛ *Proteus* بی‌رنگ یا مهار.
- ✓ اختصاصیت بالاتر از XLD/HE؛ تشخیص *Salmonella* **H₂S منفی** و **لاکتوز مثبت**.
- ✗ برخی *S.* Typhi و Paratyphi A رنگ متفاوت؛ گران؛ *Shigella* را جدا نمی‌کند.

## الف۶. مک‌کانکی سوربیتول (SMAC)
- **سوربیتول به‌جای لاکتوز**. ***E. coli* O157:H7** معمولاً **سوربیتول منفی** (در ۲۴ ساعت) ← کلنی **بی‌رنگ**؛ اکثر *E. coli* سوربیتول مثبت ← **صورتی**.
- **CT-SMAC**: + **سفیکسیم + تلوریت پتاسیم** ← مهار *Proteus* و سایر سوربیتول‌منفی‌ها؛ انتخاب‌گری بیشتر برای O157.
- **کاربرد:** اسهال **خونی**، **HUS**.
- **QC:** *E. coli* O157:H7 **غیرتوکسیژنیک** ATCC 700728 (بی‌رنگ)؛ *E. coli* ATCC 25922 (صورتی).
- ⚠️ **محدودیت‌های مهم:**
  - **STEC غیر-O157** (O26، O111، O103، O145 و O104:H4) سوربیتول **مثبت** هستند ← از دست می‌روند.
  - O157 سوربیتول‌مثبت (H−، در اروپا) هم وجود دارد.
  - ⇐ **توصیهٔ CDC:** همهٔ مدفوع‌های اسهال حاد هم‌زمان برای **کشت O157** و **آزمون توکسین شیگا (Stx1/Stx2: EIA یا PCR)** بررسی شوند.
- کلنی بی‌رنگ مشکوک ← **لاتکس O157** و **H7**، تأیید توکسین، ارسال به آزمایشگاه مرجع.

## الف۷. TCBS (Thiosulfate–Citrate–Bile salts–Sucrose)
| جزء | نقش |
|---|---|
| تیوسولفات، سیترات، **صفرای گاو**، **pH ۸٫۶** | مهار فلور روده |
| **ساکارز** | تخمیر ← اسید ← **زرد** |
| **بروموتیمول بلو + تیمول بلو** | شناساگر |
| سیترات آهن | H₂S |

| ظاهر | مثال |
|---|---|
| **زرد**، بزرگ (۲–۳ mm)، مسطح | ***V. cholerae***، *V. alginolyticus* (کلنی‌های بزرگ‌تر، گاه سوارم)، *V. fluvialis* |
| **سبز-آبی** | ***V. parahaemolyticus***، ***V. vulnificus*** (اکثر)، *V. mimicus* |

- **انکوباسیون:** ۳۵–۳۷°C، ۱۸–۲۴ ساعت. ⚠️ پس از ۲۴ ساعت رنگ‌ها تغییر می‌کنند.
- **QC:** *V. parahaemolyticus* ATCC 17802 (سبز)؛ *V. cholerae* غیرتوکسیژنیک (یا *V. alginolyticus* ATCC 17749) (زرد)؛ *E. coli* ATCC 25922 (مهار).
- ⚠️ **دام‌های مهم:**
  - **اکسیداز را از TCBS انجام ندهید** (اسید ← منفی کاذب) ← از آگار خون یا TSA.
  - *Aeromonas* و *Plesiomonas* روی TCBS رشد **ضعیف یا هیچ** دارند ← برای آن‌ها **آگار خون + آمپی‌سیلین** یا **CIN** (*Aeromonas*: کلنی با مرکز صورتی).
  - *Proteus* و انتروکوک گاه کلنی‌های زرد ریز می‌دهند.
  - تأیید: **رشد در NaCl ۰٪ و ۶٪** (*V. cholerae* بدون نمک رشد می‌کند)، **string test**، آنتی‌سرم **O1/O139**، PCR توکسین (*ctxA*).

## الف۸. CIN (Cefsulodin–Irgasan–Novobiocin)
- **سفسولودین + ایرگاسان (تریکلوزان) + نوووبیوسین** + کریستال ویوله + دزوکسی‌کولات ← مهار انتخابی.
- **مانیتول** + **نوترال رد** ← کلنی **«چشم گاوی» (bull's-eye)**: **مرکز قرمز تیره** با حاشیهٔ **شفاف**.
- **کاربرد:** ***Yersinia enterocolitica*** (درد شبه‌آپاندیسیت، لنفادنیت مزانتریک؛ شیوع در مناطق سرد)؛ همچنین ***Aeromonas*** (مرکز صورتی، حاشیهٔ شفاف؛ ← اکسیداز مثبت).
- **انکوباسیون:** **۲۵–۳۰°C** (*Yersinia* در دمای پایین بهتر)، **۴۸ ساعت**.
- **غنی‌سازی سرد** (PBS در ۴°C، ۲–۳ هفته): در کشت ناقلین (کاربرد محدود).
- **QC:** *Y. enterocolitica* ATCC 9610 (چشم گاوی)؛ *E. coli* ATCC 25922 (مهار).
- ⚠️ *Citrobacter*، *Serratia*، *Enterobacter* ممکن است کلنی مشابه بدهند ← اوره‌آز (*Yersinia* +)، اکسیداز (*Aeromonas* +).

## الف۹. محیط‌های کمپیلوباکتر
| محیط | اساس | ویژگی |
|---|---|---|
| **Campy-BAP** (Blaser) | پایهٔ بروسلا + ۱۰٪ خون گوسفند + **ونکومایسین، تری‌متوپریم، پلی‌میکسین B، سفالوتین، آمفوتریسین B** | ⚠️ **سفالوتین** برخی *Campylobacter* (*C. fetus*، *C. upsaliensis*، *C. jejuni* subsp. *doylei*) را **مهار** می‌کند |
| **CCDA / mCCDA** (Charcoal Cefoperazone Deoxycholate Agar) | **بدون خون**؛ زغال (حذف رادیکال‌های اکسیژن) + **سفوپرازون** + آمفوتریسین | رایج‌ترین در اروپا؛ ✓ مهار بهتر فلور |
| **Skirrow** | خون اسب + ونکومایسین، پلی‌میکسین، تری‌متوپریم | |
| **Butzler**، **Preston** | | |
| **CAT** (Cefoperazone, Amphotericin, Teicoplanin) | سفوپرازون کمتر | برای *C. upsaliensis* |
| **روش فیلتر** (غشای ۰٫۴۵–۰٫۶۵ µm روی آگار خون غیرانتخابی) | تحرک *Campylobacter* از فیلتر عبور می‌کند | برای گونه‌های حساس به آنتی‌بیوتیک (*C. upsaliensis*، *C. concisus*) |

- **انکوباسیون:** **میکروآئروفیل** (۵٪ O₂، ۱۰٪ CO₂، ۸۵٪ N₂)، **۴۲°C** (*C. jejuni*، *C. coli*: گرمادوست؛ مهار فلور) یا ۳۷°C (برای *C. fetus* و دیگران)، **۴۸–۷۲ ساعت**.
- **ظاهر کلنی:** خاکستری، **مرطوب، پهن‌شونده** در امتداد خط کشت، غیرهمولیتیک؛ یا گرد و برآمده. **حرکت تیرمانند/فنری** در لام مرطوب؛ گرم: **باسیل منحنی، شکل «S» یا بال مرغ دریایی**.
- **QC:** *C. jejuni* ATCC 33291 (رشد در شرایط میکروآئروفیل)؛ *E. coli* ATCC 25922 (مهار).
- جزئیات شناسایی ← ماژول خانوادهٔ خمیده‌ها.

# ب. محیط‌های تناسلی

## ب۱. تایر–مارتین اصلاح‌شده (MTM)، مارتین–لوئیس (ML) و NYC
### اساس
پایهٔ **آگار شکلات (GC base + هموگلوبین + مکمل‌های IsoVitaleX)** + مخلوط آنتی‌بیوتیک‌ها:

| محیط | ونکومایسین (گرم مثبت‌ها) | کولیستین (گرم منفی‌ها به‌جز *Neisseria*) | نیستاتین / آنیزومایسین (قارچ) | تری‌متوپریم (سوارم *Proteus*) |
|---|---|---|---|---|
| **تایر–مارتین (TM)** اولیه | ✓ | ✓ | نیستاتین | — |
| **MTM** | ✓ | ✓ | نیستاتین | ✓ |
| **مارتین–لوئیس (ML)** | ✓ (**بیشتر**) | ✓ | **آنیزومایسین** | ✓ |
| **NYC** (New York City) | ✓ | ✓ | آمفوتریسین B | ✓ | (پایهٔ شفاف با پلاسمای اسب؛ رشد *Mycoplasma hominis* و *Ureaplasma* هم) |

- سیستم‌های حمل‌ونقل: **JEMBEC** و **InTray GC** (MTM + قرص تولید CO₂).

### کاربرد
جداسازی ***N. gonorrhoeae*** (و *N. meningitidis*) از نمونه‌های **پرفلور**: سرویکس، مجرا، رکتوم، حلق. نمونه‌های استریل (خون، CSF، مایع مفصلی) ← **آگار شکلات غیرانتخابی** کافی است.

### انکوباسیون
۳۵–۳۶°C (**هرگز بیش از ۳۷°C**)، **۳–۷٪ CO₂**، **رطوبت**، **۷۲ ساعت** (بررسی روزانه).

### تفسیر
کلنی خاکستری-قهوه‌ای، براق، ۰٫۵–۱ mm ← **رنگ گرم** (دیپلوکوک گرم منفی لوبیایی) + **اکسیداز** (+) + **سوپراکسول** (H₂O₂ ۳۰٪: واکنش «انفجاری» در گنوکوک) ← شناسایی تأییدی (MALDI-TOF، قندها، آنزیم‌ها).

### QC
| سویه | انتظار |
|---|---|
| *N. gonorrhoeae* ATCC 43069 | رشد |
| *N. meningitidis* ATCC 13090 | رشد |
| *S. epidermidis* ATCC 12228 | مهار |
| *E. coli* ATCC 25922 | مهار |
| *P. mirabilis* (مثلاً ATCC 43071) | مهار (سوارم) |
| *C. albicans* ATCC 10231 | مهار |

### دام‌ها
- **۳–۱۰٪ سویه‌های گنوکوک به ونکومایسین حساس‌اند** ← روی MTM رشد نمی‌کنند ← اگر شک بالاست، **شکلات غیرانتخابی** هم کشت شود.
- *Kingella denitrificans*، *Capnocytophaga* و *N. lactamica*/*N. cinerea* ممکن است رشد کنند (شبیه گنوکوک) ← شناسایی دقیق؛ به‌ویژه در **کودکان** (اهمیت پزشکی–قانونی) ← **دو روش تأییدی** مستقل.
- گنوکوک بسیار حساس به **سرما و خشکی** ← تلقیح **فوری** یا محیط حمل‌ونقل؛ پلیت‌ها گرم شده.
- امروزه **NAAT** آزمون اصلی تشخیص است؛ کشت برای **AST** (مقاومت به سفتریاکسون؛ ← [AST/05_Fastidious_Anaerobes](../AST/05_Fastidious_Anaerobes/README.md)) و پزشکی قانونی.

# ج. محیط‌های تنفسی و ارگانیسم‌های خاص

## ج۱. BCYE (لژیونلا)
### اساس
| جزء | نقش |
|---|---|
| **L-سیستین** | **نیاز مطلق *Legionella*** (کنترل: عدم رشد روی BCYE **بدون سیستین**) |
| **پیروفسفات آهن (فریک)** | آهن |
| **زغال فعال** | جذب رادیکال‌های سمی و اسیدهای چرب |
| **عصارهٔ مخمر** | غنی |
| **ACES بافر (pH ۶٫۹)** | ⚠️ **pH بحرانی** (±۰٫۰۵) |
| α-کتوگلوتارات | تحریک رشد |

- **BCYE انتخابی** (PAV/BMPA/MWY): + **پلی‌میکسین B، آنیزومایسین، ونکومایسین** (± سفامندول)؛ MWY + **گلیسین** + رنگ‌های بروموکرزول ارغوانی و بروموتیمول آبی.
- برای نمونه‌های پرفلور: **پیش‌تیمار اسیدی** (بافر HCl–KCl، pH ۲٫۲، ۴ دقیقه) یا **حرارتی** (۵۰°C، ۳۰ دقیقه).

### کاربرد
***Legionella*** (خلط، **BAL**، بافت ریه، نمونه‌های محیطی آب). ✓ برای *Nocardia* و *Francisella* هم مفید است.

### انکوباسیون
۳۵°C، هوا (± CO₂ کم)، **رطوبت**، **۷ روز** (بیشتر کلنی‌ها در **۳–۵ روز**).

### تفسیر
کلنی خاکستری-سفید، براق، **«شیشهٔ تراشیده/موزاییکی» (cut-glass)** زیر استریومیکروسکوپ؛ ۲–۴ mm. باسیل گرم منفی **کمرنگ و باریک** (رنگ‌آمیزی ضعیف؛ **سافرانین طولانی‌تر** یا **کاربول‌فوشین** به‌جای سافرانین).
- **تأیید:** رشد روی BCYE ولی **عدم رشد** روی **BCYE بدون سیستین** و **آگار خون** + MALDI-TOF یا DFA/لاتکس سروگروه.
- برخی گونه‌ها **فلورسانس آبی-سفید** زیر UV (*L. bozemanae*، *L. dumoffii*، *L. gormanii*؛ *L. pneumophila* نه).

### QC
*L. pneumophila* ATCC 33152 (رشد)؛ برای محیط انتخابی: *E. coli* ATCC 25922 و *S. aureus* ATCC 25923 (مهار).

### دام‌ها
- **آنتی‌ژن ادراری** فقط ***L. pneumophila* سروگروه ۱** را می‌گیرد ← کشت برای سایر سروگروه‌ها و گونه‌ها و برای **اپیدمیولوژی** (مقایسهٔ سویهٔ بیمار و آب) ضروری است.
- pH نادرست یا محیط کهنه ← عدم رشد.
- رشد روی آگار خون معمولی ← **لژیونلا نیست**.

## ج۲. BCSA و OFPBL (*Burkholderia cepacia*)
| محیط | اساس |
|---|---|
| **BCSA** (B. cepacia Selective Agar) | **پلی‌میکسین B (۶۰۰ U/mL) + جنتامایسین + ونکومایسین** + لاکتوز/ساکارز + **فنل رد** |
| **OFPBL** | پایهٔ OF + **پلی‌میکسین B + باسیتراسین** + **لاکتوز** + بروموتیمول بلو |
| **PC agar** (Pseudomonas cepacia) | پلی‌میکسین + تیکارسیلین + کریستال ویوله |

- **کاربرد:** **خلط بیماران فیبروز کیستیک (CF)**؛ BCC بالقوه کشنده (**سندرم سپاسیا**) و قابل‌انتقال بین بیماران CF ← کنترل عفونت.
- **انکوباسیون:** ۳۵°C، **تا ۵ روز** (رشد کند).
- **تفسیر:** BCSA: کلنی **زرد/صورتی** با تغییر محیط به **صورتی-قرمز** (قلیایی)؛ OFPBL: کلنی زرد (اکسیداسیون لاکتوز).
- **QC:** *B. cepacia* ATCC 25416 (رشد)؛ ***P. aeruginosa* ATCC 27853 (مهار در BCSA)**؛ *S. aureus* ATCC 25923 (مهار).
- ⚠️ ***Ralstonia*، *Pandoraea*، *Achromobacter*، *Stenotrophomonas*** و برخی *Pseudomonas* هم رشد می‌کنند ← **شناسایی دقیق** (MALDI-TOF با پایگاه دادهٔ به‌روز، *recA* sequencing) و ارسال به **آزمایشگاه مرجع CF**. BCSA اختصاصی‌تر از OFPBL است.

## ج۳. آگار سترامید (*Pseudomonas*)
- **سترامید (ستیل‌تری‌متیل آمونیوم بروماید)**: ترکیب آمونیوم چهارتایی ← مهار اکثر باکتری‌ها به‌جز *P. aeruginosa*.
- **MgCl₂ + K₂SO₄** ← **افزایش تولید پیوسیانین و پیووردین** (رنگدانه‌ها).
- **کاربرد:** جداسازی/تأیید *P. aeruginosa* (نمونه‌های CF، محیطی، استخر، تجهیزات).
- **تفسیر:** کلنی **سبز-آبی**، **فلورسانس زرد-سبز** زیر UV (پیووردین). رشد در **۴۲°C** (*P. aeruginosa* +؛ *P. fluorescens*/*putida* −).
- **QC:** *P. aeruginosa* ATCC 27853 (رشد، رنگدانه، فلورسانس)؛ *E. coli* ATCC 25922 (مهار).
- ⚠️ برخی سویه‌های *P. aeruginosa* (CF، موکوئید) رنگدانه نمی‌دهند یا کند رشد می‌کنند.

## ج۴. ریگان–لو و بوردت–ژانگو (*Bordetella*)
| محیط | ترکیب | نکته |
|---|---|---|
| **ریگان–لو (Regan–Lowe)** | **آگار زغال** + **۱۰٪ خون اسب** + **سفالکسین (۴۰ mg/L)** + نیاسین | **ترجیحی**؛ عمر طولانی‌تر (۴–۸ هفته)؛ نیم‌غلظت (بدون سفالکسین در یک پلیت) ← بازیابی *B. holmesii* و برخی *B. pertussis* حساس به سفالکسین |
| **بوردت–ژانگو (Bordet–Gengou)** | **سیب‌زمینی–گلیسرول** + **۱۵–۲۰٪ خون گوسفند** + متی‌سیلین/سفالکسین | عمر کوتاه (۱ هفته)؛ همولیز β ضعیف |
| **محیط حمل‌ونقل ریگان–لو** (نیم‌غلظت زغال + سفالکسین) | | حمل تا ۴۸ ساعت |

- **نمونه:** **سواب یا آسپیرهٔ نازوفارنکس** (سواب **داکرون/نایلونی پرزدار**؛ **پنبه و آلژینات کلسیم ممنوع**: اسیدهای چرب سمی/مهار PCR).
- **انکوباسیون:** ۳۵°C، هوا، **رطوبت بالا**، **۷ روز** (کلنی *B. pertussis* در **۳–۷ روز**؛ *B. parapertussis* در ۲–۳ روز).
- **تفسیر:** کلنی ریز، **براق، گنبدی، «قطرهٔ جیوه» (mercury drop)** یا مروارید؛ کوکوباسیل گرم منفی کوچک.
- **تأیید:** DFA یا آگلوتیناسیون؛ اکسیداز (*B. pertussis* +، *B. parapertussis* −)؛ اوره‌آز (*B. parapertussis* + در ۲۴ ساعت)؛ MALDI-TOF.
- **QC:** *B. pertussis* ATCC 9797 (رشد در ۳–۵ روز)؛ *S. aureus* ATCC 25923 (مهار).
- ⚠️ **حساسیت کشت پایین** (۱۲–۶۰٪؛ پس از ۲ هفته سرفه، واکسیناسیون یا آنتی‌بیوتیک کاهش می‌یابد) ← **PCR** (IS*481*، IS*1001*، *ptxP*) آزمون اصلی؛ کشت برای **مقاومت به ماکرولید** و اپیدمیولوژی.

## ج۵. محیط‌های دیفتری: تلوریت، تینزدیل، لوفلر
| محیط | اساس | تفسیر | کاربرد |
|---|---|---|---|
| **آگار سیستین–تلوریت خون (CTBA)** | **تلوریت پتاسیم** (انتخابی؛ مهار فلور) + خون + سیستین | تلوریت احیا ← کلنی‌های **خاکستری تا سیاه** (بیوتیپ‌ها: gravis بزرگ و خاکستری؛ mitis کوچک‌تر و سیاه) | جداسازی اولیه |
| **آگار تینزدیل (Tinsdale)** | تلوریت + **سیستین + تیوسولفات** + سرم | کلنی **سیاه با هالهٔ قهوه‌ای** (تولید H₂S از سیستین با **سیستیناز**) | **افتراق *C. diphtheriae*، *C. ulcerans* و *C. pseudotuberculosis*** (سیستیناز +) از دیفتروئیدهای دیگر |
| **سرم لوفلر (Loeffler serum slope)** | سرم گاوی منعقد + تخم‌مرغ + گلوکز | رشد سریع (۶–۸ ساعت)؛ رنگ‌آمیزی **متیلن بلو**: **گرانول‌های متاکروماتیک (Babes–Ernst)** و آرایش **«حروف چینی»** | تقویت مورفولوژی؛ ⚠️ اختصاصی نیست |

- **نمونه:** سواب **زیر غشای کاذب** گلو/نازوفارنکس؛ سواب زخم پوستی (دیفتری پوستی در مهاجرین/بی‌خانمان‌ها).
- **انکوباسیون:** ۳۵–۳۷°C، هوا (± CO₂)، **۴۸ ساعت**.
- **تأیید:** شناسایی (MALDI-TOF)، و **مهم‌تر از همه، آزمون تولید توکسین**: **Elek** (ایمونودیفیوژن) یا **PCR ژن *tox*** (وجود ژن ≠ بیان؛ NTTB: سویه‌های *tox* مثبت غیرتوکسیژنیک) ← آزمایشگاه مرجع.
- **QC:** *C. diphtheriae* سویهٔ **غیرتوکسیژنیک** مرجع (طبق IFU/آزمایشگاه مرجع) برای رشد و هاله در تینزدیل؛ *S. aureus* ATCC 25923 (مهار روی محیط‌های تلوریت).
- ⚠️ **اورژانس بهداشتی**: هر شک بالینی ← **تماس فوری** با آزمایشگاه مرجع و بهداشت؛ ایمنی کارکنان (واکسیناسیون).

# د. سایر محیط‌های انتخابی

## د۱. مانیتول سالت آگار (MSA)
- **NaCl ۷٫۵٪** ← انتخابی برای استافیلوکوک‌ها (تحمل نمک).
- **مانیتول + فنل رد** ← تخمیر مانیتول ← **زرد**.
- **تفسیر:**
  - کلنی **زرد با هالهٔ زرد** ← *S. aureus* (اکثر)؛ ولی **برخی CoNS** (*S. saprophyticus*، *S. haemolyticus*، *S. capitis*…) هم زردند.
  - کلنی **صورتی/قرمز** ← CoNS مانیتول منفی (*S. epidermidis*).
- **کاربرد:** غربالگری ناقلین *S. aureus* (بینی) در محیط‌های قدیمی‌تر؛ امروزه **کروموژنیک *S. aureus*/MRSA** (گروه ۵) ترجیح دارد.
- **QC:** *S. aureus* ATCC 25923 (رشد، زرد)؛ *S. epidermidis* ATCC 12228 (رشد، صورتی)؛ *E. coli* ATCC 25922 (مهار).
- ⚠️ **کوآگولاز** از کلنی MSA ممکن است تحت تأثیر قرار گیرد (به‌ویژه لاتکس) ← تأیید از آگار خون. انتروکوک‌ها گاه رشد می‌کنند.
