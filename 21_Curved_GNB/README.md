# ۲۱. باسیل‌های گرم منفی خمیده و مارپیچی (*Campylobacter*، *Helicobacter*، *Arcobacter*)

## دامنه
باسیل‌های گرم منفی **خمیده، «S» یا «بال مرغ دریایی»**، **اکسیداز +**، اغلب **میکروآئروفیل** (۵٪ O₂، ۱۰٪ CO₂)، **غیرتخمیری** و با **حرکت تیرمانند/فنری**. با قندها شناسایی نمی‌شوند؛ کلید شناسایی: **دما، هیپورات، ایندوکسیل استات، اوره‌آز، کاتالاز**.

| جنس | گونه‌های مهم |
|---|---|
| ***Campylobacter*** | ***C. jejuni***، ***C. coli*** (گرمادوست، ۴۲°C)؛ *C. upsaliensis*، *C. lari*؛ ***C. fetus*** (باکتریمی) |
| ***Helicobacter*** | ***H. pylori*** (معده)؛ *H. cinaedi*، *H. fennelliae* (روده‌ای، باکتریمی)؛ *H. heilmannii* |
| ***Arcobacter*** (*Aliarcobacter*) | *A. butzleri*، *A. cryaerophilus* (هوازی‌تحمل، رشد در ۲۵°C) |
| شبیه‌ها | *Vibrio* (خمیده ولی تخمیری) ← [18](../18_Oxidase_Positive_Fermenters/README.md)؛ *Anaerobiospirillum*، *Desulfovibrio* ← [22](../22_Anaerobes/README.md) |

## اهمیت بالینی (خلاصه)
| ارگانیسم | بیماری |
|---|---|
| ***C. jejuni*/*C. coli*** | از شایع‌ترین علل **اسهال باکتریایی** (مرغ، شیر غیرپاستوریزه)؛ اسهال خونی، درد شبه‌آپاندیسیت؛ عوارض: **گیلن‌باره**، آرتریت واکنشی |
| ***C. fetus*** | **باکتریمی** و **عفونت عروقی** (آنوریسم، ترومبوفلبیت)، سقط؛ در سالمندان، سیروز، نقص ایمنی؛ اسهال کمتر |
| ***H. pylori*** | گاستریت مزمن، **زخم پپتیک**، **آدنوکارسینوم معده** و **لنفوم MALT**؛ شیوع بالا در ایران |
| ***H. cinaedi*** | باکتریمی، **سلولیت** و آرتریت در نقص ایمنی (HIV، پیوند)؛ عود |
| ***Arcobacter*** | اسهال (مسافران)، نادراً باکتریمی |

## نمونه‌ها و روش‌ها
- **مدفوع:** انتقال در **Cary-Blair** (۴°C) ← **CCDA** یا Campy-BAP در **۴۲°C میکروآئروفیل** ۴۸–۷۲ ساعت ← [11_Culture_Media/04 بخش الف۹](../11_Culture_Media/04_Pathogen_Specific_Selective.md)؛ روند کامل ← [04_Gastrointestinal](../04_Gastrointestinal/README.md). **روش فیلتر** روی آگار خون در ۳۷°C برای گونه‌های حساس به سفالوتین.
- **خون:** بطری‌های روتین (*C. fetus* معمولاً رشد می‌کند؛ *H. cinaedi* کند ← **انکوباسیون طولانی‌تر** و **آکریدین اورنج** در صورت شک).
- ***H. pylori*:** **آزمون تنفسی اوره (UBT)** و **آنتی‌ژن مدفوع** (غیرتهاجمی)؛ بیوپسی: **اوره‌آز سریع (RUT)**، بافت‌شناسی، **کشت** (فقط برای AST)، **PCR** (۲۳S rRNA برای کلاریترومایسین) ← [04_Gastrointestinal/02_Protocol/06](../04_Gastrointestinal/02_Protocol/06_Interpretation.md).
