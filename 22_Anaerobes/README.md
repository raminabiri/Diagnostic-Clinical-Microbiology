# ۲۲. باکتری‌های بی‌هوازی

## دامنه
باکتری‌هایی که در حضور **اکسیژن رشد نمی‌کنند** (بی‌هوازی اجباری؛ تأیید با **آزمون هوازی‌تحملی**). بیشتر **فلور طبیعی** دهان، روده و دستگاه تناسلی‌اند؛ عفونت‌ها معمولاً **چندمیکروبی** و **درون‌زاد** (آبسه، زخم، آسپیراسیون).

| گروه | جنس/گونه‌های مهم |
|---|---|
| **باسیل گرم منفی** | **گروه *Bacteroides fragilis*** (*B. fragilis*، *B. thetaiotaomicron*، *Parabacteroides*)؛ ***Prevotella***، ***Porphyromonas***؛ ***Fusobacterium*** (*F. nucleatum*، *F. necrophorum*)؛ *Bilophila*، *Desulfovibrio* |
| **کوکسی گرم مثبت** (GPAC) | *Finegoldia magna*، *Parvimonas micra*، *Peptostreptococcus anaerobius*، *Peptoniphilus*، *Anaerococcus* |
| **کوکسی گرم منفی** | *Veillonella* |
| **باسیل گرم مثبت اسپوردار** | ***Clostridium perfringens***، *C. septicum*، *C. tertium*، *C. sordellii* (*Paeniclostridium*)، ***Clostridioides difficile***، *C. tetani*، *C. botulinum* ☣️، *C. ramosum*/*C. innocuum*/*C. clostridioforme* (گرم‌متغیر) |
| **باسیل گرم مثبت بدون اسپور** | ***Actinomyces***، ***Cutibacterium acnes***، *Eggerthella lenta*، *Bifidobacterium*، *Mobiluncus* |
| خارج از این ماژول | *Lactobacillus* (هوازی‌تحمل) ← [15](../15_Aerobic_GPB/README.md)؛ *Campylobacter* ← [21](../21_Curved_GNB/README.md) |

## اهمیت بالینی (خلاصه)
| ارگانیسم | بیماری |
|---|---|
| **گروه *B. fragilis*** | **آبسهٔ داخل شکمی**، پریتونیت، باکتریمی؛ شایع‌ترین بی‌هوازی بالینی؛ مقاومت فزاینده |
| *Prevotella*، *Porphyromonas*، *Fusobacterium* | عفونت‌های **دهان و دندان**، سر و گردن، **آبسهٔ ریه** و آمپیم (آسپیراسیون)، عفونت‌های زنان |
| ***F. necrophorum*** | **سندرم لمیر** (ترومبوفلبیت سپتیک ورید ژوگولار پس از فارنژیت در جوانان)؛ فارنژیت مکرر |
| ***C. perfringens*** | **گانگرن گازی** (میونکروز)، کوله‌سیستیت آمفیزماتو، مسمومیت غذایی؛ همولیز داخل عروقی شدید |
| ***C. septicum*** | میونکروز **خودبه‌خود** و باکتریمی ← **سرطان کولون** یا نوتروپنی |
| ***C. difficile*** | **اسهال و کولیت مرتبط با آنتی‌بیوتیک** ← [04_Gastrointestinal](../04_Gastrointestinal/02_Protocol/05_Molecular_Methods.md) |
| *C. tetani*، *C. botulinum* ☣️ | **کزاز**، **بوتولیسم** (تشخیص بالینی؛ آزمون توکسین در آزمایشگاه مرجع) |
| ***Actinomyces*** | اکتینومایکوز **سروی‌کوفاسیال**، ریوی، شکمی-لگنی (IUD)؛ **گرانول‌های گوگردی** |
| ***Cutibacterium acnes*** | معمولاً **آلودگی**؛ ولی عفونت **پروتز شانه**، شانت CSF، اندوکاردیت دریچهٔ مصنوعی |

## نمونه‌ها
- **قابل‌قبول:** **آسپیره** (سوزن و سرنگ) و **بافت** در **محیط انتقال بی‌هوازی**؛ مایعات استریل؛ خون.
- **غیرقابل‌قبول برای کشت بی‌هوازی** (فلور طبیعی بی‌هوازی): **سواب** سطحی، **خلط**، سواب حلق، **ادرار** میانی، **مدفوع** (به‌جز *C. difficile*/*C. botulinum*)، سواب واژن یا سرویکس، سواب‌های پوستی.
- **رنگ گرم مستقیم** و **بو** (بوی متعفن = بی‌هوازی) ارزشمندند ← [08_Wound_Tissue](../08_Wound_Tissue/README.md).
- محیط‌ها: آگار خون بی‌هوازی، **BBE**، **KVLB**، **PEA**، **EYA**، تیوگلیکولات؛ **۴۸ ساعت** تا **۵–۷ روز** (*Actinomyces*، *Cutibacterium* تا **۱۴ روز**) ← [11_Culture_Media/06](../11_Culture_Media/06_Anaerobic.md).

## ایمنی
***C. botulinum***: توکسین بسیار قوی ← نمونه‌ها (سرم، مدفوع، غذا) **بدون کشت** به **آزمایشگاه مرجع** ارسال شوند؛ اطلاع فوری به بهداشت. سایر بی‌هوازی‌ها BSL-2.
