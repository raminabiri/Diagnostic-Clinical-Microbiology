# پروتکل ۲: انتقال، پذیرش و رد — پوست و بافت نرم

## ۱. انتقال

| نمونه | ظرف | دما | حداکثر زمان |
|---|---|---|---|
| آسپیره در سرنگ درپوش‌دار (بدون سوزن) | — | دمای اتاق | **≤ ۳۰ دقیقه** (بی‌هوازی) تا ۲ ساعت |
| آسپیره/بافت در **محیط انتقال بی‌هوازی** | ویال/کیسه بی‌هوازی | دمای اتاق | ≤ ۲۴ ساعت |

## ۲. پذیرش
- **نوع و محل دقیق نمونه** (آبسهٔ ران، زخم پاشنه، بافت فاسیا عمقی…)
- **عمیق یا سطحی؟** آسپیره/بافت یا سواب؟
- اطلاعات بالینی: گازگرفتگی (نوع حیوان)، تماس با آب، دیابت، نقص ایمنی، ظن نکروزان، مسافرت، تماس با دام (سیاه‌زخم).

## ۳. معیار رد و اقدام

| مشکل | اقدام |
|---|---|
| **سواب خشک** | رد |
| **سواب برای کشت بی‌هوازی** (به‌جز ESwab/محیط بی‌هوازی معتبر) | رد بی‌هوازی؛ هوازی انجام شود |
| **سواب سطحی از زخم با فلور پوست** (بدون علائم عفونت) | پردازش محدود یا رد طبق سیاست + آموزش |
| **نمونه در فرمالین** | رد (میکروب‌شناسی) |
| سرنگ **با سوزن** | ☣️ رد/قید + آموزش؛ در صورت غیرقابل تکرار: پردازش با احتیاط |
| سواب «سلولیت» از پوست سالم | رد + جملهٔ آموزشی |
| زخم گازگرفتگی **تازه بدون عفونت** | رد (کشت پیش‌بینی‌کنندهٔ عفونت بعدی نیست) |
| نمونه‌های متعدد از یک ضایعه در یک روز | فقط بهترین (بافت > آسپیره > سواب) |
| بافت جراحی/نکروزان | ⛔ **رد نشود** (غیرقابل تکرار)؛ با قید پردازش |
