# پروتکل ۵: روش‌های مولکولی و سریع — پوست و بافت نرم

> جدا از روش‌های کلاسیک.

| روش | کاربرد | نکته |
|---|---|---|
| **MALDI-TOF** | شناسایی سریع کلنی‌ها (*Pasteurella*، *Capnocytophaga*، *Eikenella*، *Erysipelothrix*، *Aeromonas*، بی‌هوازی‌ها) | ☣️ ⛔ برای *B. anthracis* مشکوک (کتابخانهٔ امنیتی، آئروسل) |
| **PCR *S. aureus*/*mecA*** (مستقیم از نمونهٔ SSTI یا سواب بینی) | تشخیص سریع MRSA؛ غربالگری کلونیزاسیون | نمونهٔ SSTI در برخی کیت‌ها تأیید شده است |
| **PCR ژن *lukS/F-PV* (PVL)** | آبسه‌های عودکننده، پنومونی نکروزان، خوشه‌ها (مرجع/پژوهشی) | راهنمایی بی‌کلونیزاسیون خانواده |
| **PCR *B. anthracis*** (*pagA*، *capB*، کروموزومی) | ☣️ آزمایشگاه مرجع/LRN | |
| **PCR 16S rRNA/توالی‌یابی** روی بافت | کشت منفی (آنتی‌بیوتیک قبلی)، ارگانیسم‌های سخت‌رشد | DNA زمینه |
| **NGS (متاژنومیک) بافت** | فاشئیت با کشت منفی، نقص ایمنی | مرجع |
| PCR NTM/*hsp65*/*rpoB* | ضایعات گرانولوماتوز | [ماژول ۲۳](../../23_Mycobacteria/README.md) |
| PCR *C. diphtheriae tox* | دیفتری پوستی | ماژول ۰۶ |
| PCR *Bartonella* | آنژیوماتوز باسیلاری، بیماری خراش گربه (لنف‌نود) | |

## گزارش
- «DNA *S. aureus* و ژن *mecA* شناسایی شد (PCR مستقیم): MRSA محتمل؛ کشت و آنتی‌بیوگرام در جریان.»
- «PCR 16S rRNA روی بافت: *Streptococcus pyogenes* (کشت منفی پس از آنتی‌بیوتیک).»
