# پروتکل ۷: گزارش‌دهی — پوست و بافت نرم

## ۱. یافته‌های نیازمند اطلاع فوری 📞
| یافته | گیرنده |
|---|---|
| گرم بافت عمقی در ظن عفونت نکروزان (هر ارگانیسم، به‌ویژه **کوکسی زنجیره‌ای** یا **باسیل‌های گرم مثبت درشت**) | جراح/پزشک |
| GAS در بافت عمقی | پزشک + کنترل عفونت (خوشه) |
| *C. perfringens*/*septicum* | پزشک (+ پیام: *C. septicum* ← بررسی بدخیمی کولون) |
| *V. vulnificus* | پزشک |
| ☣️ مشکوک به *B. anthracis* | **مسئول آزمایشگاه + مرجع + بهداشت** |
| *C. diphtheriae* از زخم پوستی | پزشک + بهداشت |
| MRSA در بیمار بستری (جدید) | کنترل عفونت |
| *Capnocytophaga* از خون/بافت بیمار آسپلنیک | پزشک |

## ۲. جملات استاندارد

| موقعیت | جمله |
|---|---|
| سواب سطحی با فلور | «فلور پوستی مخلوط؛ پاتوژن غالب جدا نشد. سواب سطحی زخم ممکن است کلونیزاسیون را منعکس کند؛ برای تشخیص عفونت عمقی، آسپیره یا بافت توصیه می‌شود.» |
| کیفیت پایین سواب | «سلول‌های اپی‌تلیال سنگفرشی فراوان بدون PMN؛ نمونهٔ سطحی؛ فقط پاتوژن‌های کلیدی گزارش شده‌اند.» |
| آبسه با *S. aureus* | «*Staphylococcus aureus* (MRSA) — رشد فراوان. درمان اصلی آبسه، تخلیه است.» |
| بی‌هوازی‌ها | «بی‌هوازی‌های مخلوط (گرم منفی و گرم مثبت) — رشد متوسط.» |
| گازگرفتگی | «*Pasteurella multocida* جدا شد (گاز گربه).» |
| *Eikenella* | «*Eikenella corrodens*: ذاتاً مقاوم به کلیندامایسین و مترونیدازول.» |
| *Erysipelothrix* | «*Erysipelothrix rhusiopathiae*: ذاتاً مقاوم به ونکومایسین.» |
| *C. septicum* | «*Clostridium septicum* جدا شد. ارتباط شناخته‌شده با بدخیمی کولون/خون؛ ارزیابی توصیه می‌شود.» |
| سیاه‌زخم (پیش از تأیید) | «باسیل گرم مثبت غیرهمولیتیک، غیرمتحرک؛ **ظن *Bacillus anthracis***؛ ایزوله برای تأیید به آزمایشگاه مرجع ارسال شد.» |

## ۳. نمونهٔ گزارش (فاشئیت نکروزان)

```
نمونه: بافت فاسیای ساق چپ (اتاق عمل)، ۳ قطعه + محیط بی‌هوازی
گرم (۴۰ دقیقه پس از دریافت): PMN کم؛ کوکسی‌های گرم مثبت زنجیره‌ای فراوان
    [📞 ۲۳:۱۵ به دکتر … (جراحی) — بازخوانی]
کشت:
  Streptococcus pyogenes (گروه A) — رشد فراوان
  بی‌هوازی: رشدی مشاهده نشد (۵ روز)
آنتی‌بیوگرام:
  پنی‌سیلین        S (حساسیت قابل پیش‌بینی؛ تست نشده)
  کلیندامایسین     S (D-test منفی)
  اریترومایسین     S
توضیح: کلیندامایسین برای مهار تولید توکسین در کنار پنی‌سیلین. کنترل عفونت مطلع شد.
```
