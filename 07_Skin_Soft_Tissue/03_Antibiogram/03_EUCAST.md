# آنتی‌بیوگرام — پوست و بافت نرم بر اساس EUCAST

> **مرجع:** EUCAST Breakpoint Tables (نسخهٔ جاری). ⚠️ با نسخهٔ جاری تطبیق دهید.

## ۱. نکات ویژه EUCAST

| موضوع | EUCAST |
|---|---|
| *S. aureus* | سفوکسیتین (غربالگری)؛ **فوزیدیک اسید** (نقطهٔ برش سیستمیک و موضعی)؛ **موپیروسین** (نقطهٔ برش ویژهٔ بی‌کلونیزاسیون بینی)؛ تتراسایکلین ⇒ داکسی؛ تست القایی کلیندامایسین |
| استرپتوکوک‌های بتا | بنزیل‌پنی‌سیلین (استنتاج)، ماکرولیدها، کلیندامایسین (± القایی)، **TMP-SMX** (EUCAST نقطهٔ برش دارد) |
| *Pasteurella multocida* | جدول اختصاصی EUCAST (بنزیل‌پنی‌سیلین، آمپی‌سیلین، آموکسی‌سیلین، آموکسی‌کلاو، سفوتاکسیم، تتراسایکلین/داکسی، سیپروفلوکساسین/لووفلوکساسین، TMP-SMX) |
| *Aeromonas* | جدول اختصاصی (سیپروفلوکساسین، TMP-SMX، سفپیم، آزترئونام و…) |
| *Vibrio* | (نسخهٔ جاری را چک کنید؛ برخی ECOFF/راهنما) |
| *Bacillus* غیر *anthracis* | جدول اختصاصی (ونکومایسین، سیپروفلوکساسین، لووفلوکساسین، ایمی‌پنم/مروپنم، کلیندامایسین، اریترومایسین، لینزولید) |
| بی‌هوازی‌ها | جدول بی‌هوازی + روش دیسک FAA-HB برای برخی گونه‌ها |
| *Corynebacterium* | جدول اختصاصی |

## ۲. انتخاب بر اساس عوامل بیمار
اصول همانند CLSI (فایل [02_CLSI.md](02_CLSI.md)، بخش ۲). نکتهٔ EUCAST: **فوزیدیک اسید** در اروپا برای SSTI و زرد زخم کاربرد دارد. مقاومت آن در کلون‌های اپیدمیک (زرد زخم) گزارش شده است ← AST هنگام استفاده.
