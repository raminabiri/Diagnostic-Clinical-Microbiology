# آنتی‌بیوگرام — پوست و بافت نرم بر اساس CLSI

> **مرجع:** CLSI M100 (نسخهٔ جاری)، M45 (*Pasteurella*، *Aeromonas*، *Vibrio*، *Bacillus*، *Erysipelothrix*، HACEK/*Eikenella*، *Capnocytophaga*)، M11 (بی‌هوازی)، M24. ⚠️ با نسخهٔ جاری تطبیق دهید.

## ۱. پنل بر اساس ارگانیسم

| ارگانیسم | پنل | ⛔ / نکته |
|---|---|---|
| ***S. aureus*** (2C) | سفوکسیتین (اکساسیلین)، **TMP-SMX**، **تتراسایکلین** (پیش‌بینی داکسی/مینو)، **کلیندامایسین + D-test**، اریترومایسین (برای D-test)، ونکومایسین (MIC؛ عفونت شدید)، **لینزولید**، ± سفتارولین، ریفامپین (ترکیبی)، **موپیروسین سطح بالا** (برنامهٔ بی‌کلونیزاسیون) | داپتومایسین فقط عفونت پیچیده/باکتریمی |
| **GAS / C / G** (2H-1) | **کلیندامایسین + D-test**، اریترومایسین؛ (پنی‌سیلین/آمپی‌سیلین تست لازم نیست؛ غیرحساس ← تأیید) | TMP-SMX **فقط با BMD** و فقط برای ایزولهٔ پوست/بافت نرم (**جدید Ed36**: S ≤ 0.5، I 1، R ≥ 2؛ سطح ۴)؛ دیسک/گرادیان روی آگار خون‌دار ممنوع (تیمیدین ← R کاذب) |
| ***P. aeruginosa*** (2B-1) | پنل ضدپسودومونایی (ماژول ۰۱) | |
| **Enterobacterales** (فاشئیت نوع I، پرینه) | پنل سیستمیک | نیتروفورانتوئین |
| ***Pasteurella*** (M45) | پنی‌سیلین، آمپی‌سیلین، آموکسی‌کلاو، سفتریاکسون، داکسی‌سایکلین/تتراسایکلین، لووفلوکساسین/موکسی‌فلوکساسین، TMP-SMX، ± بتالاکتاماز | گزارش نشود/تذکر: دیکلوگزاسیلین، سفالکسین، کلیندامایسین، اریترومایسین |
| *Capnocytophaga* | بتالاکتاماز؛ آموکسی‌کلاو، سفتریاکسون، کارباپنم | |
| ***Eikenella*** (M45، HACEK) | آمپی‌سیلین، آموکسی‌کلاو، سفتریاکسون، سیپروفلوکساسین، TMP-SMX، تتراسایکلین | **کلیندامایسین، مترونیدازول** |
| *Erysipelothrix* | پنی‌سیلین، سفتریاکسون، سیپروفلوکساسین، کلیندامایسین (M45) | **ونکومایسین**؛ آمینوگلیکوزیدها، TMP-SMX |
| ***V. vulnificus***/*Vibrio* (M45) | سفتازیدیم، سفوتاکسیم، داکسی/تتراسایکلین، سیپروفلوکساسین/لووفلوکساسین، TMP-SMX | |
| ***Aeromonas*** (M45) | سفپیم، سفتریاکسون، سیپروفلوکساسین، TMP-SMX، جنتامایسین/آمیکاسین، (کارباپنم با تذکر) | آمپی‌سیلین، سفازولین |
| *C. perfringens* و بی‌هوازی‌ها (M11) | پنی‌سیلین، کلیندامایسین، مترونیدازول، آمپی‌سیلین–سولباکتام، پیپ–تازو، کارباپنم | |
| ***B. anthracis*** (M45) | پنی‌سیلین، سیپروفلوکساسین، داکسی/تتراسایکلین (مرجع) | |

## ۲. انتخاب پنل بر اساس عوامل بیمار

### ۲-۱) سن
| گروه | ملاحظه |
|---|---|
| کودکان (زرد زخم، آبسه) | موپیروسین (موضعی)، سفالکسین (MSSA)، کلیندامایسین (± D-test)، TMP-SMX؛ ⛔ تتراسایکلین کمتر از ۸ سال (داکسی کوتاه‌مدت مجاز) |
| نوزاد (SSSS، پوستول) | پنل *S. aureus* کامل؛ کنترل عفونت NICU (MRSA) |

### ۲-۲) جنس و بارداری
| وضعیت | ملاحظه |
|---|---|
| بارداری | ⛔ تتراسایکلین، فلوروکینولون؛ TMP-SMX با احتیاط؛ بتالاکتام‌ها، کلیندامایسین (با D-test)، ونکومایسین |
| جنس | تأثیری ندارد |

### ۲-۳) بیماری زمینه‌ای و شرایط
| شرایط | ملاحظه |
|---|---|
| دیابت | فاشئیت نوع I؛ پنل گرم منفی + بی‌هوازی (و ماژول ۰۸: پای دیابتی) |
| نوتروپنی (اکتیما) | *P. aeruginosa*: پنل کامل؛ کشت خون |
| آسپلنی/الکلیسم (گاز سگ) | *Capnocytophaga*: بتالاکتاماز؛ آموکسی‌کلاو |
| بیماری کبدی/آهن اضافه + آب شور | *V. vulnificus*: داکسی + سفتازیدیم |
| تزریق مواد | MRSA، *S. aureus*، استرپتوکوک‌ها، *Eikenella* (لیس‌زدن سوزن)، *Clostridium* (بوتولیسم زخم) |
| آلرژی بتالاکتام | کلیندامایسین (D-test)، TMP-SMX، داکسی، لینزولید، ونکومایسین |
| عفونت‌های عودکنندهٔ MRSA | موپیروسین HLMR، PVL (مرجع) |
