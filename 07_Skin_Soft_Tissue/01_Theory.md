# تئوری: عفونت‌های باکتریایی پوست و بافت نرم

## ۱. طبقه‌بندی و عوامل

| سندرم | سطح درگیری | عوامل اصلی |
|---|---|---|
| **زرد زخم غیرتاولی** | اپیدرم | *S. aureus*، GAS |
| **زرد زخم تاولی** | اپیدرم (توکسین اکسفولیاتیو) | *S. aureus* |
| **سندرم پوست سوختهٔ استافیلوکوکی (SSSS)** | سیستمیک (توکسین) | *S. aureus* (کانون دور؛ پوست کشت منفی) |
| **اکتیما** | زخم عمقی‌تر | GAS، (*P. aeruginosa*: اکتیما گانگرنوزوم در نوتروپنی) |
| **فولیکولیت** | فولیکول | *S. aureus*؛ *P. aeruginosa* (جکوزی، «فولیکولیت وان داغ») |
| **فورونکل/کاربونکل/آبسه** | درم/زیرجلد | ***S. aureus*** (به‌ویژه **MRSA جامعه‌اکتساب**، PVL+) |
| **اریزیپل** | درم سطحی + لنفاتیک | ***S. pyogenes*** (GAS)، گروه C/G |
| **سلولیت** | درم عمقی و زیرجلد | استرپتوکوک‌های بتا همولیتیک، *S. aureus* |
| **فاشئیت نکروزان نوع I** (چندمیکروبی) | فاسیا | بی‌هوازی‌ها + Enterobacterales + استرپتوکوک‌ها (دیابت، پرینه: **گانگرن فورنیه**) |
| **فاشئیت نکروزان نوع II** (تک‌میکروبی) | فاسیا | **GAS** (± *S. aureus*)؛ گاه MRSA |
| فاشئیت نوع III | | *Vibrio vulnificus* (آب شور، بیماری کبدی)، *Aeromonas hydrophila* (آب شیرین)، *Clostridium* |
| **میونکروز کلستریدیایی (گانگرن گازی)** | عضله | ***C. perfringens*** (تروما)، ***C. septicum*** (خودبه‌خودی، **بدخیمی کولون**) |
| **گازگرفتگی سگ/گربه** | | ***Pasteurella multocida***، *Capnocytophaga canimorsus* (آسپلنی، الکل)، استافیلوکوک‌ها، استرپتوکوک‌ها، بی‌هوازی‌ها (*Fusobacterium*، *Porphyromonas*، *Prevotella*) |
| **گازگرفتگی انسان/مشت‌زدن (Clenched-fist)** | | ***Eikenella corrodens***، گروه *S. anginosus*، *S. aureus*، بی‌هوازی‌های دهانی |
| **مرتبط با آب/ماهی** | | *V. vulnificus*، *Aeromonas*، *Erysipelothrix rhusiopathiae* (اریزیپلوئید)، *Mycobacterium marinum*، *Shewanella* |
| **سیاه‌زخم پوستی** | | ***Bacillus anthracis*** (تماس با دام/پوست/پشم؛ ایران: آندمیک پراکنده) |
| **دیفتری پوستی** | | *C. diphtheriae*، *C. ulcerans* |
| **اریتراسما** | | *Corynebacterium minutissimum* (فلورسانس مرجانی در نور وود) |
| **عفونت پوستی در سیستمیک** | | مننگوکوکسمی (پورپورا)، اندوکاردیت، *Vibrio*، *P. aeruginosa* (اکتیما)، *Rickettsia* |
| ضایعات مزمن گرانولوماتوز | | NTM (*M. marinum*، *M. ulcerans*، سریع‌الرشدها پس از تزریق/مزوتراپی)، *Nocardia* (نوکاردیوز پوستی/لنفوکوتانه)، *Actinomyces*، سل پوستی؛ (لیشمانیوز و اسپوروتریکوز در افتراق) |
| مایستوما | | *Nocardia*، *Actinomadura*، *Streptomyces* (اکتینومایستوما)؛ (قارچی: اومایستوما) |

## ۲. عوامل خطر
- **MRSA جامعه:** ورزش‌های تماسی، زندان/سربازخانه، تزریق مواد، تماس نزدیک با فرد مبتلا، عفونت‌های عودکننده.
- **فاشئیت نکروزان:** دیابت، اعتیاد تزریقی، جراحی/تروما، آبله‌مرغان در کودکان (GAS)، NSAIDها (پوشاندن علائم).
- **اکتیما گانگرنوزوم:** نوتروپنی.
- **سلولیت:** ادم لنفاوی، نارسایی وریدی، شکاف بین انگشتی (تینه آ پدیس)، چاقی.

## ۳. علائم بالینی

| سندرم | علائم |
|---|---|
| زرد زخم | ضایعات با **پوستهٔ عسلی** (غیرتاولی)؛ تاول‌های شل (تاولی) |
| آبسه | تورم دردناک، قرمز، **مواج**؛ ± سلولیت اطراف |
| اریزیپل | ضایعهٔ قرمز روشن، **برجسته با مرز مشخص**، تب؛ صورت/ساق |
| سلولیت | قرمزی با مرز نامشخص، گرمی، تورم، درد |
| **فاشئیت نکروزان** | ⚠️ **درد بیش از یافته‌های ظاهری**، سفتی چوبی، تاول‌های هموراژیک، **کریپیتاسیون**، بی‌حسی پوست، شوک، **پیشرفت سریع** |
| گانگرن گازی | درد شدید، کریپیتاسیون، ترشح قهوه‌ای بدبو (**با PMN کم**) |
| *V. vulnificus* | تاول‌های هموراژیک، شوک، ۲۴–۴۸ ساعت پس از تماس |
| سیاه‌زخم پوستی | پاپول ← وزیکول ← **اسکار سیاه بدون درد** با ادم شدید اطراف |

## ۴. تشخیص بالینی و نقش آزمایشگاه

| سندرم | آیا آزمایش میکروبی لازم است؟ |
|---|---|
| سلولیت ساده (بدون چرک) | **معمولاً خیر** (کشت سواب/آسپیره کم‌بازده)؛ کشت خون فقط در شدید/نقص ایمنی/گازگرفتگی/آب |
| آبسه | **گرم + کشت چرک** (هدایت درمان، MRSA)؛ درمان اصلی **تخلیه** است |
| زرد زخم | کشت در موارد شدید، شیوع، شکست درمان، ظن MRSA |
| **فاشئیت نکروزان** | **اورژانس جراحی**؛ نمونهٔ **بافت عمقی در جراحی** + گرم فوری + کشت هوازی/بی‌هوازی + **کشت خون**؛ ⚠️ تأخیر جراحی برای تصویربرداری/آزمایش نباشد؛ (امتیاز LRINEC کمکی و ناکافی) |
| گازگرفتگی | کشت فقط اگر **عفونت بالینی** وجود دارد (نه در زخم تازهٔ بدون عفونت) |
| ضایعات مزمن/گرانولوماتوز | **بیوپسی** برای بافت‌شناسی + کشت (باکتری، AFB در ۳۰ °C، قارچ، *Nocardia*) |
| سیاه‌زخم | ☣️ گرم، کشت، PCR (مرجع)؛ گزارش فوری |

## ۵. اهمیت
- **MRSA جامعه‌اکتساب** درمان تجربی آبسه‌ها را تغییر داده است.
- **فاشئیت نکروزان** مرگ‌ومیر ۲۰–۳۰٪ دارد. گرم فوری بافت (باسیل‌های گرم مثبت درشت یا زنجیره‌های کوکسی) می‌تواند تصمیم بالینی را تسریع کند.
- **کشت سواب سطحی** زخم‌ها اغلب فقط فلور پوست/کلونیزاسیون را نشان می‌دهد ← **نمونهٔ صحیح** نقش اصلی آزمایشگاه است.
