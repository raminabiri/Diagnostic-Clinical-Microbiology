# ۲۴. باکتری‌های غیرقابل‌کشت یا دشوارکشت (درون‌سلولی، بدون دیواره، اسپیروکت‌ها)

## دامنه
باکتری‌هایی که در **کشت روتین آزمایشگاه رشد نمی‌کنند** و با **رنگ گرم دیده نمی‌شوند**؛ تشخیص بر پایهٔ **NAAT**، **سرولوژی**، **میکروسکوپی ویژه** (میدان تاریک، گیمسا، نقره) و در موارد محدود کشت سلولی یا محیط اختصاصی.

| گروه | ارگانیسم‌های مهم |
|---|---|
| **درون‌سلولی اجباری** | ***Chlamydia trachomatis***، *Chlamydia pneumoniae*، *Chlamydia psittaci*؛ ***Rickettsia*** (گروه تب منقوط و تیفوس)، *Orientia*؛ ***Coxiella burnetii***؛ *Ehrlichia*، *Anaplasma*؛ *Tropheryma whipplei* |
| **بدون دیوارهٔ سلولی** | ***Mycoplasma pneumoniae***، ***M. genitalium***، *M. hominis*، ***Ureaplasma*** |
| **اسپیروکت‌ها** | ***Treponema pallidum*** (سیفلیس)؛ ***Borrelia*** (*B. burgdorferi* sensu lato: لایم؛ ***B. persica*** و سایر: **تب راجعه**)؛ ***Leptospira*** |
| در ماژول‌های دیگر | *Bartonella*، *Brucella*، *Legionella* ← [20](../20_Fastidious_GNB/README.md)؛ *M. leprae* ← [23](../23_Mycobacteria/README.md) |

## اهمیت بالینی (خلاصه، با تأکید بر ایران)
| ارگانیسم | بیماری |
|---|---|
| ***C. trachomatis*** | شایع‌ترین STI باکتریایی؛ سرویسیت، اورتریت، PID، ناباروری؛ **LGV** (سرووار L1–L3)؛ **تراخم**؛ کونژنکتیویت و پنومونی نوزادی |
| *C. pneumoniae*، *C. psittaci* | پنومونی آتیپیک؛ *psittaci*: تماس با **پرندگان** |
| ***M. pneumoniae*** | پنومونی آتیپیک («پنومونی راه‌رونده»)، کودکان و جوانان؛ آگلوتینین‌های سرد؛ **مقاومت به ماکرولید** (به‌ویژه شرق آسیا) |
| ***M. genitalium*** | اورتریت غیرگنوکوکی پایدار، سرویسیت، PID؛ **مقاومت به ماکرولید و فلوروکینولون** |
| *M. hominis*، *Ureaplasma* | تب پس از زایمان، عفونت در پیوند (هیپرآمونمی)، نوزاد نارس؛ در سواب واژن معمولاً **فلور** |
| ***T. pallidum*** | سیفلیس اولیه (شانکر)، ثانویه، نهفته، ثالثیه، **نوروسیفلیس**، **مادرزادی** |
| ***B. persica*** | **تب راجعهٔ ناشی از کنه** (آندمیک در ایران)؛ تشخیص با **لام خون محیطی در حین تب** |
| *B. burgdorferi* | بیماری لایم (اروپا، آمریکای شمالی؛ در ایران نادر/وارده) |
| ***Leptospira*** | **لپتوسپیروز** (آندمیک در **گیلان و مازندران**، کشاورزان شالیزار)؛ از تب خفیف تا **سندرم ویل** (زردی، نارسایی کلیه، خونریزی ریوی) |
| ***Coxiella burnetii*** | **تب Q** (تماس با دام، آندمیک در ایران)؛ حاد: پنومونی/هپاتیت؛ مزمن: **اندوکاردیت با کشت منفی** |
| ***Rickettsia*** | تب منقوط مدیترانه‌ای (*R. conorii*)، تیفوس؛ تب + راش + **اسکار (tache noire)** |
| *T. whipplei* | بیماری ویپل؛ اندوکاردیت با کشت منفی |

## نمونه‌ها و روش‌ها (خلاصه)
| ارگانیسم | روش اصلی | نمونه |
|---|---|---|
| *C. trachomatis* | **NAAT** | **ادرار اول جریان** (مرد)، **سواب واژن** (زن، حتی خودنمونه‌گیری)، رکتوم/حلق (سنجش تأییدشده) |
| *M. pneumoniae* | **NAAT** (± جهش ۲۳S)؛ سرولوژی IgM (کودکان) | سواب حلق/نازوفارنکس، خلط |
| *M. genitalium* | **NAAT** + **جهش مقاومت ماکرولید** | مانند *C. trachomatis* |
| *M. hominis*، *Ureaplasma* | کشت اختصاصی (A8، 10B، SP4) یا NAAT | مایع آمنیوتیک، ادرار، نمونه‌های استریل ← [05_Genital](../05_Genital/02_Protocol/04_Culture_Identification.md) |
| *T. pallidum* | **سرولوژی** (ترپونمایی + غیرترپونمایی)؛ میدان تاریک/NAAT از ضایعه | سرم، CSF، ترشح شانکر |
| *Borrelia* (تب راجعه) | **لام خون ضخیم و نازک (گیمسا/رایت)** حین تب؛ PCR | خون EDTA |
| *Leptospira* | **PCR خون/CSF** (هفتهٔ اول)؛ **PCR ادرار** و **سرولوژی** (MAT، IgM ELISA) (هفتهٔ دوم به بعد) | خون، ادرار، سرم |
| *Coxiella* | **سرولوژی IFA** (فاز I و II)؛ PCR (حاد، دریچه) | سرم، بافت دریچه |
| *Rickettsia* | **سرولوژی IFA** (دو نمونه)؛ **PCR اسکار/بیوپسی پوست** | سرم، بیوپسی |

## ایمنی
*C. psittaci*، *Coxiella* و *Rickettsia* در کشت **BSL-3**؛ کشت آن‌ها فقط در آزمایشگاه مرجع. کشت *Leptospira* و سرم‌های بیماران BSL-2.
