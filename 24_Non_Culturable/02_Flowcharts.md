# فلوچارت‌های تشخیصی: باکتری‌های غیرقابل‌کشت یا دشوارکشت

## فلوچارت ۱: سرولوژی سیفلیس — الگوریتم سنتی و معکوس

```mermaid
flowchart TD
subgraph S1[الگوریتم سنتی]
A1[RPR یا VDRL] -->|منفی| A2[سیفلیس نیست<br/>مگر شک به اولیهٔ زودرس: تکرار 2 تا 4 هفته]
A1 -->|مثبت، تیتر| A3[ترپونمایی: TPPA یا EIA]
A3 -->|مثبت| A4[سیفلیس فعلی یا قبلی<br/>تیتر RPR برای پایش]
A3 -->|منفی| A5[مثبت کاذب بیولوژیک]
end
subgraph S2[الگوریتم معکوس]
B1[ترپونمایی خودکار: EIA یا CLIA] -->|منفی| B2[سیفلیس نیست<br/>مگر اولیهٔ زودرس]
B1 -->|مثبت| B3[RPR کمّی]
B3 -->|مثبت| B4[سیفلیس فعلی یا قبلی<br/>تیتر برای پایش]
B3 -->|منفی| B5[ترپونمایی دوم: TPPA]
B5 -->|مثبت| B6[سیفلیس قبلی درمان‌شده<br/>یا اولیه یا نهفتهٔ دیررس]
B5 -->|منفی| B7[احتمالاً EIA مثبت کاذب]
end
```

### منطق
- **الگوریتم سنتی** ارزان است ولی سیفلیس **اولیهٔ زودرس** و **نهفتهٔ دیررس** (RPR منفی) را از دست می‌دهد.
- **الگوریتم معکوس** برای آزمایشگاه‌های پرحجم (خودکار) مناسب است و حساس‌تر است ولی **ناهمخوانی EIA+/RPR−** ایجاد می‌کند که باید با **ترپونمایی دوم** حل شود.

## فلوچارت ۲: تب با سابقهٔ تماس — انتخاب آزمون

```mermaid
flowchart TD
A[تب حاد با سابقهٔ تماس] --> B{نوع تماس}

C --> C1[هفتهٔ اول: PCR خون<br/>بعد: PCR ادرار + IgM یا MAT]

```
