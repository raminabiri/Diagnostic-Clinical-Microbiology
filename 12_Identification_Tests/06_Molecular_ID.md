## ۶.۱ توالی‌یابی ژن 16S rRNA
### اساس
ژن **16S rRNA** (≈ ۱۵۰۰ bp) در همهٔ باکتری‌ها وجود دارد: **نواحی حفاظت‌شده** (محل پرایمر) + **نواحی متغیر (V1–V9)** (تمایز گونه‌ها). معمولاً **۵۰۰ bp اول** (V1–V3) یا کل ژن توالی‌یابی می‌شود و با پایگاه‌های **مرجع ویرایش‌شده** مقایسه می‌شود (نه فقط GenBank عمومی).

### کاربرد
- ایزوله‌هایی که با MALDI-TOF/بیوشیمیایی **شناسایی نمی‌شوند** (نادر، کندرشد، فنوتیپ غیرمعمول).
- **مستقیم از نمونه** (بافت دریچه، مایع مفصلی، CSF، استخوان) در **عفونت‌های کشت‌منفی**: **PCR 16S + توالی‌یابی سنگر** (یک ارگانیسم) یا **NGS آمپلیکون** (چندمیکروبی).
- *Bartonella*، *Tropheryma whipplei*، *Coxiella*، *Kingella kingae* (مفصل کودکان) و پاتوژن‌های سخت‌رشد.

### تفسیر (چارچوب CLSI MM18؛ نمونه)
| درصد شباهت با سویهٔ تیپ | تفسیر |
|---|---|
| **≥ ۹۹٫۰٪** (و تفاوت کافی با گونهٔ بعدی، معمولاً بیش از ۰٫۸٪) | شناسایی **گونه** |
| **۹۷٫۰–۹۸٫۹٪** | شناسایی **جنس** |
| **کمتر از ۹۷٪** | خانواده؛ احتمالاً گونهٔ جدید |

### محدودیت‌ها: گروه‌هایی که 16S **تمایز نمی‌دهد**
| گروه | جایگزین |
|---|---|
| ***E. coli*/*Shigella*** | بیوشیمیایی/سرولوژی، ژن‌های *ipaH* (*Shigella*/EIEC) |
| ***S. pneumoniae*/*S. mitis*/*S. oralis*** | ***lytA***، *piaB*، *sodA* |
| **گروه *B. cereus*** (*B. anthracis*) | *gyrB*، پلاسمیدهای pXO1/pXO2 (آزمایشگاه مرجع) |
| ***Burkholderia cepacia* complex** | ***recA*** |
| ***Aeromonas***، ***Enterobacter*** complex | *gyrB*، *rpoB*، *hsp60* |
| ***M. tuberculosis* complex** (*M. tuberculosis* در برابر *M. bovis*) | RD (regions of difference)، WGS |
| **NTM نزدیک** (*M. abscessus* زیرگونه‌ها، *M. avium*/*intracellulare*/*chimaera*) | ***rpoB***، ***hsp65***، *erm(41)*، ITS |
| ***Brucella*** (گونه‌ها) | ITS، IS711 |
| ***Nocardia*** | *secA1*، *hsp65*، چند‌ژنی |

## ۶.۳ آزمون‌های شناسایی هدفمند (Targeted NAAT)
| آزمون | کاربرد |
|---|---|
| **پنل‌های سندرمی کشت خون** (BCID2، ePlex BCID، Verigene) | شناسایی ارگانیسم + ژن‌های مقاومت از **کشت خون مثبت** (≈ ۱ ساعت) |
| **پنل مننژیت/انسفالیت** (BioFire ME) | CSF؛ ⚠️ مثبت کاذب *S. pneumoniae* و منفی کاذب؛ **همیشه همراه کشت** |
| **پنل گوارشی** (GI panel) | مدفوع: *Salmonella*، *Shigella*/EIEC، STEC، *Campylobacter*، *Vibrio*، *Yersinia*، *C. difficile*… ← **کشت بازتابی** برای ایزوله (AST، اپیدمیولوژی) |
| **پنل پنومونی** | BAL/آسپیرهٔ تراشه؛ **نیمه‌کمّی** |
| **NAAT اختصاصی** | *C. trachomatis*/*N. gonorrhoeae*، *M. genitalium*، *B. pertussis*، *Legionella*، GBS، *C. difficile* (*tcdB*)، **MTB** (Xpert MTB/RIF Ultra) |
| **Line Probe Assay مایکوباکتری** (GenoType CM/AS، MTBDR*plus*/*sl*) | شناسایی گونهٔ مایکوباکتری و مقاومت |
| **PNA-FISH** | کشت خون مثبت (*S. aureus*/CoNS، انتروکوک، گرم منفی‌ها، *Candida*) |

## ۶.۴ توالی‌یابی کل ژنوم (WGS) و متاژنومیکس
| روش | کاربرد | محدودیت |
|---|---|---|
| **WGS ایزوله** | شناسایی قطعی (ANI ≥ ۹۵–۹۶٪ = همان گونه)، **تایپینگ اپیدمیولوژیک** (cgMLST، SNP؛ طغیان‌ها)، ژن‌های مقاومت/ویرولانس، MTB (مقاومت؛ کاتالوگ WHO) | هزینه، زمان، بیوانفورماتیک؛ پیش‌بینی مقاومت هنوز جایگزین AST نیست (به‌جز MTB) |
| **متاژنومیکس (mNGS)** مستقیم از نمونه | عفونت‌های کشت‌منفی، CNS، نقص ایمنی | آلودگی محیطی/معرف‌ها، DNA میزبان، تفسیر دشوار، گران |

## ۶.۵ اصول تفسیر و گزارش
1. **کنترل‌های منفی استخراج و تکثیر** (آلودگی DNA باکتریایی در معرف‌ها مشکل شایع 16S مستقیم است).
2. **همخوانی بالینی و فنوتیپی** (مثلاً *Ralstonia* در 16S مستقیم ← آلودگی آب/معرف شایع).
3. ارگانیسم‌های **فلور پوست** در نمونهٔ استریل با یک نتیجهٔ مثبت ← احتیاط.
4. گزارش: درصد شباهت، طول توالی، پایگاه داده، و **سطح شناسایی** (گونه/جنس/complex).
5. نتیجهٔ مولکولی مثبت **بدون ایزوله** ← AST ممکن نیست ← اهمیت **کشت هم‌زمان**.
