# Urine Microbiology Case Studies

این پوشه شامل ۲۰ کیس آموزشی درباره تشخیص میکروب‌شناسی عفونت ادراری است.

## فایل‌ها

- `01-20-urine-microbiology-cases.md`: کیس‌ها، بدون پاسخ؛ مناسب ارائه به دانشجو
- `answer-key-short-01-20.md`: کلید کوتاه مدرس
- `answer-key-detailed-01-20.md`: پاسخ تشریحی گام‌به‌گام

## روش پیشنهادی استفاده

برای هر کیس، دانشجو باید این پنج مورد را تعیین کند:

1. کیفیت نمونه و نیاز یا عدم نیاز به تکرار آن
2. تفسیر یافته‌های مستقیم: دیپ‌استیک، لام یا رنگ‌آمیزی گرم
3. تفسیر کشت: ارگانیسم، شمارش CFU/mL و احتمال آلودگی/کلونیزاسیون/عفونت
4. پنل AST مناسب بر مبنای ارگانیسم و محل عفونت
5. متن گزارش میکروب‌شناسی و کامنت لازم

> Educational use only. نتایج AST در این کیس‌ها فرضی‌اند. انتخاب دیسک، روش AST، breakpoints و گزارش نهایی باید با SOP محلی و یک استاندارد واحد (CLSI یا EUCAST) انجام شود.
