# Assessments: Urine Microbiology

این پوشه ابزارهای ارزشیابی آموزشی بخش میکروب‌شناسی ادرار را نگهداری می‌کند.

## محتوای پیشنهادی

- سوالات تشریحی با کلید پاسخ
- سناریوهای موردی و کلید تشریحی
- Rubric نمره‌دهی
- چک‌لیست مهارت عملی (OSPE/OSCE)
- آزمون کوتاه پیش‌آزمون و پس‌آزمون

## اصل نمره‌دهی

ارزیابی باید چهار حوزه را جداگانه پوشش دهد:

1. کیفیت و نوع نمونه
2. بررسی مستقیم، لام و کشت
3. تفسیر کمی و شناسایی میکروب‌شناسی
4. AST و گزارش‌دهی مسئولانه

> پاسخ‌های درمانی باید با سیاست محلی، مسئول فنی، و گایدلاین به‌روز تطبیق داده شوند. در این پروژه، تمرکز اصلی بر استدلال آزمایشگاهی و تفسیر نتایج است.
