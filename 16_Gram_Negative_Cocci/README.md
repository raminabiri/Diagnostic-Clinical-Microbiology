# ۱۶. کوکسی‌های گرم منفی (*Neisseria* و *Moraxella*)

## دامنه
| گروه | جنس/گونه‌های مهم |
|---|---|
| ***Neisseria* پاتوژن** | ***N. gonorrhoeae***، ***N. meningitidis*** ☣️ |
| ***Neisseria* همسفره** (فلور حلق) | *N. lactamica*، *N. cinerea*، *N. polysaccharea*، *N. sicca*، *N. mucosa*، *N. subflava*، *N. flavescens*؛ *N. elongata* و *N. bacilliformis* (میله‌ای) |
| ***Moraxella*** | ***M. catarrhalis*** (دیپلوکوک)؛ سایر *Moraxella* (*M. nonliquefaciens*، *M. lacunata*، *M. osloensis*) کوکوباسیل‌اند |
| شبیه‌ها (در ماژول‌های دیگر) | *Kingella* (کاتالاز −) ← [20 سخت‌رشدها](../20_Fastidious_GNB/README.md)؛ *Acinetobacter* (اکسیداز −) ← [19 غیرتخمیری‌ها](../19_Non_Fermenters/README.md)؛ *Veillonella* (بی‌هوازی) ← [22](../22_Anaerobes/README.md) |

## اهمیت بالینی (خلاصه)
| ارگانیسم | بیماری |
|---|---|
| ***N. gonorrhoeae*** | اورتریت، سرویسیت، PID، پروکتیت، فارنژیت، **عفونت منتشر (DGI)**: آرتریت، تنوسینوویت، ضایعات پوستی؛ **افتالمی نوزادی**؛ همیشه **پاتوژن** (هرگز فلور نیست) |
| ***N. meningitidis*** | **مننژیت** و **مننگوکوکسمی** (پورپورای برق‌آسا)؛ پنومونی؛ اورتریت (کلاد اورتروتروپیک)؛ حامل حلقی در ۵–۱۰٪ بزرگسالان |
| ***M. catarrhalis*** | اوتیت میانی، سینوزیت، **تشدید COPD**؛ نادراً باکتریمی؛ **> ۹۰٪ بتالاکتاماز +** |
| *Neisseria* همسفره | فلور حلق؛ نادراً اندوکاردیت یا باکتریمی در نقص ایمنی؛ مهم‌ترین نقش: **اشتباه با گنوکوک یا مننگوکوک** |

## نمونه‌ها و محیط‌ها
- نمونه‌های **پرفلور** (سرویکس، مجرا، رکتوم، حلق) ← **MTM / ML / NYC** + آگار شکلات ← [11_Culture_Media/04 بخش ب۱](../11_Culture_Media/04_Pathogen_Specific_Selective.md).
- نمونه‌های **استریل** (خون، CSF، مایع مفصلی) ← **آگار شکلات** و آگار خون ← [11_Culture_Media/01](../11_Culture_Media/01_Basic_Enriched.md).
- انکوباسیون: **۳۵–۳۶°C** (هرگز > ۳۷°C)، **۵٪ CO₂**، رطوبت، **۷۲ ساعت**.
- **NAAT** امروزه روش اصلی تشخیص گنوکوک است؛ کشت برای **AST**، پزشکی قانونی و شکست درمان ← [12_Identification_Tests/06](../12_Identification_Tests/06_Molecular_ID.md).

## ایمنی ☣️
***N. meningitidis***: عفونت آزمایشگاهی با مرگ‌ومیر حدود **۵۰٪** ← **همهٔ کار با کلنی و AST در BSC**؛ **واکسیناسیون** کارکنان (MenACWY و MenB)؛ در صورت مواجهه بدون حفاظت ← **پروفیلاکسی** طبق دستورالعمل بهداشت.
