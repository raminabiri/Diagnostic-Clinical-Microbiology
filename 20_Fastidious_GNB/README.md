# ۲۰. باسیل‌ها و کوکوباسیل‌های گرم منفی سخت‌رشد

## دامنه
گرم منفی‌هایی که روی **آگار خون** ضعیف یا هیچ رشد می‌کنند، **CO₂** یا **محیط اختصاصی** می‌خواهند، یا **کند** رشد می‌کنند (۲–۷ روز). اغلب **روی MacConkey رشد نمی‌کنند**.

| گروه | جنس/گونه‌های مهم |
|---|---|
| ***Haemophilus*** | ***H. influenzae*** (تیپ b و غیرقابل‌تایپ NTHi)، ***H. parainfluenzae***، *H. haemolyticus*، *H. ducreyi* |
| **HACEK** | ***Aggregatibacter*** (*A. actinomycetemcomitans*، *A. aphrophilus*)، ***Cardiobacterium hominis***، ***Eikenella corrodens***، ***Kingella kingae*** |
| ***Capnocytophaga*** | *C. canimorsus*، *C. cynodegmi* (سگ)؛ *C. ochracea* و … (دهان انسان) |
| ***Bordetella*** | ***B. pertussis***، *B. parapertussis*، *B. bronchiseptica*، *B. holmesii* |
| ***Legionella*** | ***L. pneumophila*** (سروگروه ۱)، سایر گونه‌ها |
| **زئونوزهای خطرناک** ☣️ | ***Brucella*** (*B. melitensis*، *B. abortus*)، ***Francisella tularensis*** |
| سایر | ***Bartonella*** (*B. henselae*، *B. quintana*)؛ *Streptobacillus moniliformis* |
| در ماژول‌های دیگر | *Pasteurella* ← [18](../18_Oxidase_Positive_Fermenters/README.md)؛ *Campylobacter*، *Helicobacter* ← [21](../21_Curved_GNB/README.md) |

## اهمیت بالینی (خلاصه)
| ارگانیسم | بیماری |
|---|---|
| ***H. influenzae*** | تیپ b: مننژیت، اپی‌گلوتیت، باکتریمی (کودکان واکسینه‌نشده)؛ NTHi: اوتیت، سینوزیت، تشدید COPD، پنومونی |
| ***H. ducreyi*** | **شانکروئید** (زخم تناسلی دردناک) |
| **HACEK** | **اندوکاردیت با کشت «منفی»** (حدود ۱–۳٪ اندوکاردیت‌ها)؛ *Eikenella*: **زخم مشت به دندان (fight bite)**؛ *K. kingae*: **آرتریت/استئومیلیت کودکان زیر ۴ سال** |
| ***C. canimorsus*** | **سپسیس برق‌آسا** پس از گاز/لیس سگ در **اسپلنکتومی** و الکلیسم |
| ***B. pertussis*** | **سیاه‌سرفه**؛ خطر مرگ در **شیرخواران**؛ بزرگسالان: سرفهٔ طولانی |
| ***Legionella*** | **پنومونی شدید** (منبع: آب، برج خنک‌کننده، دوش)؛ تب پونتیاک |
| ***Brucella*** ☣️ | **تب مالت**: تب مواج، تعریق، آرتریت ساکروایلیاک، اسپوندیلیت؛ **آندمیک در ایران** (لبنیات غیرپاستوریزه، دام) |
| ***F. tularensis*** ☣️ | تولارمی (اولسروگلاندولار، پنومونیک)؛ تماس با خرگوش، کنه |
| ***Bartonella*** | بیماری خراش گربه، آنژیوماتوز باسیلی (HIV)، **اندوکاردیت با کشت منفی** |

## نمونه‌ها و محیط‌ها
- **آگار شکلات** + CO₂ (*Haemophilus*، HACEK، *Capnocytophaga*، *Brucella*، *Francisella*) ← [11_Culture_Media/01](../11_Culture_Media/01_Basic_Enriched.md).
- **کشت خون:** سیستم‌های خودکار مدرن اکثر HACEK و *Brucella* را در **۵ روز** معمول جدا می‌کنند؛ **K. kingae**: مایع مفصلی را در **بطری کشت خون** تلقیح کنید (بازده بیشتر) + PCR.
- ***Bordetella*:** سواب **نازوفارنکس** (داکرون/فلوکد؛ نه پنبه) ← **PCR** (روش اصلی) ± **ریگان–لو** (۷ روز) ← [11_Culture_Media/04 بخش ج۴](../11_Culture_Media/04_Pathogen_Specific_Selective.md).
- ***Legionella*:** **BCYE** (۷ روز) + **آنتی‌ژن ادراری** (فقط سروگروه ۱) + PCR ← [11_Culture_Media/04 بخش ج۱](../11_Culture_Media/04_Pathogen_Specific_Selective.md).
- ***Brucella*:** کشت خون/مغز استخوان + **سرولوژی** (رایت، 2-ME، کومبس) ← [01_Differential_Tables جدول ۵](01_Differential_Tables.md).
- ***Bartonella*:** کشت دشوار ← **سرولوژی** و **PCR** (بافت، دریچه).

## ایمنی ☣️
***Brucella*** (شایع‌ترین عفونت آزمایشگاهی باکتریایی) و ***Francisella***: کوکوباسیل گرم منفی **بسیار ریز** و کند‌رشد روی آگار خون/شکلات، **بدون رشد روی MacConkey** ← **کار در BSC**، **بدون MALDI-TOF و سیستم خودکار**، ارجاع (پروتکل Sentinel). **پزشک باید شک بالینی را روی برگهٔ درخواست بنویسد.** ← [12_Identification_Tests/03 بخش ۳.۱۲](../12_Identification_Tests/03_Disk_and_Growth_Tests.md)
