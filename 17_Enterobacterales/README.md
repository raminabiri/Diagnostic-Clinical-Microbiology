# ۱۷. Enterobacterales

## دامنه
باسیل‌های گرم منفی **اکسیداز منفی**، **تخمیرکنندهٔ گلوکز**، **نیترات +** (تقریباً همه)، رشد روی **MacConkey**.

| گروه | جنس/گونه‌های مهم |
|---|---|
| **پاتوژن‌های روده‌ای** | ***Salmonella*** (تیفوئیدی و غیرتیفوئیدی)، ***Shigella***، ***E. coli*** پاتوتیپ‌های اسهال‌زا (STEC، EPEC، ETEC، EAEC، EIEC)، ***Yersinia enterocolitica*** |
| **فرصت‌طلب‌ها (عفونت ادراری، خون، بیمارستانی)** | ***E. coli***، ***Klebsiella pneumoniae*** complex، *K. oxytoca*، ***Enterobacter cloacae*** complex، *Klebsiella aerogenes*، ***Citrobacter*** (*C. freundii*، *C. koseri*)، ***Serratia marcescens***، ***Proteus*** (*P. mirabilis*، *P. vulgaris*)، *Morganella morganii*، *Providencia*، *Hafnia*، *Pantoea* |
| **پاتوژن‌های خاص** | ***Yersinia pestis*** ☣️ (Sentinel)، *Y. pseudotuberculosis*، *Cronobacter sakazakii* (شیرخشک نوزاد)، *Edwardsiella tarda*، *K. pneumoniae* **هایپرویرولنت** (hvKp) |
| شبیه‌ها (در ماژول‌های دیگر) | اکسیداز + تخمیری: *Vibrio*، *Aeromonas*، ***Plesiomonas*** (تنها اکسیداز + نزدیک به Enterobacterales) ← [18](../18_Oxidase_Positive_Fermenters/README.md)؛ غیرتخمیری‌ها ← [19](../19_Non_Fermenters/README.md) |

> **نام‌گذاری:** راستهٔ **Enterobacterales** (۲۰۱۶) چند خانواده دارد: Enterobacteriaceae، *Yersiniaceae* (*Yersinia*، *Serratia*)، *Morganellaceae* (*Proteus*، *Morganella*، *Providencia*)، *Hafniaceae* (*Hafnia*، *Edwardsiella*)، *Erwiniaceae* (*Pantoea*). *Enterobacter aerogenes* ← ***Klebsiella aerogenes***.

## اهمیت بالینی (خلاصه)
| ارگانیسم | بیماری |
|---|---|
| ***E. coli*** | شایع‌ترین علت **UTI** و باکتریمی گرم منفی؛ مننژیت نوزادی (K1)؛ پاتوتیپ‌های اسهال‌زا؛ **STEC ← HUS** |
| ***K. pneumoniae*** | پنومونی، UTI، باکتریمی بیمارستانی؛ **ESBL و کارباپنماز**؛ hvKp: **آبسهٔ کبدی** با متاستاز (چشم، CNS) |
| ***Enterobacter*، *K. aerogenes*، *C. freundii*** | عفونت بیمارستانی؛ **AmpC القایی** ← شکست سفالوسپورین نسل ۳ |
| ***Serratia*** | عفونت بیمارستانی، کاتتر، چشم؛ مقاومت ذاتی به **کولیستین** |
| ***Proteus*، *Morganella*، *Providencia*** | UTI با **سنگ استروویت** (اوره‌آز)؛ سوارم؛ مقاومت ذاتی به **کولیستین** و **تیگسایکلین/نیتروفورانتوئین** |
| ***Salmonella* Typhi/Paratyphi** | **تب روده‌ای**؛ کشت **خون** (هفتهٔ اول)، مغز استخوان، مدفوع |
| ***Salmonella* غیرتیفوئیدی** | گاستروانتریت؛ باکتریمی و عفونت عروقی در سالمندان و نقص ایمنی |
| ***Shigella*** | اسهال خونی؛ دوز عفونی بسیار کم؛ **مقاومت چندگانه** (XDR *S. sonnei*) |
| ***Y. enterocolitica*** | انتروکولیت، **لنفادنیت مزانتریک** (شبه‌آپاندیسیت)؛ باکتریمی در **اضافه‌بار آهن**؛ رشد در **یخچال** (خون تزریقی) |
| ***Y. pestis*** ☣️ | طاعون (خیارکی، سپتی‌سمیک، ریوی) |

## نمونه‌ها و محیط‌ها
- **همهٔ نمونه‌ها:** آگار خون + **MacConkey** (یا EMB) ← [11_Culture_Media/02](../11_Culture_Media/02_Primary_Selective_Differential.md).
- **مدفوع:** XLD، HE، SS، کروموژنیک *Salmonella*، **SMAC** (O157)، **CIN** (*Yersinia*)، **سلنیت F/GN براث** ← [11_Culture_Media/04 بخش الف](../11_Culture_Media/04_Pathogen_Specific_Selective.md)، [03](../11_Culture_Media/03_Enrichment_Broths.md)؛ روند کامل ← [04_Gastrointestinal](../04_Gastrointestinal/README.md).
- **ادرار:** CLED یا کروموژنیک ← [02_Urine](../02_Urine/README.md).
- **غربالگری مقاومت:** کروموژنیک ESBL و CRE ← [11_Culture_Media/05](../11_Culture_Media/05_Resistance_Screening.md).
- **تست‌های لوله‌ای:** TSI/KIA، LIA، SIM/MIO، سیترات، اوره، MR-VP، دکربوکسیلازها، PAD، مالونات ← [11_Culture_Media/08](../11_Culture_Media/08_Biochemical_Tube_Media.md).

## ایمنی ☣️
- ***Y. pestis***: باسیل گرم منفی کوچک با **رنگ‌پذیری دوقطبی** («سنجاق قفلی»)، رشد **کند** (کلنی ریز در ۲۴ ساعت، «تخم‌مرغ نیمرو» در ۴۸–۷۲ ساعت)، اکسیداز −، کاتالاز +، اوره‌آز −، **بی‌حرکت** ← **کار در BSC**، **بدون سیستم خودکار و MALDI-TOF**، ارجاع (پروتکل Sentinel) ← [12_Identification_Tests/03 بخش ۳.۱۲](../12_Identification_Tests/03_Disk_and_Growth_Tests.md).
- *Shigella*، *S.* Typhi و STEC: **دوز عفونی کم** ← از شایع‌ترین عفونت‌های آزمایشگاهی؛ رعایت BSL-2 و بهداشت دست.
