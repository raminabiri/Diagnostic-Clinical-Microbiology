## ۲. ویژگی‌های کلیدی پاتوژن‌ها

| ارگانیسم | ویژگی |
|---|---|
| *N. gonorrhoeae* | دیپلوکوک گرم منفی، **بسیار حساس به خشکی و سرما**؛ نیاز به CO₂؛ **مقاومت چندگانه** (WHO: پاتوژن اولویت‌دار)؛ عفونت بی‌علامت در زنان شایع |
| *C. trachomatis* | داخل‌سلولی اجباری؛ سروارهای D–K (تناسلی)، L1–L3 (LGV)؛ **شایع‌ترین STI باکتریایی**؛ بی‌علامت در حدود ۷۰٪ زنان |
| *M. genitalium* | بدون دیوارهٔ سلولی؛ رشد بسیار کند ← فقط NAAT؛ **مقاومت بالا به ماکرولید و فزاینده به فلوروکینولون** |
| *Gardnerella vaginalis* | باسیل گرم متغیر؛ در زنان سالم هم هست ← **کشت آن برای تشخیص BV بی‌ارزش است** |
| GBS | کلونیزاسیون واژن/رکتوم در حدود ۱۰–۳۰٪ زنان باردار؛ عامل اصلی سپسیس و مننژیت نوزادی زودرس |
| *H. ducreyi* | کوکوباسیل گرم منفی، «مدرسهٔ ماهی/خط آهن»؛ کشت دشوار |
| *T. pallidum* | غیرقابل کشت؛ سرولوژی، دارک‌فیلد، PCR |

## ۳. علائم بالینی

| سندرم | علائم |
|---|---|
| اورتریت (مرد) | ترشح (گنوره: چرکی فراوان؛ غیرگنوکوکی: موکوئید کم)، سوزش ادرار |
| سرویسیت | ترشح موکوپورولان، خونریزی تماسی؛ اغلب بی‌علامت |
| BV | ترشح نازک خاکستری همگن، **بوی ماهی** (به‌ویژه پس از مقاربت)، **بدون التهاب** |
| تریکومونیاز | ترشح کف‌آلود زرد–سبز، خارش، دهانهٔ رحم توت‌فرنگی |
| کاندیدیاز | ترشح پنیری، خارش، سوزش |
| PID | درد لگن، حساسیت حرکت سرویکس/رحم/ضمائم، تب |
| شانکر سیفلیس | زخم **بدون درد**، سخت، لبه‌های برجسته |
| شانکروئید | زخم **دردناک**، لبه‌های نامنظم، لنفادنوپاتی چرکی (بوبو) |
| LGV | زخم گذرا ← لنفادنوپاتی اینگوینال دردناک (نشانهٔ شیار)، پروکتیت |
| سپسیس نفاسی GAS | تب بالا، درد شکم، شوک سریع؛ ⚠️ **اورژانس** |

## ۴. تشخیص بالینی و اندیکاسیون آزمایش

| موقعیت | آزمایش پیشنهادی |
|---|---|
| غربالگری CT/NG (زنان فعال جنسی زیر ۲۵ سال، پرخطرها، بارداری) | **NAAT** (سواب واژینال یا ادرار اول جریان) |
| اورتریت مرد | **گرم اورترال** (سریع) + NAAT CT/NG (± MG در موارد پایدار) |
| BV | **Amsel** (بالینی) یا **Nugent** (گرم)؛ یا پنل مولکولی واژینال |
| بارداری **۳۶ ۰/۷ تا ۳۷ ۶/۷ هفته** | **غربالگری GBS** (کشت غنی‌شده یا NAAT پس از غنی‌سازی) — ACOG 2020 |
| شکست درمان گنوره | **کشت + آنتی‌بیوگرام** |
| PID | NAAT CT/NG/MG؛ کشت از نمونه‌های جراحی |
| زخم تناسلی | سرولوژی سیفلیس، PCR HSV، (PCR/کشت *H. ducreyi*، LGV) |
| تب/درد پس از زایمان | **کشت خون** + کشت آندومتر/زخم (هوازی و بی‌هوازی) |
| سوءاستفادهٔ جنسی | NAAT (با تأیید) و/یا **کشت**، طبق CDC و الزامات قانونی |

## ۵. اهمیت عمومی
- STIها خطر **ناباروری، حاملگی خارج رحمی، درد مزمن لگن، انتقال HIV** و عوارض نوزادی (کونژنکتیویت، پنومونی) را بالا می‌برند.
- **درمان شریک جنسی** و **گزارش به بهداشت** بخشی از کنترل است.
- **مقاومت گنوکوک** (سفتریاکسون، آزیترومایسین) تهدید جهانی است. ⇐ کشت و AST در شکست درمان و نظام مراقبت (WHO GASP) حیاتی است.
