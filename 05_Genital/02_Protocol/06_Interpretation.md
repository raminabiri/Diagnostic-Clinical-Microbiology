# پروتکل ۶: تفسیر نتایج — نمونه‌های تناسلی

## ۱. فلور طبیعی واژن (برای جلوگیری از گزارش غلط)
- **غالب:** *Lactobacillus* (*crispatus*، *jensenii*، *gasseri*، *iners*)
- **طبیعی در تعداد کم:** CoNS، استرپتوکوک‌های ویریدانس، **GBS**، انتروکوک، *E. coli*، *Gardnerella*، *Ureaplasma*، *M. hominis*، بی‌هوازی‌ها، *Candida* (۱۰–۲۰٪)، دیفتروئیدها، *S. aureus* (حدود ۵–۱۵٪)
- ⇒ «رشد» این ارگانیسم‌ها در سواب واژینال **به‌خودی‌خود بیماری نیست**.

## ۲. ارگانیسم‌هایی که همیشه پاتوژن‌اند (هر محل تناسلی)
*N. gonorrhoeae*، *C. trachomatis*، *M. genitalium*، *T. pallidum*، *H. ducreyi*، *T. vaginalis*.

## ۳. ارگانیسم‌هایی با اهمیت وابسته به زمینه

| ارگانیسم | زمینهٔ معنی‌دار |
|---|---|
| **GBS** | **غربالگری بارداری** (کلونیزاسیون = پروفیلاکسی حین زایمان)؛ اندومتریت/سپسیس نفاسی؛ واژینیت التهابی (بحث‌برانگیز) |
| **GAS** (*S. pyogenes*) | **همیشه گزارش** (کلونیزاسیون واژن نادر؛ ولوواژینیت کودکان؛ سپسیس نفاسی) |
| *S. aureus* | TSS، آبسه؛ در سواب واژینال روتین معمولاً گزارش نمی‌شود (مگر ظن TSS) |
| *H. influenzae* | ولوواژینیت کودکان؛ سپسیس نوزادی |
| *Listeria* | جفت، آمنیوتیک، نوزاد |
| *Clostridium* | پس از سقط/زایمان (شوک توکسیک) |
| *Ureaplasma*/*M. hominis* | آمنیوتیک، نوزاد نارس، پیوند؛ نه سواب واژینال |
| *Actinomyces* | PID/آبسهٔ لگن با IUD |
| *Shigella* (ولوواژینیت) | کودکان |

## ۴. تفسیر GBS
| نتیجه | معنی |
|---|---|
| GBS در غربالگری ۳۶–۳۷ هفته | **پروفیلاکسی حین زایمان** (پنی‌سیلین/آمپی‌سیلین)؛ آلرژی ← سفازولین (کم‌خطر) یا کلیندامایسین (پرخطر، **اگر حساس**) یا ونکومایسین |
| کلیندامایسین R یا D-test + | ونکومایسین برای آلرژی پرخطر |
| GBS در ادرار در طول بارداری | پروفیلاکسی؛ غربالگری ۳۶ هفته لازم نیست (ماژول ۰۲) |
| سابقهٔ نوزاد قبلی با بیماری GBS | پروفیلاکسی بدون نیاز به غربالگری |

## ۵. تفسیر BV
| Nugent | Amsel | تفسیر |
|---|---|---|
| ۷–۱۰ | ≥ ۳ | BV |
| ۴–۶ | | بینابینی؛ با Amsel/بالین؛ ممکن است مرحلهٔ گذار باشد |
| ۰–۳ | | طبیعی |
| Nugent ۰–۳ + PMN فراوان | | واژینیت التهابی؛ بررسی تریکوموناس، گنوره، کلامیدیا، سرویسیت |

> ⚠️ BV در **غیرعلامت‌دار غیرباردار** درمان نمی‌شود. در بارداری پرخطر و پیش از برخی جراحی‌ها اهمیت دارد.

## ۶. تفسیر NAAT

| موقعیت | تفسیر |
|---|---|
| NAAT CT مثبت ۲ هفته پس از درمان | ممکن است **اسید نوکلئیک باقیمانده** باشد، نه شکست درمان |
| NAAT NG مثبت در حلق با کیت تأییدنشده | احتمال **واکنش متقاطع** ← تأیید |
| NAAT مثبت در کودک | پیامد قانونی ← **تأیید** + **کشت/نگهداری ایزوله** |
| *U. urealyticum* در NAAT تناسلی مرد بی‌علامت | کلونیزاسیون؛ اغلب درمان نمی‌شود |

## ۷. گنوره: کشت در برابر NAAT
| وضعیت | ترجیح |
|---|---|
| غربالگری و تشخیص روتین | NAAT |
| **شکست درمان/ظن مقاومت** | **کشت + AST** (و NAAT هم‌زمان) |
| پزشکی قانونی | کشت (± NAAT تأییدشده) |
| نظام مراقبت مقاومت | کشت |
| نمونه‌های استریل (مایع مفصل در DGI، خون) | کشت + NAAT (اعتبارسنجی) |

## ۸. سرولوژی سیفلیس (اشاره)
- **الگوریتم سنتی:** غیرترپونمایی (RPR/VDRL) ← تأیید ترپونمایی (TPPA/FTA-ABS)
- **الگوریتم معکوس:** ترپونمایی (EIA/CLIA) ← RPR ← در ناهمخوانی، TPPA
- RPR **کمّی** برای پایش درمان (کاهش ۴ برابری = پاسخ)
