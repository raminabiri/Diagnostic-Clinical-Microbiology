# پروتکل ۹: خطاهای رایج و عیب‌یابی — نمونه‌های تناسلی

## ۱. پیش‌آزمایشی

| خطا | پیامد | اصلاح |
|---|---|---|
| سواب گنوکوک در یخچال/تأخیر | منفی کاذب کشت | تلقیح مستقیم یا JEMBEC؛ دمای اتاق |
| لوبریکانت روی اسپکولوم | مهار رشد | آب گرم |
| سواب پنبه‌ای/دستهٔ چوبی | سمی برای گنوکوک/کلامیدیا | داکرون/فلاک |
| ادرار NAAT بیش از ۲۰–۳۰ mL یا ادرار میانی | منفی کاذب (رقیق‌شدن) | ادرار **اول جریان** ۱۰–۲۰ mL |
| GBS از سرویکس یا بدون رکتوم | منفی کاذب (کاهش حدود ۴۰٪ حساسیت بدون رکتوم) | سواب واژینال–رکتال |
| غربالگری GBS پیش از ۳۶ هفته | ارزش اخباری کمتر برای زمان زایمان | ۳۶ ۰/۷ تا ۳۷ ۶/۷ هفته |
| ذکرنکردن آلرژی پنی‌سیلین در درخواست GBS | عدم انجام AST کلیندامایسین | فیلد اجباری |
| «کشت واژینال روتین» | گزارش فلور و درمان غیرضروری | رد و هدایت |
| تست بهبود NAAT زودرس (کمتر از ۳ هفته) | مثبت باقیمانده | زمان‌بندی صحیح |

## ۲. آزمایشی

| خطا | پیامد | اصلاح |
|---|---|---|
| انکوباسیون گنوکوک بدون CO₂ یا در ۳۷+ °C | عدم رشد | ۳۵–۳۶٫۵ °C + CO₂ |
| فقط محیط انتخابی (حاوی ونکومایسین) | از دست رفتن سویه‌های حساس به ونکومایسین | + CA در نمونه‌های استریل |
| شناسایی گنوکوک فقط با اکسیداز و گرم | اشتباه با *N. meningitidis*، *N. lactamica*، *Kingella*، *Moraxella* | قندها/MALDI؛ **دو روش** در نمونه‌های قانونی/خارج‌تناسلی |
| Carrot broth بدون رنگ ← «منفی» | از دست رفتن GBS غیرهمولیتیک | ساب‌کالچر براث‌های بی‌رنگ |
| Nugent: شمارش مورفوتیپ‌ها در نواحی ضخیم | امتیاز غلط | نواحی تک‌لایه؛ ۱۰ میدان |
| اشتباه *Mobiluncus* با باسیل‌های دیگر | | باسیل خمیدهٔ گرم متغیر |
| آلودگی متقاطع در NAAT (Carry-over) | مثبت کاذب خوشه‌ای | جداسازی نواحی؛ پایش سطوح |
| دیسک دیفیوژن گنوکوک روی MHA معمولی | نتیجهٔ نامعتبر | **آگار GC + ۱٪ مکمل** |

## ۳. پس‌آزمایشی

| خطا | پیامد | اصلاح |
|---|---|---|
| گزارش «*S. aureus*/*E. coli*/انتروکوک» در سواب واژینال | درمان غیرضروری | گزارش «فلور طبیعی» |
| گزارش اریترومایسین برای پروفیلاکسی GBS | درمان ناکافی (حذف از راهنماها) | فقط کلیندامایسین (± D-test) |
| عدم گزارش به بهداشت/شریک | عفونت مجدد | فرایند |
| عدم اطلاع فوری GAS نفاسی | مرگ‌ومیر، خوشهٔ بیمارستانی | 📞 |
| افشای نتایج STI به افراد غیرمجاز | نقض محرمانگی | دسترسی محدود |

## ۴. عیب‌یابی: خوشه‌ای از NAAT گنوکوک مثبت
1. یک کیت/دستگاه/کارشناس؟ کنترل‌های منفی؟
2. **wipe test** سطوح و تجهیزات (آلودگی آمپلیکون/RNA)
3. تکرار نمونه‌ها با روش دوم (هدف متفاوت)
4. در صورت تأیید آلودگی: گزارش اصلاحی + CAPA
