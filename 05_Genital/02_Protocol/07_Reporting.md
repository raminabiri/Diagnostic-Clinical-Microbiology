# پروتکل ۷: گزارش‌دهی — نمونه‌های تناسلی

## ۱. اصول
1. **محرمانگی** بالاتر از معمول (STI): گزارش فقط به پزشک درخواست‌کننده/سامانهٔ امن.
2. **ذکر محل نمونه** (واژن، سرویکس، اورترا، رکتوم، حلق، ادرار).
3. **گزارش به بهداشت** طبق دستورالعمل (گنوره، سیفلیس، کلامیدیا در برخی نظام‌ها).
4. فلور طبیعی با عبارت کلی گزارش شود؛ از نام‌بردن ارگانیسم‌های فلور خودداری کنید.

## ۲. یافته‌های نیازمند اطلاع فوری 📞
| یافته | دلیل |
|---|---|
| **GAS** در نمونه‌های نفاسی/پس از سقط/آندومتر | سپسیس نفاسی؛ کنترل عفونت (خوشهٔ بیمارستانی) |
| *Clostridium sordellii*/*perfringens* پس از سقط/زایمان | شوک توکسیک |
| *Listeria* (جفت/آمنیوتیک) | نوزاد |
| **GNID** در گرم اورترال (درمانگاه اورژانس، طبق سیاست) | درمان هم‌زمان |
| *N. gonorrhoeae* **غیرحساس به سفتریاکسون** یا **مقاوم به آزیترومایسین سطح بالا** | **فوری به بهداشت/مرجع** (تهدید بهداشت عمومی) |
| نتیجهٔ مثبت STI در **کودک** | پزشک + سیستم حمایتی/قانونی طبق قانون |

## ۳. جملات استاندارد

| موقعیت | جمله |
|---|---|
| سواب واژینال برای کشت عمومی | «کشت عمومی سواب واژینال انجام نمی‌شود؛ فلور طبیعی شامل ارگانیسم‌های متعدد است. آزمایش هدفمند (NAAT CT/NG/TV، BV، کاندیدا، GBS) درخواست شود.» |
| GBS مثبت | «*Streptococcus agalactiae* (گروه B) شناسایی شد. پروفیلاکسی ضدمیکروبی حین زایمان توصیه می‌شود.» |
| GBS + آلرژی | «کلیندامایسین: حساس (D-test منفی).» / «کلیندامایسین: **مقاوم** (مقاومت القایی، D-test مثبت)؛ ونکومایسین برای آلرژی پرخطر.» |
| GBS منفی | «استرپتوکوک گروه B جدا نشد.» |
| Nugent ۷–۱۰ | «امتیاز Nugent: ۸؛ سازگار با واژینوز باکتریایی.» |
| کشت گنوکوک مثبت | «*Neisseria gonorrhoeae* جدا شد. آنتی‌بیوگرام پیوست. بیماری واجب‌الگزارش؛ درمان شریک جنسی.» |
| NAAT CT مثبت | «RNA *Chlamydia trachomatis* شناسایی شد (NAAT). درمان شریک جنسی و آزمایش مجدد ۳ ماه بعد توصیه می‌شود.» |
| فلور | «فلور طبیعی واژینال؛ پاتوژن اختصاصی جدا نشد.» |
| *Ureaplasma* در سواب واژینال | «*U. urealyticum* جزء فلور شایع دستگاه تناسلی است؛ اهمیت بالینی در این نمونه محدود است.» |

## ۴. نمونهٔ گزارش‌ها

### الف) غربالگری GBS با آلرژی
```
نمونه: سواب واژینال–رکتال (۳۶ هفته)   آلرژی: پنی‌سیلین — آنافیلاکسی (پرخطر)
روش: غنی‌سازی LIM ← ساب‌کالچر SBA
نتیجه: Streptococcus agalactiae (گروه B) — مثبت
  کلیندامایسین:  R  (D-test مثبت: مقاومت القایی)
  اریترومایسین:  R  (فقط برای D-test؛ برای پروفیلاکسی استفاده نشود)
توضیح: برای پروفیلاکسی حین زایمان در آلرژی پرخطر، ونکومایسین توصیه می‌شود.
```

### ب) کشت گنوکوک (شکست درمان)
```
نمونه: سواب اورترال (مرد)   سابقه: درمان با سفتریاکسون ۵۰۰ mg ۱۰ روز پیش، علائم پایدار
گرم: PMN فراوان؛ دیپلوکوک گرم منفی داخل‌سلولی
کشت: Neisseria gonorrhoeae
آنتی‌بیوگرام (آگار دایلوشن، CLSI):
  سفتریاکسون    MIC 0.5 µg/mL   غیرحساس (Non-susceptible)  [📞 بهداشت/مرجع]
  سفیکسیم       MIC 1           غیرحساس
  آزیترومایسین  MIC 0.5         WT (≤ ECV)
  سیپروفلوکساسین MIC 16         R
توضیح: سویه به آزمایشگاه مرجع برای تأیید و توالی‌یابی ارسال شد. پیگیری شریک‌ها.
```
