# پروتکل ۲: انتقال، پذیرش و رد نمونه‌های تناسلی

## ۱. *N. gonorrhoeae*: حساس‌ترین ارگانیسم به انتقال

| روش | توضیح | زمان |
|---|---|---|
| **تلقیح مستقیم کنار بیمار** (بهترین) | روی **Modified Thayer–Martin (MTM)** یا **Martin–Lewis** یا **GC-Lect** گرم‌شده تا دمای اتاق ← **فوراً در CO₂** (جار شمع یا کیسهٔ تولید CO₂) | — |
| **سیستم‌های انتقال–کشت** (JEMBEC، InTray GC، Gono-Pak) | پلیت با قرص تولید CO₂ | انکوباسیون پیش از حمل ۱۸–۲۴ ساعت در ۳۵ °C (یا طبق IFU) |
| سواب در **محیط انتقال غیرمغذی** (Amies با ذغال، Stuart) | ⚠️ بازده کمتر | **دمای اتاق، ≤ ۶ ساعت** (حداکثر ۲۴ ساعت با کاهش بازده)؛ ⛔ **یخچال** |

> ⛔ **سرما و خشکی** گنوکوک را از بین می‌برند. ⛔ لوبریکانت روی اسپکولوم.

## ۲. سایر نمونه‌ها

| نمونه | ظرف | دما | زمان |
|---|---|---|---|
| NAAT (سواب/ادرار) | لولهٔ کیت | طبق IFU (اغلب ۲–۳۰ °C) | معمولاً **۳۰–۶۰ روز** (سواب در محیط کیت)؛ ادرار خام: ≤ ۲۴ ساعت دمای اتاق/۷ روز یخچال پیش از انتقال به محیط |
| GBS (سواب در Amies/Stuart) | | دمای اتاق یا ۲–۸ °C | **≤ ۴ روز**؛ (پس از ۲۴ ساعت بهتر یخچال) |
| لام هواخشک (Nugent) | جعبهٔ لام | دمای اتاق | روزها |
| آندومتر، بافت، آمنیوتیک (بی‌هوازی) | محیط انتقال بی‌هوازی | دمای اتاق | ≤ ۲ ساعت (تا ۲۴ ساعت در محیط بی‌هوازی) |
| *Ureaplasma*/*Mycoplasma* (کشت) | محیط انتقال مخصوص (مثلاً SP4 یا 10B) | ۴ °C | ≤ ۲۴ ساعت؛ بیشتر: ۷۰– °C |
| *H. ducreyi* | کشت فوری | — | |
| پزشکی قانونی | پلمب + زنجیرهٔ نگهداری | طبق آزمایش | |

## ۳. معیار پذیرش
- سواب/ظرف **مناسب آزمایش** (سواب NAAT کیت X برای کیت X)
- **حجم ادرار اول جریان** در محدودهٔ کیت (خط پرشدن)
- برچسب، **محل نمونه** (واژن/سرویکس/اورترا/رکتوم/حلق)
- برای GBS: **وضعیت آلرژی پنی‌سیلین**

## ۴. معیار رد و اقدام

| مشکل | اقدام |
|---|---|
| سواب کیت NAAT نادرست یا لوله بدون سواب/دو سواب | **رد** (طبق IFU) |
| ادرار بیش از خط یا کمتر از حداقل در لولهٔ NAAT | رد |
| سواب گنوکوک در یخچال یا بیش از ۲۴ ساعت | پردازش با قید/رد؛ پیشنهاد NAAT |
| **سواب واژینال برای «کشت عمومی»** | رد + پیشنهاد آزمایش هدفمند (BV، GBS، NAAT، تریکوموناس، کاندیدا) |
| **کشت *Gardnerella*** | رد (بی‌ارزش) |
| سواب سرویکس برای GBS | رد/قید و درخواست سواب واژینال–رکتال |
| IUD برای کشت روتین | رد (مگر *Actinomyces* با بالین) |
| سواب خشک (برای کشت) | رد |
| نمونهٔ پزشکی قانونی بدون زنجیرهٔ نگهداری | پردازش بالینی، ولی گزارش «بدون اعتبار قانونی»؛ اطلاع به مسئول |

## ۵. نکات ویژه
- **سواب پنبه‌ای و دستهٔ چوبی** برای گنوکوک و کلامیدیا (کشت) ممکن است سمی باشد ← داکرون/ریون/فلاک با دستهٔ پلاستیکی/آلومینیومی.
- NAATهای **گنوکوک در حلق**: واکنش متقاطع با *Neisseria* غیرگنوکوکی در برخی سنجش‌ها ← کیت تأییدشده یا تست تأییدی.
