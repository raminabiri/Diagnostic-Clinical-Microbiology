# آنتی‌بیوگرام پاتوژن‌های تنفسی بر اساس CLSI

> **مرجع:** CLSI M100 (نسخهٔ جاری)، M45 (*Corynebacterium*، *Moraxella*)، M24 (*Nocardia*، مایکوباکتری‌ها). ⚠️ با نسخهٔ جاری تطبیق دهید.

## ۱. پنل بر اساس ارگانیسم

| ارگانیسم (جدول) | پنل | ⛔ / نکته |
|---|---|---|
| ***S. pneumoniae*** (2G) — پنومونی | پنی‌سیلین (وریدی، غیرمننژیت؛ یا آموکسی‌سیلین خوراکی)، سفتریاکسون/سفوتاکسیم (غیرمننژیت)، **اریترومایسین** (پیش‌بینی آزیترومایسین/کلاریترومایسین)، **تتراسایکلین** (پیش‌بینی داکسی‌سایکلین)، **لووفلوکساسین**، TMP-SMX، ونکومایسین، لینزولید، کلیندامایسین (± D-test)، سفتارولین | پنی‌سیلین وریدی غیرمننژیت: S ≤ 2، I = 4، R ≥ 8؛ آموکسی‌سیلین (خوراکی، غیرمننژیت): S ≤ 2، I = 4، R ≥ 8 |
| ***H. influenzae*** (2E) | **بتالاکتاماز**، آمپی‌سیلین، آموکسی‌کلاو، سفتریاکسون/سفوتاکسیم، سفوروکسیم، لووفلوکساسین، TMP-SMX، آزیترومایسین (فقط «S»)، تتراسایکلین | BLNAR |
| ***M. catarrhalis*** (M45) | بتالاکتاماز (اختیاری)؛ در صورت نیاز: آموکسی‌کلاو، سفوروکسیم، اریترومایسین، TMP-SMX، تتراسایکلین، سیپروفلوکساسین | آمپی‌سیلین (بتالاکتاماز) |
| **GAS** (2H-1) | **اریترومایسین**، **کلیندامایسین + D-test** (برای آلرژی/عفونت شدید)؛ پنی‌سیلین تست لازم نیست | |
| ***S. aureus*** (2C) — پنومونی | سفوکسیتین، ونکومایسین (MIC)، **لینزولید**، TMP-SMX، کلیندامایسین (+ D-test)، داکسی‌سایکلین، سفتارولین | ⛔ **داپتومایسین** |
| **Enterobacterales** (2A) — HAP/VAP | پیپ–تازو، سفتریاکسون، سفپیم، مروپنم، سیپروفلوکساسین/لووفلوکساسین، جنتامایسین/توبرامایسین/آمیکاسین، TMP-SMX؛ CRE: سفتازیدیم–اویباکتام، مروپنم–واباباکتام، ایمی‌پنم–رلباکتام، سفیدروکول، کولیستین (BMD) | ⛔ تیگسایکلین (روتین)، نیتروفورانتوئین |
| ***P. aeruginosa*** (2B-1) | پیپ–تازو، سفتازیدیم، سفپیم، ایمی‌پنم، مروپنم، آزترئونام، سیپروفلوکساسین/لووفلوکساسین، توبرامایسین (آمیکاسین: محدود به ادرار در M100 جدید)؛ DTR: سفتولوزان–تازو، سفتازیدیم–اویباکتام، ایمی‌پنم–رلباکتام، سفیدروکول، کولیستین (BMD) | ⛔ جنتامایسین (حذف ۲۰۲۳) |
| ***A. baumannii*** (2B-2) | آمپی‌سیلین–سولباکتام، مروپنم، ایمی‌پنم، سفپیم، سفتازیدیم، آمیکاسین، توبرامایسین، سیپروفلوکساسین، TMP-SMX، مینوسایکلین، کولیستین (BMD)، سولباکتام–دورلوباکتام، سفیدروکول | |
| ***S. maltophilia*** (2B-4) | **TMP-SMX**، لووفلوکساسین، مینوسایکلین، (سفیدروکول) | ⛔ کارباپنم‌ها |
| BCC (2B-3) | (نسخهٔ جاری را چک کنید؛ CLSI بسیاری از نقاط برش را حذف کرده) — گزارش MIC با تذکر | آمینوگلیکوزیدها، کولیستین |
| ***C. diphtheriae*** (M45 *Corynebacterium*) | پنی‌سیلین، اریترومایسین، (کلیندامایسین، ریفامپین، تتراسایکلین، ونکومایسین) | |
| ***Nocardia*** (M24) | TMP-SMX، لینزولید، آمیکاسین، ایمی‌پنم، سفتریاکسون، آموکسی‌کلاو، سیپروفلوکساسین، کلاریترومایسین، توبرامایسین، مینوسایکلین (BMD) | مرجع |

## ۲. انتخاب پنل بر اساس عوامل بیمار

### ۲-۱) سن
| گروه | ملاحظه |
|---|---|
| کودکان | آموکسی‌سیلین (پنوموکوک)، آموکسی‌کلاو (هموفیلوس)، ماکرولید (*Mycoplasma*، سیاه‌سرفه)؛ ⛔ فلوروکینولون/تتراسایکلین (جز ضرورت) |
| شیرخوار کمتر از ۱ ماه (سیاه‌سرفه) | ⛔ اریترومایسین (تنگی پیلور) ← آزیترومایسین |
| سالمند | پنل معمول |

### ۲-۲) جنس و بارداری
| وضعیت | ملاحظه |
|---|---|
| بارداری | ⛔ فلوروکینولون، تتراسایکلین؛ گزارش بتالاکتام‌ها، آزیترومایسین |
| جنس | تأثیری ندارد |

### ۲-۳) بیماری زمینه‌ای و شرایط
| شرایط | ملاحظه |
|---|---|
| **CF** | *P. aeruginosa*: پنل کامل + **توبرامایسین/آمیکاسین/کولیستین/آزترئونام** (استنشاقی)؛ MIC ترجیحی؛ AST هر موروتیپ؛ *S. aureus*: + سفتارولین؛ BCC: مرجع |
| **COPD/برونشکتازی** | *H. influenzae*، *M. catarrhalis*، *P. aeruginosa*: داروهای خوراکی (آموکسی‌کلاو، داکسی، فلوروکینولون) |
| **پس از آنفلوانزا/پنومونی نکروزان** | MRSA: لینزولید (ضدتوکسین)، کلیندامایسین (± D-test)، ونکومایسین |
| **ونتیلاتور/ICU** | پنل گرم منفی بیمارستانی + کارباپنماز + DTR |
| **نقص ایمنی** | *Nocardia*، NTM، *Legionella*؛ ارسال به مرجع |
| **آسپیراسیون** | بی‌هوازی روتین AST نمی‌شوند (آموکسی‌کلاو/آمپی‌سیلین–سولباکتام تجربی) |
| آلرژی بتالاکتام | ماکرولید، داکسی، فلوروکینولون (پنوموکوک)؛ لینزولید/ونکومایسین (MRSA) |
