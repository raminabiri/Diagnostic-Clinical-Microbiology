# پروتکل ۲: انتقال، پذیرش و رد نمونه‌های تنفسی

## ۱. انتقال

| نمونه | دما | حداکثر زمان |
|---|---|---|
| خلط، ETA، BAL، PSB (باکتری) | دمای اتاق | **≤ ۲ ساعت** (رشد بیش از حد فلور و کاهش پنوموکوک/هموفیلوس) |
| | ۲–۸ °C | **≤ ۲۴ ساعت** |
| خلط برای AFB | ۲–۸ °C | ≤ ۷ روز (ترجیحاً کمتر از ۲۴ ساعت) |
| سواب حلق (GAS) | دمای اتاق یا یخچال | ≤ ۴۸–۷۲ ساعت (GAS مقاوم است) |
| دیفتری | دمای اتاق در محیط Amies | ≤ ۲۴ ساعت؛ ترجیحاً تلقیح فوری |
| *B. pertussis* (کشت) | Regan–Lowe انتقال، دمای اتاق | ≤ ۲۴ ساعت (تا ۴۸ ساعت) |
| PCR (سیاه‌سرفه، *Mycoplasma*، پنل‌ها) | ۲–۸ °C | طبق کیت (معمولاً ≤ ۷۲ ساعت؛ بیشتر ۷۰– °C) |
| *Legionella* | ۲–۸ °C | ≤ ۲۴–۴۸ ساعت |
| BAL برای پنل پنومونی | ۲–۸ °C | ≤ ۲۴ ساعت |

## ۲. غربالگری کیفیت خلط (برای کشت باکتری روتین)

### معیارهای میکروسکوپی (در LPF، ۱۰۰×)

| سیستم | قبول | رد |
|---|---|---|
| **Murray–Washington** (رایج) | **کمتر از ۱۰ SEC/LPF** و بیش از ۲۵ PMN/LPF (گروه ۴ و ۵)؛ یا SEC کمتر از ۱۰ به‌تنهایی | **≥ ۱۰ SEC/LPF** (یا بیش از ۲۵ SEC) |
| **Bartlett** (امتیازی) | جمع امتیاز مثبت | جمع امتیاز ≤ ۰ |
| فقط SEC (ساده، ASM) | **کمتر از ۱۰ SEC/LPF** | ≥ ۱۰ SEC/LPF |

> SEC = سلول اپی‌تلیال سنگفرشی (نشانهٔ آلودگی بزاقی).
> ⚠️ **PMN کم** در نوتروپنی، *Legionella* و برخی پنومونی‌ها رخ می‌دهد ← معیار رد اصلی **SEC** است.

### استثناها (غربالگری اعمال نمی‌شود)
- خلط برای **AFB**، **قارچ**، ***Legionella***، ***Nocardia***، **CF**
- **BAL**، **PSB** و بیوپسی
- **ETA**: برخی آزمایشگاه‌ها معیار متفاوت دارند (مثلاً رد اگر **SEC بیش از ۱۰ و بدون باکتری**)؛ نمونه‌های ETA با **«عدم وجود باکتری» در گرم** ارزش اخباری منفی بالایی برای VAP دارند

## ۳. معیار رد و اقدام

| مشکل | اقدام |
|---|---|
| **خلط بزاقی** (SEC ≥ ۱۰/LPF) | **رد** + جمله: «نمونه حاوی بزاق است و برای کشت باکتری مناسب نیست؛ نمونهٔ جدید (سرفهٔ عمیق) ارسال شود.» (گرم گزارش می‌شود ولی کشت انجام نمی‌شود) |
| نمونهٔ **۲۴ ساعته** خلط | رد |
| بیش از یک خلط در ۲۴ ساعت برای کشت روتین | فقط اولی |
| **سواب حلق برای «کشت عمومی»** | فقط GAS (± سایر هدف‌ها با درخواست مشخص) |
| **سواب NP برای کشت باکتری روتین** | رد (مگر سیاه‌سرفه، دیفتری، غربالگری MRSA، *N. meningitidis* حامل) |
| خلط/ETA برای **بی‌هوازی** | رد |
| تأخیر بیش از ۲ ساعت در دمای اتاق | رد/قید |
| سواب پنبه‌ای برای PCR سیاه‌سرفه | رد |
| سواب حلق برای سیاه‌سرفه | رد |
| نمونهٔ «سواب گلو برای *Mycoplasma*» به‌تنهایی | قبول ولی ترکیب NP + حلق ارجح |

## ۴. اولویت‌بندی BAL (حجم محدود)
1. باکتری (گرم + کشت کمّی)
2. AFB/Xpert (ظن TB)
3. قارچ/*Pneumocystis* (خارج از دامنه)
4. *Legionella*، *Nocardia*، ویروس (بر اساس بالین)
5. سیتولوژی (بخش دیگر)

## ۵. اطلاعات بالینی ضروری
CF، ونتیلاتور، نقص ایمنی، ظن TB، دیفتری، سیاه‌سرفه، *Legionella*، مسافرت، آنتی‌بیوتیک قبلی. این اطلاعات **محیط‌ها، انکوباسیون و سطح ایمنی** را تعیین می‌کند.
