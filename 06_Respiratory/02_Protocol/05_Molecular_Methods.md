# پروتکل ۵: روش‌های مولکولی — نمونه‌های تنفسی

> جدا از روش‌های کلاسیک.

## ۱. نمای کلی

| روش | جایگاه |
|---|---|
| **NAAT GAS** (حلق) | جایگزین RADT + کشت (حساسیت بیش از ۹۵٪)؛ بدون نیاز به تأیید منفی‌ها |
| **PCR *B. pertussis*** (IS481 ± IS1001، IS1002، *ptxP*) | **روش انتخابی** در ۰–۴ هفتهٔ اول سرفه |
| PCR *M. pneumoniae* (± **جهش 23S rRNA** مقاومت ماکرولید) | روش انتخابی |
| PCR *C. pneumoniae*، *Legionella* (همهٔ گونه‌ها و سروگروه‌ها) | مکمل آنتی‌ژن ادراری و کشت |
| **Xpert MTB/RIF Ultra** | **آزمون اولیه** TB ریوی (WHO)؛ [ماژول ۲۳](../../23_Mycobacteria/README.md) |
| **پنل پنومونی** (مثلاً BioFire Pneumonia Panel) | BAL/خلط/ETA در بیماران بستری شدید |
| PCR *tox* دیفتری | سریع؛ تأیید Elek |
| PCR *F. necrophorum* | فارنژیت جوانان، لمیر |
| پنل‌های تنفسی ویروسی | خارج از دامنه |
| mNGS BAL | نقص ایمنی، پنومونی ناشناخته (مرجع) |

## ۲. سیاه‌سرفه

| هدف | ویژگی |
|---|---|
| **IS481** | چند نسخه (۵۰–۲۵۰) ← بسیار حساس؛ ⚠️ در ***B. holmesii*** (و برخی *B. bronchiseptica*) هم هست |
| IS1001 | *B. parapertussis* |
| hIS1001 | *B. holmesii* |
| *ptxP* (پروموتر توکسین) | اختصاصی *B. pertussis* |

> 🔬 **Ct بسیار بالا** (مثلاً بیش از ۳۵) IS481: ممکن است **آلودگی محیطی** (واکسن‌های حاوی DNA در مطب) یا تعداد بسیار کم باشد ← «مثبت ضعیف/نامعین» با تفسیر بالینی. **نمونه‌گیری دور از محل تزریق واکسن.**
> زمان: PCR در **۳ هفتهٔ اول** سرفه حساس‌تر است (تا ۴ هفته). **سرولوژی (IgG anti-PT)** پس از ۲–۸ هفته (بزرگسالان/نوجوانان، اگر بیش از ۱ سال از واکسیناسیون گذشته باشد).

## ۳. پنل پنومونی (BioFire Pneumonia Panel — نمونهٔ شاخص)
- **۱۵ باکتری با نتیجهٔ نیمه‌کمّی** (bin: ۱۰⁴، ۱۰⁵، ۱۰⁶، ≥ ۱۰⁷ نسخه/mL): *Acinetobacter calcoaceticus-baumannii* complex، *Enterobacter cloacae* complex، *E. coli*، *H. influenzae*، *K. aerogenes*، *K. oxytoca*، *K. pneumoniae* group، *Moraxella catarrhalis*، *Proteus*، *P. aeruginosa*، *Serratia marcescens*، *S. aureus*، *S. agalactiae*، *S. pneumoniae*، *S. pyogenes*
- **۳ آتیپیک (کیفی):** *C. pneumoniae*، *L. pneumophila*، *M. pneumoniae*
- **ویروس‌ها** (۸ گروه؛ خارج از دامنه)
- **ژن‌های مقاومت:** *mecA/C* + MREJ، CTX-M، KPC، NDM، OXA-48-like، VIM، IMP

### محدودیت‌ها ⚠️
| مسئله | پیامد |
|---|---|
| نسخه/mL **≠** CFU/mL | bin معمولاً **۱ لگ بالاتر** از کشت کمّی است |
| **پوشش ندادن**: *S. maltophilia*، *Achromobacter*، *Legionella* غیر *pneumophila*، *Nocardia*، بی‌هوازی‌ها، MTB | «شناسایی نشد» ≠ عدم وجود |
| بیش از ۵۰٪ شناسایی‌ها در bin پایین ممکن است در کشت رشد نکنند (فلور یا ارگانیسم مرده) | تفسیر با گرم و بالین |
| ژن مقاومت در نمونهٔ چندمیکروبی | به کدام ارگانیسم تعلق دارد؟ |
| **OXA-23** (*A. baumannii*) در پنل نیست | |
| بیشترین ارزش | **ارزش اخباری منفی** برای MRSA و پسودوموناس ← کاهش داروهای وسیع‌الطیف |

## ۴. *Mycoplasma pneumoniae*
- PCR (سواب ترکیبی NP + حلق، یا خلط). **مقاومت به ماکرولید** (جهش 23S rRNA A2063G/A2064G): بسیار بالا در شرق آسیا (بیش از ۸۰٪)؛ متغیر در سایر مناطق.
- سرولوژی IgM: کودکان؛ **جفت‌سرم** برای اطمینان.

## ۵. *Legionella*
- PCR همهٔ گونه‌های *Legionella* (*mip*، *ssrA*، 16S) + *L. pneumophila* اختصاصی
- برای شیوع: **کشت** (ایزوله) برای مقایسهٔ ژنومی با نمونه‌های آب ضروری است ← کشت را کنار PCR انجام دهید

## ۶. تشخیص مولکولی سل (اشاره)
- Xpert MTB/RIF Ultra روی خلط (اولین نمونه)؛ Xpert MTB/XDR (INH، فلوروکینولون، آمینوگلیکوزید)
- LPA (Line probe)، WGS در مرجع
- جزئیات: [ماژول ۲۳](../../23_Mycobacteria/README.md)
