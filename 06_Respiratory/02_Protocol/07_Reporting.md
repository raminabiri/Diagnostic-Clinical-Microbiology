# پروتکل ۷: گزارش‌دهی — نمونه‌های تنفسی

## ۱. اصول
- **کیفیت نمونه** را گزارش کنید (SEC، PMN).
- **نیمه‌کمّی** (یا CFU/mL در کمّی) برای هر پاتوژن.
- **فلور** با عبارت کلی؛ ارگانیسم‌های فلور نام برده نشوند.
- پاتوژن‌های بهداشت عمومی ← گزارش فوری و ارسال به مرجع.

## ۲. یافته‌های نیازمند اطلاع فوری 📞
| یافته | گیرنده |
|---|---|
| **AFB مثبت** یا Xpert MTB مثبت (± مقاومت ریفامپین) | پزشک + **کنترل عفونت** (ایزولهٔ تنفسی) + بهداشت |
| ***C. diphtheriae*** (حتی مشکوک) | پزشک + **بهداشت (فوری)** + مرجع |
| ***B. pertussis*** | پزشک + بهداشت |
| *Legionella* (کشت/آنتی‌ژن/PCR) | پزشک + بهداشت (بررسی منبع آب) |
| ***Nocardia*** | پزشک |
| ☣️ مشکوک به *B. anthracis*، *Y. pestis*، *F. tularensis*، *Burkholderia mallei/pseudomallei* | **مسئول آزمایشگاه + آزمایشگاه مرجع + بهداشت** (بدون ادامهٔ کار) |
| GAS در نمونهٔ تهاجمی (پلور/BAL)، پنومونی نکروزان *S. aureus* | پزشک |
| CRE/CRAB/MRSA در بیمار بستری (جدید) | کنترل عفونت |
| اولین BCC در بیمار CF | پزشک CF + کنترل عفونت |

## ۳. جملات استاندارد

| موقعیت | جمله |
|---|---|
| خلط بزاقی | «نمونه حاوی بزاق است (SEC ≥ ۱۰/LPF) و نمایندهٔ دستگاه تنفسی تحتانی نیست؛ کشت انجام نشد. لطفاً نمونهٔ جدید از سرفهٔ عمیق ارسال شود.» |
| فلور | «فلور طبیعی دهانی–حلقی؛ پاتوژن غالب جدا نشد.» |
| پاتوژن غالب | «*Streptococcus pneumoniae* — رشد فراوان (غالب).» |
| ETA کمّی | «*P. aeruginosa* حدود ۱۰⁶ CFU/mL؛ *K. pneumoniae* حدود ۱۰³ CFU/mL (زیر آستانه).» |
| BAL | «*S. aureus* ۵ × ۱۰⁴ CFU/mL (بالاتر از آستانهٔ ۱۰⁴).» |
| مخمر | «مخمر جدا شد؛ در نمونه‌های تنفسی معمولاً کلونیزاسیون است و شناسایی نشد.» |
| GAS | «*Streptococcus pyogenes* (گروه A) جدا شد.» |
| RADT منفی کودک | «آنتی‌ژن سریع GAS منفی؛ کشت تأییدی در جریان.» |
| دیفتری | «*Corynebacterium diphtheriae* بیوتایپ mitis جدا شد؛ آزمون توکسین (Elek/PCR) در آزمایشگاه مرجع. بیماری واجب‌الگزارش فوری.» |
| پنل مولکولی | «نتایج نیمه‌کمّی پنل (نسخه/mL) معادل CFU/mL کشت نیستند.» |

## ۴. نمونهٔ گزارش (VAP)

```
نمونه: آسپیرهٔ داخل‌تراشه (ETA)   بیمار ونتیله ۶ روز، ICU
گرم: PMN فراوان؛ SEC نادر؛ باسیل‌های گرم منفی فراوان
کشت کمّی:
  Pseudomonas aeruginosa  ≥ ۱۰⁶ CFU/mL
  فلور دهانی–حلقی          کم
آنتی‌بیوگرام P. aeruginosa:
  پیپراسیلین–تازوباکتام  R
  سفتازیدیم             R
  سفپیم                 R
  مروپنم               R
  سیپروفلوکساسین        R
  توبرامایسین           S
  آمیکاسین              S
  سفتولوزان–تازوباکتام   S
  سفتازیدیم–اویباکتام   S
  کولیستین (BMD)        MIC 1 (I، CLSI)
توضیح: P. aeruginosa با مقاومت دشوار به درمان (DTR). کنترل عفونت مطلع شد.
```
