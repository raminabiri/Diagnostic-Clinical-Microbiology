# آنتی‌بیوگرام در باکتریمی — اصول

## ۱. ویژگی‌های AST در کشت خون
1. **سرعت** اهمیت حیاتی دارد. روش‌های سریع (RAST، BCID) در کنار روش استاندارد.
2. **دقت MIC** در برخی ارگانیسم‌ها/داروها الزامی است: ونکومایسین در استافیلوکوک، پنی‌سیلین در استرپتوکوک‌های ویریدانس و اندوکاردیت، داپتومایسین، کولیستین.
3. **گزارش انتخابی** با محوریت داروهای وریدی مؤثر در باکتریمی.
4. **تفسیر مکانیسم‌محور** (ESBL، AmpC، کارباپنماز، MRSA، VRE) برای انتخاب درست دارو، حتی وقتی نتیجهٔ ظاهری «حساس» است.
5. **ارگانیسم‌های آلوده‌کنندهٔ محتمل** آنتی‌بیوگرام نمی‌شوند (CoNS تک‌ست و …).

## ۲. داروهایی که در باکتریمی معمولاً گزارش نمی‌شوند

| دارو | دلیل |
|---|---|
| نیتروفورانتوئین، فسفومایسین خوراکی | غلظت خونی ناکافی؛ فقط ادراری |
| داروهای فقط خوراکی (سفالکسین، سفیکسیم، آموکسی‌سیلین) | نه برای درمان اولیهٔ باکتریمی (ممکن است در تغییر به خوراکی بعدی با درخواست گزارش شوند) |
| تیگسایکلین | سطح سرمی پایین؛ افزایش مرگ در متاآنالیزها؛ نه برای باکتریمی |
| اریترومایسین (استافیلوکوک) | فقط برای D-test |
| سفالوسپورین‌ها برای *Enterococcus*، *Listeria*، MRSA | مقاومت ذاتی/مکانیسمی |
| آمینوگلیکوزیدها برای *Salmonella* و *Shigella* | در شرایط آزمایشگاهی فعال، در بدن بی‌اثر (CLSI) |
| سفالوسپورین‌های نسل ۱ و ۲ و سفامایسین‌ها برای *Salmonella* | همان دلیل |
| **پیپراسیلین–تازوباکتام** برای ESBL در باکتریمی | گزارش شود ولی با جملهٔ تفسیری (کارآزمایی MERINO) |

## ۳. مقاومت‌های ذاتی پرکاربرد (خلاصه)

| ارگانیسم | مقاوم ذاتی به |
|---|---|
| *Enterococcus* spp. | سفالوسپورین‌ها، آمینوگلیکوزیدها (سطح پایین)، کلیندامایسین، TMP-SMX (در بدن)؛ *E. faecium*: اغلب آمپی‌سیلین (اکتسابی)؛ *E. gallinarum/casseliflavus*: ونکومایسین سطح پایین (*vanC*) |
| *Listeria* | سفالوسپورین‌ها |
| *K. pneumoniae* | آمپی‌سیلین |
| *E. cloacae* complex، *K. aerogenes*، *C. freundii*، *S. marcescens*، *Morganella*، *Providencia*، *Hafnia* (گروه «ESCPM/HAFNIA») | آمپی‌سیلین، آموکسی‌کلاو، سفازولین/سفالوسپورین نسل ۱، (*Serratia*: کولیستین)؛ **AmpC کروموزومی القایی** |
| *Proteus*، *Morganella*، *Providencia*، *Serratia* | **کولیستین/پلی‌میکسین**، تتراسایکلین/تیگسایکلین (کاهش حساسیت)، نیتروفورانتوئین |
| *P. aeruginosa* | آمپی‌سیلین، آموکسی‌کلاو، سفازولین، سفوتاکسیم/سفتریاکسون، ارتاپنم، تتراسایکلین/تیگسایکلین، TMP-SMX |
| *A. baumannii* | آمپی‌سیلین، آموکسی‌کلاو، سفازولین، ارتاپنم، فسفومایسین، آزترئونام (عملاً) |
| *S. maltophilia* | **همهٔ کارباپنم‌ها**، آمینوگلیکوزیدها، بیشتر بتالاکتام‌ها |
| *Burkholderia cepacia* complex | آمینوگلیکوزیدها، کولیستین، بیشتر بتالاکتام‌ها |
| *Elizabethkingia*، *Chryseobacterium* | کارباپنم‌ها، کولیستین، آمینوگلیکوزیدها |
| گرم منفی‌ها | ونکومایسین، لینزولید، داپتومایسین، کلیندامایسین |
| *Erysipelothrix*، *Leuconostoc*، *Pediococcus*، *Lactobacillus* (اغلب) | **ونکومایسین** |
| *Bacillus cereus* | بتالاکتام‌ها (پنی‌سیلین، سفالوسپورین‌ها) |
| *B. fragilis* group | پنی‌سیلین، آمپی‌سیلین (بتالاکتاماز) |

## ۴. مکانیسم‌های مقاومت مهم در باکتریمی

| مکانیسم | تشخیص آزمایشگاهی | پیام گزارش |
|---|---|---|
| **MRSA** | سفوکسیتین ۳۰ µg (دیسک) یا MIC اکساسیلین؛ PBP2a؛ *mecA/mecC* | همهٔ بتالاکتام‌ها R (به‌جز سفتارولین/سفتوبیپرول) |
| **پنی‌سیلیناز در *S. aureus*** | نیتروسفین + **آزمون لبهٔ هاله** (Zone-edge test) برای سویه‌های با هالهٔ پنی‌سیلین ≥ ۲۹ mm | پنی‌سیلین فقط اگر هر دو منفی‌اند S گزارش شود |
| **VISA/hVISA** | MIC ونکومایسین ۴–۸ (*S. aureus*)؛ **دیسک تشخیص نمی‌دهد** | MIC ≥ ۲ با پاسخ بالینی ضعیف ← بررسی hVISA (مرجع) |
| مقاومت القایی کلیندامایسین (*erm*) | **D-test** | کلیندامایسین R گزارش شود (در باکتریمی کاربرد محدود) |
| **VRE** | MIC ونکومایسین؛ *vanA/vanB* | لینزولید، داپتومایسین (دوز بالا) |
| **HLAR** | جنتامایسین ۱۲۰ µg / استرپتومایسین ۳۰۰ µg (دیسک) یا BMD (۵۰۰/۱۰۰۰ µg/mL) | «سینرژی با جنتامایسین وجود ندارد» در اندوکاردیت انتروکوکی |
| **ESBL** | دیسک ترکیبی کلاوولانات (CLSI، اختیاری)؛ CTX-M | **کارباپنم** برای باکتریمی |
| **AmpC القایی کروموزومی** (*E. cloacae*، *K. aerogenes*، *C. freundii*) | از گونه استنتاج می‌شود | سفتریاکسون حتی اگر S باشد خطر شکست؛ **سفپیم** ارجح (IDSA AMR Guidance) |
| AmpC پلاسمیدی (CMY، DHA) در *E. coli*/*Klebsiella* | مقاومت به سفوکسیتین + سفالوسپورین‌های نسل ۳؛ آزمون‌های مهار با بورونیک اسید/کلوکساسیلین | سفپیم یا کارباپنم |
| **کارباپنماز** | mCIM/eCIM، Carba NP، ایمونوکروماتوگرافی (KPC، OXA-48، NDM، VIM، IMP)، PCR | انتخاب دارو بر اساس **نوع** آنزیم (فایل CLSI) |
| **DTR-*P. aeruginosa*** (Difficult-to-treat) | مقاوم به همهٔ بتالاکتام‌های ضدپسودومونایی و فلوروکینولون‌ها | تست سفتولوزان–تازوباکتام، سفتازیدیم–اویباکتام، ایمی‌پنم–رلباکتام، سفیدروکول |
| مقاومت به کینولون در *Salmonella* | MIC سیپروفلوکساسین با نقاط برش اختصاصی *Salmonella* (CLSI)؛ دیسک **پفلوکساسین ۵ µg** (EUCAST) | ⚠️ دیسک نالیدیکسیک اسید برخی مکانیسم‌ها (*qnr*) را تشخیص نمی‌دهد |

## ۵. اندوکاردیت: نکات ویژه 🔬
- **استرپتوکوک‌های ویریدانس و *S. gallolyticus*:** **MIC پنی‌سیلین** (و سفتریاکسون) الزامی است. دسته‌بندی AHA برای رژیم درمان:
  - MIC ≤ 0.12 µg/mL: بسیار حساس
  - بیش از 0.12 تا کمتر از 0.5: حساسیت نسبی
  - ≥ 0.5: مقاوم (رژیم انتروکوکی)
- ***Enterococcus*:** آمپی‌سیلین، ونکومایسین، **HLAR** (جنتامایسین و استرپتومایسین). در *E. faecalis* حساس به آمپی‌سیلین ← آمپی‌سیلین + سفتریاکسون (سینرژی دوگانهٔ بتالاکتام) گزینهٔ رایج است، به‌ویژه با HLAR مثبت.
- ***S. aureus*:** MIC ونکومایسین و داپتومایسین؛ ریفامپین و جنتامایسین برای دریچهٔ مصنوعی.
- **HACEK:** بتالاکتاماز؛ سفتریاکسون (CLSI M45).
- **NVS** (*Abiotrophia*، *Granulicatella*): MIC پنی‌سیلین و سفتریاکسون در CAMHB + خون اسب لیزشده + پیریدوکسال (M45)؛ درمان مشابه انتروکوک.

## ۶. گزارش انتخابی (Cascade) در باکتریمی — مثال‌ها

| ارگانیسم | ردیف ۱ (همیشه) | ردیف ۲ (اگر ردیف ۱ مقاوم یا درخواست) |
|---|---|---|
| *E. coli* | آمپی‌سیلین، سفازولین*، سفتریاکسون، پیپ–تازو، جنتامایسین، سیپروفلوکساسین، TMP-SMX | سفپیم، مروپنم، ارتاپنم، آمیکاسین؛ و اگر کارباپنم R: سفتازیدیم–اویباکتام، مروپنم–واباباکتام، ایمی‌پنم–رلباکتام، سفیدروکول، کولیستین (BMD) |
| *S. aureus* | اکساسیلین (سفوکسیتین)، ونکومایسین (MIC)، TMP-SMX، کلیندامایسین (± D-test) | داپتومایسین، لینزولید، ریفامپین، سفتارولین |
| *P. aeruginosa* | پیپ–تازو، سفتازیدیم، سفپیم، مروپنم، سیپروفلوکساسین، توبرامایسین | ایمی‌پنم، آزترئونام، آمیکاسین؛ DTR: داروهای جدید + کولیستین |

\* سفازولین با نقاط برش سیستمیک (نه ادراری).

## ۷. آنتی‌بیوگرام تجمعی (CLSI M39)
- **فقط اولین ایزولهٔ هر گونه برای هر بیمار** در دورهٔ گزارش
- حداقل **۳۰ ایزوله** برای گزارش درصد حساسیت
- به‌تفکیک: کل بیمارستان، ICU، منبع خون
- انتشار سالانه برای درمان تجربی و سیاست‌های مدیریت آنتی‌بیوتیک
