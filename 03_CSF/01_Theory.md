# تئوری: عفونت‌های باکتریایی سیستم عصبی مرکزی

## ۱. بیماری‌ها

| سندرم | تعریف | اهمیت برای آزمایشگاه |
|---|---|---|
| **مننژیت باکتریایی حاد** (Acute bacterial meningitis) | التهاب نرم‌شامه و عنکبوتیه و عفونت فضای زیرعنکبوتیه | اورژانس؛ لام و کشت CSF محور تشخیص |
| **مننژیت مرتبط با شانت/درن** (Shunt/EVD-associated ventriculitis) | عفونت سیستم شانت بطنی یا درن خارجی بطن | ارگانیسم‌های کم‌حدت؛ کشت طولانی |
| **مننژیت پس از جراحی اعصاب یا تروما** (Post-neurosurgical / post-traumatic meningitis) | پس از کرانیوتومی، شکستگی قاعدهٔ جمجمه یا نشت CSF | باسیل‌های گرم منفی بیمارستانی و استافیلوکوک |
| **آبسهٔ مغزی** (Brain abscess) | کانون چرکی داخل پارانشیم | LP اغلب ممنوع؛ نمونه از آسپیرهٔ آبسه |
| **مننژیت سلی** (Tuberculous meningitis) | عفونت تحت‌حاد/مزمن با *M. tuberculosis* | حجم زیاد CSF، Xpert، کشت طولانی |
| **مننژیت آسپتیک** (Aseptic meningitis) | پلئوسیتوز با کشت باکتری منفی | اغلب ویروسی؛ افتراق از مننژیت نیمه‌درمان |

## ۲. عوامل ایجادکننده

### ۲-۱) بر اساس سن

| گروه | عوامل شایع | نکته |
|---|---|---|
| نوزاد (< ۱ ماه) | *Streptococcus agalactiae* (GBS)، *Escherichia coli* (به‌ویژه K1)، *Listeria monocytogenes* | سایر گرم منفی‌ها: *Klebsiella*، *Citrobacter koseri* (آبسهٔ مغزی)، *Cronobacter sakazakii* (شیرخشک)، *Elizabethkingia meningoseptica* |
| ۱ تا ۲۳ ماه | *S. pneumoniae*، *N. meningitidis*، GBS، *H. influenzae* | GBS تا حدود ۳ ماهگی (شروع دیررس) |
| ۲ تا ۵۰ سال | *N. meningitidis*، *S. pneumoniae* | مننگوکوک در نوجوانان و تجمع‌ها (خوابگاه، سربازخانه، حج) |
| > ۵۰ سال | *S. pneumoniae*، *L. monocytogenes*، باسیل‌های گرم منفی هوازی | لیستریا در سالمندان پوشش تجربی می‌خواهد |

### ۲-۲) بر اساس شرایط زمینه‌ای

| شرایط | عوامل |
|---|---|
| شکستگی قاعدهٔ جمجمه / نشت CSF (رینوره) | *S. pneumoniae*، *H. influenzae*، استرپتوکوک گروه A |
| ترومای نافذ / پس از کرانیوتومی | *S. aureus*، استافیلوکوک‌های کوآگولاز منفی (CoNS)، باسیل‌های گرم منفی (*Klebsiella*، *Acinetobacter baumannii*، *Pseudomonas aeruginosa*) |
| شانت بطنی یا EVD | CoNS (به‌ویژه *S. epidermidis*)، *S. aureus*، *Cutibacterium acnes*، باسیل‌های گرم منفی |
| بارداری، نقص ایمنی سلولی، پیوند، کورتیکواستروئید، الکلیسم | *L. monocytogenes* |
| اسپلنکتومی، آسپلنی | *S. pneumoniae*، *N. meningitidis*، *H. influenzae* |
| نقص کمپلمان انتهایی (C5–C9) یا مصرف اکولیزومب | *N. meningitidis* (عود‌کننده، سروگروه‌های نادر) |
| HIV | *S. pneumoniae*، *L. monocytogenes*، *M. tuberculosis* (+ کریپتوکوک) |
| مصرف شیر غیرپاستوریزه و لبنیات سنتی | *Brucella* spp. (نوروبروسلوز)، *L. monocytogenes* |
| عفونت گوش میانی/سینوس | *S. pneumoniae*، *H. influenzae*؛ در آبسه: استرپتوکوک‌های گروه *anginosus* و بی‌هوازی‌ها |

> 🔬 **پیشرفته — اپیدمیولوژی تغییرپذیر:** واکسیناسیون Hib (در برنامهٔ ملی ایران به‌صورت پنتاوالان) بروز مننژیت *H. influenzae* تیپ b را به‌شدت کاهش داده است؛ بنابراین هموفیلوس غیرتیپ b و غیرقابل‌تیپ‌بندی نسبتاً مهم‌تر شده‌اند. واکسن کونژوگهٔ پنوموکوک باعث جابه‌جایی سروتیپ (serotype replacement) شده است. *Brucella* در مناطق آندمیک از جمله ایران باید در مننژیت مزمن لنفوسیتی مدنظر باشد.

### ۲-۳) راه‌های ورود
- **هماتوژن** (شایع‌ترین): کلونیزاسیون نازوفارنکس ← تهاجم ← باکتریمی ← عبور از سد خونی–مغزی.
- **مجاورتی:** اوتیت، سینوزیت، ماستوئیدیت.
- **مستقیم:** تروما، جراحی، شانت، نقص مادرزادی (سینوس درمال، میلومننگوسل).

## ۳. علائم بالینی

| گروه | علائم |
|---|---|
| بزرگسال | تب، سردرد، سفتی گردن، تغییر هوشیاری (تریاد کلاسیک فقط در حدود ۴۰–۵۰٪)؛ تهوع، استفراغ، فوتوفوبی، تشنج، علائم کانونی عصبی |
| مننگوکوکسمی | پتشی و پورپورای سریعاً پیشرونده، شوک، DIC (پورپورا فولمینانس) |
| نوزاد و شیرخوار | علائم غیراختصاصی: تب یا هیپوترمی، بی‌قراری، خواب‌آلودگی، بدی تغذیه، آپنه، فونتانل برجسته، تشنج |
| سالمند و نقص ایمنی | ممکن است تب و سفتی گردن نداشته باشند؛ فقط گیجی |
| مننژیت سلی | شروع تدریجی طی هفته‌ها، سردرد، تب خفیف، فلج اعصاب کرانیال، هیدروسفالی |
| عفونت شانت | سردرد، تب خفیف، اختلال کارکرد شانت، قرمزی مسیر شانت، درد شکم (شانت VP) |

نشانه‌های کرنیگ و برودزینسکی اختصاصی‌اند ولی **حساسیت پایینی** دارند؛ منفی‌بودن آن‌ها مننژیت را رد نمی‌کند.

## ۴. تشخیص بالینی و اقدامات اولیه

1. **ظن بالینی** ← کشت خون **پیش از** آنتی‌بیوتیک (در ۵۰–۹۰٪ مننژیت باکتریایی مثبت است).
2. **تصویربرداری پیش از LP** فقط در صورت وجود یکی از موارد زیر (معیارهای IDSA): نقص ایمنی، سابقهٔ ضایعهٔ CNS، تشنج جدید (یک هفتهٔ اخیر)، پاپی‌ادم، کاهش سطح هوشیاری، نقص عصبی کانونی.
3. **پونکسیون کمری** و ارسال CSF برای شمارش سلولی، قند، پروتئین، لاکتات، گرم و کشت (± PCR).
4. **آنتی‌بیوتیک تجربی نباید منتظر CT یا LP بماند.** اگر LP به تأخیر می‌افتد: کشت خون ← دگزامتازون + آنتی‌بیوتیک ← CT ← LP.

| گروه | درمان تجربی رایج (جهت آشنایی آزمایشگاه) |
|---|---|
| نوزاد | آمپی‌سیلین + سفوتاکسیم (یا آمپی‌سیلین + آمینوگلیکوزید) |
| ۱ ماه تا ۵۰ سال | سفتریاکسون/سفوتاکسیم + ونکومایسین |
| > ۵۰ سال یا نقص ایمنی سلولی | سفتریاکسون + ونکومایسین + آمپی‌سیلین |
| پس از جراحی اعصاب/شانت | ونکومایسین + سفپیم یا سفتازیدیم یا مروپنم |

> ⚠️ **پیام برای آزمایشگاه:** CSF ظرف ۲–۴ ساعت پس از آنتی‌بیوتیک وریدی ممکن است برای مننگوکوک استریل شود (برای پنوموکوک معمولاً تا حدود ۴–۱۰ ساعت). بنابراین ثبت **زمان دوز اول آنتی‌بیوتیک** روی برگهٔ درخواست برای تفسیر کشت منفی ضروری است.

## ۵. پیش‌آگهی و عوارض
- مرگ‌ومیر مننژیت پنوموکوکی حتی با درمان مناسب حدود ۱۵–۳۰٪ است.
- عوارض: کاهش شنوایی (به‌ویژه پنوموکوک و Hib)، تشنج، هیدروسفالی، اختلال شناختی.
- **مننژیت مننگوکوکی و Hib بیماری‌های واجب‌الگزارش‌اند**؛ تماس‌های نزدیک پروفیلاکسی می‌گیرند. آزمایشگاه در زنجیرهٔ گزارش‌دهی نقش مستقیم دارد (فایل [07_Reporting.md](02_Protocol/07_Reporting.md)).
