# ۱۵. باسیل‌های گرم مثبت هوازی

## دامنه
| گروه | جنس/گونه‌های مهم |
|---|---|
| **اسپوردار** | ***Bacillus anthracis*** ☣️، ***B. cereus*** group، سایر *Bacillus* |
| **کورینه‌فرم‌ها** | ***Corynebacterium diphtheriae***، *C. ulcerans*، *C. pseudotuberculosis*؛ *C. jeikeium*، *C. urealyticum*، *C. striatum*، *C. amycolatum*؛ *Arcanobacterium haemolyticum*، *Trueperella pyogenes*، *Rothia dentocariosa* |
| **باسیل‌های کوتاه منظم** | ***Listeria monocytogenes***، ***Erysipelothrix rhusiopathiae***، *Lactobacillus*، ***Gardnerella vaginalis*** |
| **اکتینومیست‌های هوازی** | ***Nocardia***، ***Rhodococcus equi***، *Gordonia*، *Tsukamurella*، *Streptomyces*، *Actinomadura* |
| خارج از این ماژول | *Cutibacterium*، *Actinomyces*، *Clostridium* ← [22 بی‌هوازی‌ها](../22_Anaerobes/README.md)؛ مایکوباکتری‌ها ← [23](../23_Mycobacteria/README.md) |

## اهمیت بالینی (خلاصه)
| ارگانیسم | بیماری |
|---|---|
| ***L. monocytogenes*** | **مننژیت/باکتریمی** در بارداری، نوزادان، سالمندان، نقص ایمنی سلولی؛ **مقاومت ذاتی به سفالوسپورین‌ها** |
| ***B. anthracis*** | سیاه‌زخم پوستی، تنفسی، گوارشی، تزریقی ☣️ |
| ***B. cereus*** | مسمومیت غذایی؛ عفونت چشم پس از تروما؛ باکتریمی کاتتر؛ نوزادان |
| ***C. diphtheriae*** (توکسیژنیک) | دیفتری حلقی و پوستی؛ **اورژانس بهداشتی** |
| ***C. jeikeium*، *C. striatum*، *C. amycolatum*** | عفونت کاتتر، پروتز، اندوکاردیت؛ **چندمقاوم** |
| ***C. urealyticum*** | **سیستیت انکروسته**، سنگ استروویت |
| ***Arcanobacterium haemolyticum*** | فارنژیت نوجوانان با **راش شبه‌مخملکی** |
| ***Erysipelothrix*** | اریزیپلوئید (کارگران گوشت/ماهی)، اندوکاردیت؛ **ونکومایسین R ذاتی** |
| ***Gardnerella*** | واژینوز باکتریایی، باکتریمی پس از زایمان |
| ***Nocardia*** | عفونت ریوی، **آبسهٔ مغزی**، پوستی؛ نقص ایمنی و پیوند |
| ***Rhodococcus equi*** | پنومونی حفره‌دار (HIV، پیوند) |

## ایمنی ☣️
***B. anthracis***: کلنی **بزرگ، خاکستری، غیرهمولیتیک، شیشهٔ مات، لبهٔ «سر مدوسا»**، چسبنده، **بی‌حرکت** ← **توقف کار روی میز باز**، **BSC**، **بدون MALDI-TOF**، ارجاع (پروتکل Sentinel) ← [12_Identification_Tests/03 بخش ۳.۱۲](../12_Identification_Tests/03_Disk_and_Growth_Tests.md).
